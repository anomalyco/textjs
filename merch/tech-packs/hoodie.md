### Center chest: ▼, tonal embroidery

| | |
| --- | --- |
| Artwork | `artwork/hoodie-chest.svg` |
| Size | 44.45 × 38.89 mm (1.75 × 1.53 in), all sizes |
| Placement | Centered on the center front, top edge 4 in below the front neck seam |
| Stitch | Fill (tatami) at 45° with a 1 mm satin border for a sharp edge; a solid shape this wide is too long for satin alone |
| Estimate | About 4,000 stitches (digitizer to confirm) |
| Thread | Black: Isacord 40 #0020 or Madeira Polyneon 40 #1800 |
| Backing | Cutaway; water-soluble topping so stitches sit above the fleece |

The mark is tonal. It shows where light catches the stitch direction.
