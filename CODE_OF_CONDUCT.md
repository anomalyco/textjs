# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Harassment, personal attacks and publishing other people's private information are not tolerated.

This applies in the repository, in issues and pull requests, and anywhere you represent the project.

## Reporting

Report unacceptable behavior to [conduct@textjs.org](mailto:conduct@textjs.org). Reports are kept confidential. Maintainers may remove comments and contributions that break this code, and ban the people who post them.
