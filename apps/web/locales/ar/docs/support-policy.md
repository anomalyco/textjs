الإصلاحات في إصدارات الدعم طويل الأمد

<!-- s:043b92b499 -->
- الثغرات الأمنية في حزم Text.js
- الأعطال وفقدان البيانات وفشل البناء التي لا يتوفر لها حل بديل
- التوافق مع إصدارات Chrome و Edge و Firefox و Safari الجديدة التي تعطّل العرض في وحدة التحكم
- التوافق مع بيئات التشغيل ووجهات النشر المدعومة

التغييرات غير المتوافقة

<!-- s:82596fcd52 -->
لا تتغير العناصر التالية إلا في إصدار رئيسي، بعد تحذير بإيقاف الدعم في إصدار فرعي واحد على الأقل:

<!-- s:4ca9fd7807 -->
- التصديرات العامة للحزم `@textjs/app` و `@textjs/react` و `@textjs/core`، بما فيها `@textjs/app/server` و `@textjs/app/cache`
- خيارات `text.config.ts` وأوامر واجهة سطر الأوامر `text` وراياتها
- اصطلاحات الملفات في `app/` و `middleware.ts` وإعدادات مقاطع المسارات
- تخطيطات مخرجات المحوّل (`.vercel/output`، `_worker.js`، `dist/server.js`)

<!-- s:883f3eeb26 -->
لا تشمل التغطية: واجهات API المصنّفة تجريبية أو `unstable_`، بما فيها كل ما يندرج ضمن `@textjs/core/experimental`، و `@textjs/react/experimental` و `@textjs/app/experimental` ‏(قد تتغير في إصدار ثانوي، مع ملاحظات في سجل التغييرات)، والتفاصيل الداخلية مثل `@textjs/core/internal`، وترويسات `x-middleware-*` والبيانات الوصفية للبناء في `.text/`، وإصدارات canary، والصياغة الدقيقة لسلاسل التنسيق و CSS في `console.log` ‏(تبقى الإطارات متطابقة بصريًا؛ وقد يصبح ترميزها أسرع).

دعم بيئات التشغيل

<!-- s:30122ce1bb -->
| بيئة التشغيل | الإصدارات المدعومة |
| :-- | :-- |
| DevTools في Chrome / Edge | الإصدار المستقر الحالي والإصداران المستقران السابقان |
| وحدتا التحكم في Firefox و Safari | الإصدار المستقر الحالي |
| Node.js | إصدارات الدعم طويل الأمد النشطة وإصدارات الصيانة (`text start`، وظائف Vercel) |
| Bun | أحدث إصدار من 1.x |
| Cloudflare Workers | `compatibility_date` بتاريخ 2025-01-01 أو أحدث، `nodejs_compat` |

<!-- s:509c18536b -->
لا يُعد إسقاط دعم إصدار من بيئة تشغيل بلغ نهاية عمره تغييرًا غير متوافق.
