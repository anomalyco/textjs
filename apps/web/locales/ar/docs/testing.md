تعرض الحزمة `@textjs/app/testing` (أو `@textjs/react/testing`) تطبيقك خارج الشاشة، وتضغط المفاتيح وتُرجع الإطار كنص. تعمل الاختبارات دون متصفح أو DevTools.

<!-- s:9bc71b1ad2 -->
تعمل مع أي مشغّل يدعم اختبارات `async`، بما في ذلك Bun و Vitest و Jest.

<!-- s:f7898e6b92 -->
العرض

<!-- s:fc969a7928 -->
| الطريقة | الوصف |
| :-- | :-- |
| `render(el, { cols, rows, theme })` | تركيب خارج الشاشة (80×24 افتراضيًا) |
| `lastFrame()` | الإطار كنص عادي |
| `lines()` | الإطار كمصفوفة من الصفوف |
| `frames` | كل إطار مميز حتى الآن |
| `toAnsi()` | ANSI بألوان حقيقية، للقطات |
| `cell(x, y)` | `{ char, fg, bg, attrs }` |
| `locate(text)` | إحداثيات `{ x, y }` لأول تطابق |
| `rerender(el)` / `unmount()` | تحديث أو إزالة التركيب |

<!-- s:893f22353a -->
تعرض الدالة `renderToString(el, options)` مرة واحدة وتُرجع النص.

<!-- s:99a3c4d459 -->
الإدخال

<!-- s:105149560b -->
يعمل كل استدعاء داخل `act()` ويُفرغ الإطارات الناتجة، ليرى التوكيد التالي التحديث.

<!-- s:1f65c071dc -->
الوقت

<!-- s:ab365d9403 -->
تستخدم الرسوم المتحركة ومؤشرات الانتظار والإشعارات العابرة مؤقتات حقيقية، لذا تُعدّ `wait` و `waitFor` الطريقة الموثوقة لمراقبتها.

<!-- s:26f93acae3 -->
اللقطات

<!-- s:05724c9883 -->
تُزال المسافات البيضاء من يمين الإطارات وأسفلها، فلا تتغير اللقطات بسببها.
