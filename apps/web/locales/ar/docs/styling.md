نسّق المكوّنات باستخدام أدوات `className` أو خصائص محددة الأنواع. لا تحتوي تطبيقات Text.js على أوراق أنماط.

<!-- s:e0ac1db626 -->
أدوات التنسيق

<!-- s:2de571e2bf -->
تقبل `className` أدوات تنسيق بأسلوب Tailwind. تساوي كل وحدة خلية واحدة.

<!-- s:785b2c3db0 -->
| الفئة | أمثلة |
| :-- | :-- |
| التخطيط | `flex-row` `grow` `items-center` `gap-1` |
| التباعد | `p-1` `px-2` `mt-1` |
| الحدود | `border` `rounded` `border-accent` |
| اللون | `bg-surface` `text-muted` |

<!-- s:0b98e5506b -->
خصائص محددة الأنواع

<!-- s:4963259a42 -->
لكل أداة تنسيق خاصية مقابلة. تتقدم الخصائص على `className`.

<!-- s:15a3834a24 -->
الألوان

<!-- s:d333dad27a -->
استخدم القيم السداسية العشرية أو أسماء Tailwind أو رموز السمة مثل `fg` و `muted` و `surface` و `accent` و `success` و `danger`. تتبع الرموز السمة النشطة.

<!-- s:087abce968 -->
السمات

<!-- s:abba2a3188 -->
تتوفر خمسة إعدادات مسبقة مدمجة: `geistDark` و `geistLight` و `opencodeDark` و `tokyoNight` و `amberCrt`.
