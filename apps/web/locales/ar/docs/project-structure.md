text.config.ts

<!-- s:144c0672ce -->
| الخيار | القيمة الافتراضية | الوصف |
| :-- | :-- | :-- |
| `title` | `""` | عنوان الصفحة و FocusPad |
| `viewport` | ملاءمة وحدة التحكم، وإلا `120×36` | `responsive` (القيمة الافتراضية `true`)، والأبعاد البديلة `width × height`، و `theme` |
| `hints` | `[]` | مفتاحان أو ثلاثة مفاتيح تظهر على FocusPad في الصفحة |
| `action` | `press <first hint>` | الإجراء المطلوب بعد التركيز، مثل `"type a prompt"` |
| `devIndicators` | `true` | طبقة التطوير داخل وحدة التحكم (`[▼]`) |
| `focusHint` | `true` | «انقر على الصفحة لاستخدام لوحة المفاتيح» فوق الصف الأخير في وحدة التحكم عندما لا يكون التركيز على الصفحة |
| `rewrites` | `[]` | إعادة الكتابة والوكلاء |
| `ansi` | `{ cols: 80, rows: 24 }` | حجم الإطار لعملاء [curl والطرفية](/docs/curl)، أو `false` لتقديم HTML لهم |
