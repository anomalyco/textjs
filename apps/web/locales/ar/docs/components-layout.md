تخطّط هذه العناصر الأساسية شبكة الخلايا باستخدام Yoga flexbox.

<!-- s:00be928124 -->
`<Box>`

<!-- s:cdedc6ec73 -->
حاوية التخطيط.

<!-- s:b2726c7ef5 -->
| Prop | الوصف |
| :-- | :-- |
| `className` | أدوات تنسيق الخلايا |
| `border` | `single` `rounded` `double` `heavy` `dashed` |
| `title` | نص مضمّن في الحد العلوي |
| `bg` / `fg` | لون الخلفية والنص |
| `overflow` | `hidden` أو `scroll` |

<!-- s:a83221d138 -->
`<Text>`

<!-- s:ea0876c03f -->
نص ضمن السطر. تتحول مكوّنات `<Text>` المتداخلة إلى عناصر span منسّقة.

<!-- s:d078a242d3 -->
| Prop | الوصف |
| :-- | :-- |
| `color` | لون النص |
| `bold` `italic` `underline` `dim` | السمات |
| `wrap` | `wrap` `nowrap` `truncate-end` |

<!-- s:e9a9218253 -->
`<ScrollBox>`

<!-- s:51162fc3b2 -->
عمود قابل للتمرير. تثبّت الخاصية `stickyScroll` موضع التمرير في الأسفل مع ازدياد المحتوى.

<!-- s:9029b4d81b -->
`<Modal>`

<!-- s:3804dec517 -->
طبقة متراكبة في الوسط تعتّم ما تحتها وتحصر التركيز داخلها.

<!-- s:7a128a8b11 -->
Spacer و Divider و Badge

<!-- s:72e5d35050 -->
أدوات مساعدة للتخطيط

<!-- s:e76299d593 -->
اختصارات لترتيبات flex الشائعة.

<!-- s:0f066fb217 -->
`<SplitPane>`

<!-- s:20cd99b8e7 -->
لوحتان وفاصل. عند استخدام `resizable`، ينضم الفاصل إلى ترتيب التنقل بمفتاح `Tab` ويغيّر المفتاحان `←` `→` موضعه (بمقدار خمس خلايا مع `Shift`).

<!-- s:2143924860 -->
تأخذ الخاصية `size` قيمة كسرية (`0.3`) أو عددًا من الخلايا (`24`). يرتّب الإعداد `direction="column"` اللوحتين عموديًا.
