تعمل حقول الإدخال هذه بلوحة المفاتيح وتدير تركيزها بنفسها.

<!-- s:1d0d345c65 -->
التركيز

<!-- s:bc06482880 -->
ينقل `Tab` و `Shift+Tab` التركيز بين العناصر. يكتسب `autoFocus` التركيز عند تركيب المكوّن.

<!-- s:fca23dd943 -->
تستهلك المحررات التي لها التركيز ضغطات مفاتيحها، لذا لا تؤدي كتابة `1` أبدًا إلى تشغيل اختصار عام.

<!-- s:7c862ee98e -->
`<Input>`

<!-- s:fdde26d4d9 -->
حقل إدخال أحادي السطر مع تحرير بأسلوب readline.

<!-- s:88cdcfc0ea -->
| Prop | الوصف |
| :-- | :-- |
| `value` / `onChange` | قيمة متحكّم بها |
| `onSubmit` | استدعاء عند الضغط على `Enter` |
| `placeholder` | نص يظهر عند خلو الحقل |
| `mask` | حرف إخفاء للقيم السرية |

<!-- s:995d41e175 -->
`<Textarea>`

<!-- s:cf370a7f95 -->
محرر متعدد الأسطر. يرسل `Enter` المحتوى، ويضيف `Shift+Enter` سطرًا جديدًا.

<!-- s:667b32bc16 -->
`<Select>`

<!-- s:1c8033c766 -->
قائمة خيارات بلوحة المفاتيح مع بحث تقريبي اختياري.

<!-- s:70fe7d6c9b -->
| Prop | الوصف |
| :-- | :-- |
| `options` | `{ value, label, hint?, badge? }[]` |
| `onChange` | استدعاء عند الضغط على `Enter` |
| `searchable` | تصفية الخيارات عند الكتابة |

<!-- s:958ee46fb6 -->
`<Tabs>`

<!-- s:f61cb509c5 -->
المؤشر عند فقدان التركيز

<!-- s:f0552feed5 -->
عندما تفقد الصفحة التركيز، تتجمد المؤشرات وتتوقف الإطارات، مما يتيح تحديد نص وحدة التحكم ونسخه.
