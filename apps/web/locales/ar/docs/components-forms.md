يتضمن Text.js عناصر تحكم للنماذج ومربعات حوار وإشعارات عابرة. ينضم كل عنصر تحكم إلى ترتيب التنقل بمفتاح `Tab` ويستجيب لمفتاح `Space` أو `Enter`.

<!-- s:0c4878f82e -->
عناصر التحكم

<!-- s:920d5e74e5 -->
| المكوّن | المفاتيح | القيمة |
| :-- | :-- | :-- |
| `<Button>` | `↵` `Space` | `onPress` |
| `<Checkbox>` | `Space` `↵` | `checked` / `onChange` |
| `<Switch>` | `Space` `←` `→` | `checked` / `onChange` |
| `<RadioGroup>` | `↑` `↓` (أو `←` `→`) | `value` / `onChange` |
| `<Slider>` | `←` `→`، `Shift` ×5، `Home` `End` | `value` / `onChange` |

<!-- s:1c3c5ba8fd -->
تقبل جميعها `autoFocus` و `focused` و `id` و `disabled`. تعمل في الوضع المتحكم فيه وغير المتحكم فيه (`defaultChecked`، `defaultValue`).

<!-- s:0a2857b66b -->
الأزرار

<!-- s:1981291f42 -->
تكون قيمة `variant` إحدى القيم `primary` أو `secondary` أو `ghost` أو `danger`. يملأ التركيز الزر بلون التمييز دون تغيير حجمه.

<!-- s:56be122300 -->
`<Dialog>`

<!-- s:30940c6b5c -->
مكوّن `<Modal>` مع وصف وصفّ للإجراءات.

<!-- s:7cfec2b258 -->
`<Confirm>`

<!-- s:7e0406516a -->
نعم أو لا. يجيب المفتاحان `y` و `n` مباشرة؛ وينقل المفتاحان `←` و `→` التركيز بين الأزرار. يحدد `destructive` نمط زر التأكيد ويركز على زر «إلغاء» أولًا.

<!-- s:fecae30a60 -->
الإشعارات العابرة

<!-- s:76abda6137 -->
اعرض مكوّن `<Toaster />` واحدًا، ثم استدعِ `useToast()` في أي موضع ضمن الجذر نفسه.

<!-- s:d5c6b1208e -->
| الخيار | الوصف |
| :-- | :-- |
| `duration` | المدة بالمللي ثانية (الافتراضي `4000`؛ تبقى إشعارات التحميل) |
| `id` | إعادة الاستخدام لتحديث إشعار عابر في مكانه |
| `position` | في `<Toaster>`: ‏`bottom-right` (الافتراضي)، `top-center`، … |
| `max` | في `<Toaster>`: عدد الإشعارات الظاهرة في آن واحد (الافتراضي `3`) |

<!-- s:476f42f2b3 -->
تُعرض الإشعارات العابرة فوق مربعات الحوار المشروطة ولا تستحوذ على التركيز أبدًا.
