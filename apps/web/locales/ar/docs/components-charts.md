`<LineChart>`

<!-- s:79abfce919 -->
مخططات خطية بمصفوفة نقاط مع محور ص ودليل.

<!-- s:977778a73f -->
| Prop | الوصف |
| :-- | :-- |
| `series` | `{ data, label?, color? }[]` |
| `data` | اختصار لسلسلة واحدة |
| `height` | الصفوف (الافتراضي `8`) |
| `min` / `max` | حدود ثابتة (الافتراضي: البيانات) |
| `axis` | محور ص مع تسميات للحدين الأدنى والأقصى |
| `formatValue` | تسميات المحور (الافتراضي `1.2k`) |
| `marker` | `quadrant` (الافتراضي) أو `braille` |

<!-- s:3827b070cb -->
يحزم `braille` شبكة نقاط 2×4 في كل خلية. استخدمه في الطرفيات: لا يدعم Menlo، خط وحدة التحكم في DevTools على macOS، رموز برايل، والرموز البديلة أعرض من خلية.

<!-- s:a1d8752203 -->
ألوان السلاسل الافتراضية هي `accent` و `success` و `warning` و `info` و `danger`.

`<Image>`

<!-- s:35a4098e50 -->
ترسم وحدتا التحكم في Chromium و Firefox الصورة ككائن رسومي بكسلي. يحافظ فن البكسل (256 لونًا أو أقل، دون بكسلات شفافة جزئيًا) على ما يصل إلى 8 × 16 بكسل لكل خلية، والصور الفوتوغرافية على ما يصل إلى 4 × 8. تستخدم Safari والطرفيات والنسخ النصية العادية والصفحات ذات [`runtime = "server"`](/docs/server-rendering) أنصاف الكتل `▀`: تحتوي كل خلية على بكسلين، العلوي في المقدمة والسفلي في الخلفية. مرّر `renderMode="halfblock"` لرسم أنصاف الكتل في كل مكان، كما كان يفعل `<Image>` في الإصدار 1.3.

<!-- s:70bb4fc454 -->
| Prop | الوصف |
| :-- | :-- |
| `src` | عنوان URL للصورة (المتصفح فقط) |
| `pixels` | بيانات RGBA خام بصيغة `{ width, height, data }`، 4 بايت لكل بكسل بترتيب الصفوف |
| `width` / `height` | العرض بالخلايا والارتفاع بالصفوف. مرّر أحدهما للحفاظ على نسبة الأبعاد، أو لا تمرّر أيًا منهما لاستخدام 1 × 2 بكسل لكل خلية (يضبط `src` الحجم إلى 256 × 256 px كحد أقصى) |
| `fit` | `contain` (الافتراضي)، أو `cover` أو `fill` |
| `alt` | النص المعروض أثناء تحميل `src` أو عند فشله |
| `renderMode` | `auto` (الافتراضي: كائن رسومي حيث يُدعم، وأنصاف كتل `▀` في غير ذلك) أو `halfblock` |

<!-- s:c106665c64 -->
يقبل `<Image>` أيضًا خصائص التخطيط.

<!-- s:20dac26bff -->
يُحمّل `src` عبر لوحة رسم، لذا تحتاج الصور من مصادر مختلفة إلى CORS. يقبل `pixels` بيانات RGBA خام في أي مكان، بما في ذلك الطرفية.

<!-- s:4e3b06ef0e -->
تُرسم الصورة أيضًا بأنصاف الكتل في Chromium و Firefox عندما يتعذر عرضها ككائن رسومي واحد:

<!-- s:00d2e660eb -->
- صورتان متجاورتان في الصفوف نفسها، كما في معرض صور.
- صورة فوتوغرافية بجانبها نص. يبقى فن البكسل بجانب النص كائنًا رسوميًا.
- صورة مقتصة بواسطة صندوق `overflow="hidden"`، أو مغطاة جزئيًا بصندوق آخر.
- بكسلات شفافة فوق نص أو فوق أكثر من لون خلفية واحد.

<!-- s:dd4fefaac0 -->
`<Pixels>` (تجريبي)

<!-- s:71eeeca05d -->
تصدّر الحزمة `@textjs/react/experimental` المكوّن `<Pixels>` لمخازن الإطارات الحية بتنسيق `0xRRGGBBAA` مثل الألعاب والمحاكيات والفيديو. اكتب البكسلات المحزومة في `source.data` في موضعها وزد `frame` لإعادة الرسم.

<!-- s:2d12b69e81 -->
| Prop | الوصف |
| :-- | :-- |
| `source` | `{ width, height, data: Uint32Array }` بترتيب `0xRRGGBBAA` |
| `frame` | عداد الإطارات؛ زده بعد تعديل `source.data` |
| `width` / `height` | حجم الصندوق بالخلايا والصفوف |
| `fit` | `contain` (الافتراضي) أو `fill` |
| `pixelAspect` | العرض المعروض مقسومًا على ارتفاع بكسل مصدر واحد (الافتراضي `1`) |
| `palette` | لوحة ألوان `PackedColor[]` اختيارية لتكميم الألوان وفقًا لها |
| `sample` | مرشح أنصاف الكتل البديلة: `nearest` (الافتراضي) أو `average` |
| `renderMode` | `auto` (الافتراضي: كائن رسومي حيث يُدعم، وأنصاف كتل `▀` في غير ذلك) أو `halfblock` |

<!-- s:2164b4fe56 -->
يرسم `renderMode="auto"` كائنًا رسوميًا بكسليًا في Chromium، وفي Firefox وفق قواعد تنسيق وحدة التحكم فيه (لم يُقَس أداؤه)، ويستخدم أنصاف الكتل `▀` بديلًا في Safari والطرفيات والنسخ النصية العادية والصفحات ذات [`runtime = "server"`](/docs/server-rendering). مرّر `renderMode="halfblock"` لرسم أنصاف الكتل في كل مكان.

<!-- s:5d2bbbc47b -->
لرسم البكسلات دون React، استورد `drawPixels` من `@textjs/core/experimental` مع `DrawPixelsOptions` و `PixelSource` و `PixelFit` و `PixelSample` و `PixelRenderMode` و `PixelEncoding` و `PixelRect`. يحافظ الخيار `encoding: "rgba"` على أكثر من 256 لونًا وعلى تدرج الشفافية للصور الثابتة، ويرسم `fallback` خلاياك الخاصة حيثما يتعذر عرض الكائن الرسومي. راجع [التغييرات غير المتوافقة](/docs/support-policy#breaking-changes) لمعرفة كيفية تحديد إصدارات الصادرات التجريبية.
