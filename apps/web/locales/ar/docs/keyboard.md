عرّف الاختصارات مرة واحدة باستخدام `useKeymap`. يوجّهها Text.js، ويسردها في طبقة `?`، ويعرضها في التذييل ويتيح البحث عنها في لوحة الأوامر.

<!-- s:b084dfc727 -->
`useKeymap`

<!-- s:f944f97e4b -->
| الصيغة | المعنى |
| :-- | :-- |
| `ctrl+k` | مفاتيح التعديل: `ctrl` `alt` `shift` `meta` `mod` |
| `mod+k` | `⌘` أو `Ctrl`، أيهما مضغوط |
| `j, down` | بدائل |
| `g g` | تسلسل (1 ثانية بين المفاتيح) |
| `G` | الحرف الكبير يعني استخدام `Shift` |
| `?` | تطابق المفاتيح القابلة للطباعة الحرف |

<!-- s:ef55b4b9de -->
تكون القيم معالجًا أو ربطًا يتضمن `label` و `group` و `hint` و `disabled` و `noRepeat`. تعمل الروابط التي لا تحمل تسميات، لكنها لا تظهر في طبقة المساعدة.

<!-- s:01f344cdbe -->
يعيد `useKeymapBindings()` الروابط ذات التسميات النشطة حاليًا، لاستخدامها في تذييلات وقوائم خاصة بك.

<!-- s:dd8af5eb69 -->
تعمل خرائط المفاتيح عبر `useInput`، لذا تنطبق القواعد المعتادة: تكون الأولوية لحقول الإدخال التي عليها التركيز، ويوقف المفتاح المطابق انتشار الحدث، ويعطّل `<Modal>` المفتوح الروابط خارجه. مرّر `{ priority, global, isActive }` لتغيير ذلك.

<!-- s:da19075700 -->
`<KeyHelp>`

<!-- s:907e2eedda -->
اضغط `?` لعرض كل الروابط ذات التسميات ضمن مجموعات. تسرد الطبقة الروابط النشطة في الموضع الذي فُتحت فيه.

<!-- s:3cebb95bfc -->
`<KeyHints>` و `<StatusBar>`

<!-- s:04fa34bd49 -->
يعرض `<KeyHints />` الروابط المعلّمة بالقيمة `hint: true`، أو عناصر `items` المحددة صراحة. يمثّل `<StatusBar>` تذييلًا من صف واحد مع موضع `right`.

<!-- s:b9ded39a0a -->
يعرض `<Kbd>mod+k</Kbd>` مفتاحًا واحدًا. تعطي `formatKeys("ctrl+shift+p")` النتيجة `⌃⇧P` على macOS و `ctrl+shift+P` على الأنظمة الأخرى.

<!-- s:8b6afd6178 -->
`<CommandPalette>`

<!-- s:65192cd436 -->
يفتح `Ctrl+K` (أو `Ctrl+P`) مشغّلًا ببحث تقريبي يشمل أوامرك وكل الروابط ذات التسميات، مع تمييز الأحرف المطابقة.

<!-- s:e88bab4eab -->
| Prop | الوصف |
| :-- | :-- |
| `commands` | `{ id, label, group?, keys?, keywords?, run }[]` |
| `keys` | اختصار الفتح (الافتراضي `ctrl+k, ctrl+p`؛ والقيمة `null` للتعطيل) |
| `includeKeymap` | سرد روابط خريطة المفاتيح (الافتراضي `true`) |
| `open` / `onOpenChange` | تحكّم خارجي |

<!-- s:ddd093fe85 -->
تُغلق اللوحة قبل تنفيذ الأمر، لذا يمكن للأوامر فتح نوافذ حوار خاصة بها. تُصدّر `fuzzyMatch` و `fuzzyFilter` لاستخدامهما في قوائمك الخاصة.
