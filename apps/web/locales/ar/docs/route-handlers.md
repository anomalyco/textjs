تحدد معالجات المسارات نقاط نهاية API في الدليل `app` باستخدام واجهتي الويب `Request` و `Response`.

<!-- s:895d99d1b5 -->
اصطلاح التسمية

<!-- s:ac1d1b9fcb -->
صدّر `GET` أو `POST` أو `PUT` أو `PATCH` أو `DELETE` أو `HEAD` أو `OPTIONS`. تعمل المعالجات مع `text dev` و `text start` وكل [محوّل نشر](/docs/deploying) للخادم، بعد [middleware](/docs/middleware). خزّن معالجات `GET` مؤقتًا باستخدام [إعدادات مقطع المسار](/docs/caching).

<!-- s:53eeba0ff3 -->
المعالجات الديناميكية

<!-- s:bfa759b36e -->
تُفك شيفرة قيم `params`. يتلقى المسار الذي يحتوي على شرطة مائلة أو شرطة مائلة عكسية مشفّرة (`%2F`، `%5C`) الاستجابة `400`، لذا مرّر المعرّفات التي قد تحتوي على `/` في معامل استعلام أو شفّرها بصيغة base64url.
