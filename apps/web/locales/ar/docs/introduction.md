Text.js إطار عمل يستخدم React لتطبيقات تُعرض في وحدة التحكم ضمن DevTools باستخدام `console.log`.

<!-- s:34bf1ea7dd -->
المعاينة تفاعلية. انقر عليها واضغط `↑`.

<!-- s:0bccbd98be -->
المزايا المضمّنة

<!-- s:d3708efc68 -->
- **React 19**: العرض المتزامن، و Suspense وحدود الأخطاء.
- **App Router**: التخطيطات والصفحات والمقاطع الديناميكية ومعالجات المسارات.
- **تخطيط Yoga**: flexbox في WebAssembly، مع محاذاة إلى خلايا ذات أبعاد صحيحة.
- **Turbolog**: استدعاء واحد للدالة `console.log` لكل إطار تغيّر.
- **واجهة وحدة التحكم**: تستضيف الصفحة لوحة تركيز وحقل إدخال مخفيًا فقط.

<!-- s:5ae438610c -->
آلية العمل

<!-- s:75f47f9f8c -->
تتدفق الحالة نزولًا: React، ثم التخطيط، ثم مخزن مؤقت للخلايا، ثم وحدة التحكم.

<!-- s:25c55610d2 -->
تُتخطّى الإطارات التي لم تتغيّر، لذا لا تسجّل التطبيقات الخاملة شيئًا.
