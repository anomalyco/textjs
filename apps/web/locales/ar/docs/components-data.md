تعرض `<List>` و `<Table>` و `<Tree>` مجموعات بيانات كبيرة. تُعرض الصفوف المرئية فقط.

<!-- s:44ffd1d0a7 -->
التنقل

<!-- s:e3dca4574c -->
تستخدم `<List>` و `<Table>` و `<Tree>` نموذجًا موحدًا للوحة المفاتيح.

<!-- s:cdac0643be -->
| المفاتيح | الإجراء |
| :-- | :-- |
| `↑` `↓` / `j` `k` | التنقل |
| `PgUp` `PgDn`، `Ctrl+U` `Ctrl+D` | التنقل صفحة، نصف صفحة |
| `Home` `End` / `g` `G` | الأول، الأخير |
| `↵` | `onSelect` |
| عجلة التمرير | تحريك المؤشر |

<!-- s:1c65c42a4d -->
تملأ العنصر الأب افتراضيًا. مرّر `height` لتحديد عدد ثابت من الصفوف.

<!-- s:3a828804bb -->
`<List>`

<!-- s:2603a57dc8 -->
قائمة افتراضية العرض. يبلغ ارتفاع كل صف خلية واحدة.

<!-- s:3408e68b29 -->
| Prop | الوصف |
| :-- | :-- |
| `items` | أي مصفوفة |
| `renderItem` | `(item, { highlighted, focused }) => ReactNode` |
| `isItemDisabled` | يتجاوزه المؤشر |
| `height` | الصفوف المرئية (الافتراضي: ملء المساحة) |
| `highlightedIndex` / `onHighlight` | مؤشر متحكَّم فيه |
| `vimKeys` | `j` `k` `g` `G` (الافتراضي `true`) |

<!-- s:55759482eb -->
`<Table>`

<!-- s:ff77c49577 -->
تتقاسم الأعمدة العرض المتبقي ما لم تحدد `width`. تستخدم الرؤوس والخلايا قواعد flex نفسها، لذا تتراصف دائمًا.

<!-- s:e9719839f0 -->
| حقل العمود | الوصف |
| :-- | :-- |
| `key` | المعرّف وموصّل الوصول الافتراضي |
| `width` / `grow` | عدد ثابت من الخلايا أو حصة من الباقي |
| `align` | `left` `right` `center` |
| `value` | قيمة العرض والفرز |
| `render` | محتوى خلية مخصص |
| `compare` | فرز مخصص |

<!-- s:045ee40857 -->
الفرز

<!-- s:d04de39344 -->
مع `sortable`، اضغط رقم العمود للفرز حسبه (ومرة أخرى لعكس الاتجاه)، واضغط `s` للتنقل بين الأعمدة و `S` لعكس الاتجاه. الفرز مستقر. تحكّم فيه باستخدام `sort` و `onSortChange`.

<!-- s:6d625a19ed -->
التحديد

<!-- s:2132bc20a2 -->
يضيف `selectionMode="multiple"` عمود خانات اختيار؛ ويبدّل `Space` حالة تحديد الصف المميز. استخدم `selectedKeys` و `onSelectionChange` للتحكم في التحديد، و `getRowKey` للحصول على مفاتيح ثابتة.

<!-- s:3bd95f58e2 -->
`<Tree>`

<!-- s:ec4c582ab8 -->
شجرة قابلة للتوسيع مع خطوط إرشادية.

<!-- s:eeb148154f -->
يوسّع `→` الفرع أو ينتقل إلى داخله. يطوي `←` الفرع أو ينتقل إلى العنصر الأب. يبدّل `Space` حالة التوسيع. تتيح `flattenTree(data, expanded)` الصفوف المرئية إذا احتجت إلى عارض خاص بك.
