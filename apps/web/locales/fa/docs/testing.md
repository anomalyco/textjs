ماژول `@textjs/app/testing` (یا `@textjs/react/testing`) برنامهٔ شما را خارج از صفحه رندر می‌کند، کلیدها را فشار می‌دهد و فریم را به‌صورت متن برمی‌گرداند. تست‌ها بدون مرورگر یا DevTools اجرا می‌شوند.

<!-- s:9bc71b1ad2 -->
این ماژول با هر اجراکننده‌ای که از تست‌های `async` پشتیبانی کند، از جمله Bun، Vitest و Jest، کار می‌کند.

<!-- s:f7898e6b92 -->
رندر

<!-- s:fc969a7928 -->
| متد | توضیحات |
| :-- | :-- |
| `render(el, { cols, rows, theme })` | نصب خارج از صفحه (پیش‌فرض 80×24) |
| `lastFrame()` | فریم به‌صورت متن ساده |
| `lines()` | فریم به‌صورت آرایه‌ای از سطرها |
| `frames` | همهٔ فریم‌های متمایز تا این لحظه |
| `toAnsi()` | ANSI با رنگ واقعی، برای اسنپ‌شات‌ها |
| `cell(x, y)` | `{ char, fg, bg, attrs }` |
| `locate(text)` | مختصات `{ x, y }` اولین تطابق |
| `rerender(el)` / `unmount()` | به‌روزرسانی یا برچیدن |

<!-- s:893f22353a -->
تابع `renderToString(el, options)` یک بار رندر می‌کند و متن را برمی‌گرداند.

<!-- s:99a3c4d459 -->
ورودی

<!-- s:105149560b -->
هر فراخوانی درون `act()` اجرا می‌شود و فریم‌های حاصل را تخلیه می‌کند، بنابراین بررسی بعدی به‌روزرسانی را می‌بیند.

<!-- s:1f65c071dc -->
زمان

<!-- s:ab365d9403 -->
انیمیشن‌ها، نشانگرهای چرخان و اعلان‌های گذرا از زمان‌سنج‌های واقعی استفاده می‌کنند، بنابراین توابع `wait` و `waitFor` راه مطمئن مشاهدهٔ آن‌ها هستند.

<!-- s:26f93acae3 -->
اسنپ‌شات‌ها

<!-- s:05724c9883 -->
فضای خالی سمت راست و پایین فریم‌ها حذف می‌شود تا اسنپ‌شات‌ها به‌دلیل فضای خالی مدام تغییر نکنند.
