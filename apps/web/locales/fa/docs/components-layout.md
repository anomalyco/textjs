این اجزای پایه، شبکهٔ سلول‌ها را با flexbox در Yoga چیدمان می‌کنند.

<!-- s:00be928124 -->
`<Box>`

<!-- s:cdedc6ec73 -->
ظرف چیدمان.

<!-- s:b2726c7ef5 -->
| Prop | توضیحات |
| :-- | :-- |
| `className` | ابزارهای سلول |
| `border` | `single` `rounded` `double` `heavy` `dashed` |
| `title` | متنِ درج‌شده در حاشیهٔ بالا |
| `bg` / `fg` | رنگ پس‌زمینه و متن |
| `overflow` | `hidden` یا `scroll` |

<!-- s:a83221d138 -->
`<Text>`

<!-- s:ea0876c03f -->
متن درون‌خطی. کامپوننت `<Text>` تودرتو به spanهای دارای سبک تبدیل می‌شود.

<!-- s:d078a242d3 -->
| Prop | توضیحات |
| :-- | :-- |
| `color` | رنگ متن |
| `bold` `italic` `underline` `dim` | ویژگی‌ها |
| `wrap` | `wrap` `nowrap` `truncate-end` |

<!-- s:e9a9218253 -->
`<ScrollBox>`

<!-- s:51162fc3b2 -->
ستونی با قابلیت پیمایش. ویژگی `stickyScroll` با افزایش محتوا، موقعیت پیمایش را در پایین نگه می‌دارد.

<!-- s:9029b4d81b -->
`<Modal>`

<!-- s:3804dec517 -->
لایه‌ای در مرکز که محتوای زیر خود را کم‌نور می‌کند و تمرکز را درون خود نگه می‌دارد.

<!-- s:7a128a8b11 -->
Spacer، Divider و Badge

<!-- s:72e5d35050 -->
ابزارهای کمکی چیدمان

<!-- s:e76299d593 -->
میان‌برهایی برای آرایش‌های رایج flex.

<!-- s:0f066fb217 -->
`<SplitPane>`

<!-- s:20cd99b8e7 -->
دو بخش و یک جداکننده. با ویژگی `resizable`، جداکننده به ترتیب پیمایش کلید `Tab` اضافه می‌شود و کلیدهای `←` `→` اندازهٔ آن را تغییر می‌دهند (با کلید `Shift` به‌اندازهٔ پنج سلول).

<!-- s:2143924860 -->
مقدار `size` کسری (`0.3`) یا تعدادی سلول (`24`) است. تنظیم `direction="column"` بخش‌ها را روی هم می‌چیند.
