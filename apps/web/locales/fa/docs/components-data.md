کامپوننت‌های `<List>`، `<Table>` و `<Tree>` مجموعه‌داده‌های بزرگ را نمایش می‌دهند. فقط ردیف‌های قابل‌مشاهده رندر می‌شوند.

<!-- s:44ffd1d0a7 -->
ناوبری

<!-- s:e3dca4574c -->
کامپوننت‌های `<List>`، `<Table>` و `<Tree>` مدل مشترکی برای کار با صفحه‌کلید دارند.

<!-- s:cdac0643be -->
| کلیدها | عمل |
| :-- | :-- |
| `↑` `↓` / `j` `k` | جابه‌جایی |
| `PgUp` `PgDn`، `Ctrl+U` `Ctrl+D` | یک صفحه، نیم‌صفحه |
| `Home` `End` / `g` `G` | ابتدا، انتها |
| `↵` | `onSelect` |
| چرخ ماوس | جابه‌جایی مکان‌نما |

<!-- s:1c65c42a4d -->
این کامپوننت‌ها به‌طور پیش‌فرض فضای والد خود را پر می‌کنند. برای تعداد ثابتی از ردیف‌ها، مقدار `height` را ارسال کنید.

<!-- s:3a828804bb -->
`<List>`

<!-- s:2603a57dc8 -->
یک فهرست مجازی‌سازی‌شده. ارتفاع هر ردیف یک سلول است.

<!-- s:3408e68b29 -->
| Prop | توضیح |
| :-- | :-- |
| `items` | هر آرایه‌ای |
| `renderItem` | `(item, { highlighted, focused }) => ReactNode` |
| `isItemDisabled` | رد شدن از آن هنگام حرکت مکان‌نما |
| `height` | ردیف‌های قابل‌مشاهده (پیش‌فرض: پر کردن فضا) |
| `highlightedIndex` / `onHighlight` | مکان‌نمای کنترل‌شده |
| `vimKeys` | `j` `k` `g` `G` (پیش‌فرض `true`) |

<!-- s:55759482eb -->
`<Table>`

<!-- s:ff77c49577 -->
ستون‌ها عرض باقی‌مانده را بین خود تقسیم می‌کنند، مگر اینکه مقدار `width` را تعیین کنند. سرستون‌ها و سلول‌ها از قواعد یکسان flex استفاده می‌کنند، بنابراین همیشه هم‌تراز می‌مانند.

<!-- s:e9719839f0 -->
| فیلد ستون | توضیح |
| :-- | :-- |
| `key` | شناسه و دسترسی‌دهنده پیش‌فرض |
| `width` / `grow` | تعداد ثابت سلول‌ها یا سهمی از فضای باقی‌مانده |
| `align` | `left` `right` `center` |
| `value` | مقدار نمایش و مرتب‌سازی |
| `render` | محتوای سفارشی سلول |
| `compare` | مرتب‌سازی سفارشی |

<!-- s:045ee40857 -->
مرتب‌سازی

<!-- s:d04de39344 -->
با فعال بودن `sortable`، شماره یک ستون را برای مرتب‌سازی بر اساس آن فشار دهید (دوباره برای معکوس کردن)، کلید `s` را برای گردش بین ستون‌ها و کلید `S` را برای معکوس کردن جهت فشار دهید. مرتب‌سازی پایدار است. آن را با `sort` و `onSortChange` کنترل کنید.

<!-- s:6d625a19ed -->
انتخاب

<!-- s:2132bc20a2 -->
تنظیم `selectionMode="multiple"` یک ستون علامت‌گذاری اضافه می‌کند؛ کلید `Space` وضعیت انتخاب ردیف برجسته‌شده را تغییر می‌دهد. برای کنترل آن از `selectedKeys` و `onSelectionChange` و برای کلیدهای پایدار از `getRowKey` استفاده کنید.

<!-- s:3bd95f58e2 -->
`<Tree>`

<!-- s:ec4c582ab8 -->
یک درخت بازشدنی با خطوط راهنما.

<!-- s:eeb148154f -->
کلید `→` شاخه را باز می‌کند یا وارد آن می‌شود. کلید `←` شاخه را می‌بندد یا به والد می‌رود. کلید `Space` وضعیت باز یا بسته بودن را تغییر می‌دهد. اگر به رندرکننده خودتان نیاز دارید، تابع `flattenTree(data, expanded)` ردیف‌های قابل‌مشاهده را در اختیارتان می‌گذارد.
