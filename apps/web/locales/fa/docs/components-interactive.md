این ورودی‌ها با صفحه‌کلید کنترل می‌شوند و فوکوس خود را مدیریت می‌کنند.

<!-- s:1d0d345c65 -->
فوکوس

<!-- s:bc06482880 -->
کلیدهای `Tab` و `Shift+Tab` فوکوس را به‌صورت چرخه‌ای جابه‌جا می‌کنند. ویژگی `autoFocus` هنگام نصب کامپوننت، فوکوس را می‌گیرد.

<!-- s:fca23dd943 -->
ویرایشگرهای دارای فوکوس، رویدادهای کلیدهای خود را مصرف می‌کنند، بنابراین تایپ کردن `1` هرگز میان‌بر سراسری را فعال نمی‌کند.

<!-- s:7c862ee98e -->
`<Input>`

<!-- s:fdde26d4d9 -->
ورودی تک‌خطی با ویرایش به سبک readline.

<!-- s:88cdcfc0ea -->
| Prop | توضیحات |
| :-- | :-- |
| `value` / `onChange` | مقدار کنترل‌شده |
| `onSubmit` | فراخوانی هنگام فشردن `Enter` |
| `placeholder` | نمایش هنگام خالی بودن |
| `mask` | نویسهٔ پوشاننده برای اطلاعات محرمانه |

<!-- s:995d41e175 -->
`<Textarea>`

<!-- s:cf370a7f95 -->
ویرایشگر متن چندخطی. کلید `Enter` متن را ارسال می‌کند و کلید `Shift+Enter` خط جدیدی اضافه می‌کند.

<!-- s:667b32bc16 -->
`<Select>`

<!-- s:1c8033c766 -->
فهرست گزینه‌های قابل کنترل با صفحه‌کلید، با جست‌وجوی تقریبی اختیاری.

<!-- s:70fe7d6c9b -->
| Prop | توضیحات |
| :-- | :-- |
| `options` | `{ value, label, hint?, badge? }[]` |
| `onChange` | فراخوانی هنگام فشردن `Enter` |
| `searchable` | فیلتر کردن گزینه‌ها با تایپ |

<!-- s:958ee46fb6 -->
`<Tabs>`

<!-- s:f61cb509c5 -->
نشانگر بدون فوکوس

<!-- s:f0552feed5 -->
وقتی صفحه فوکوس را از دست می‌دهد، نشانگرها ثابت می‌مانند و فریم‌ها متوقف می‌شوند تا بتوانید متن کنسول را انتخاب و کپی کنید.
