Text.js شامل کنترل‌های فرم، کادرهای گفت‌وگو و اعلان‌های گذرا است. هر کنترل در ترتیب پیمایش با کلید `Tab` قرار می‌گیرد و به کلید `Space` یا `Enter` پاسخ می‌دهد.

<!-- s:0c4878f82e -->
کنترل‌ها

<!-- s:920d5e74e5 -->
| کامپوننت | کلیدها | مقدار |
| :-- | :-- | :-- |
| `<Button>` | `↵` `Space` | `onPress` |
| `<Checkbox>` | `Space` `↵` | `checked` / `onChange` |
| `<Switch>` | `Space` `←` `→` | `checked` / `onChange` |
| `<RadioGroup>` | `↑` `↓` (یا `←` `→`) | `value` / `onChange` |
| `<Slider>` | `←` `→`، `Shift` ×5، `Home` `End` | `value` / `onChange` |

<!-- s:1c3c5ba8fd -->
همهٔ آن‌ها `autoFocus`، `focused`، `id` و `disabled` را می‌پذیرند. هر دو حالت کنترل‌شده و کنترل‌نشده (`defaultChecked`، `defaultValue`) کار می‌کنند.

<!-- s:0a2857b66b -->
دکمه‌ها

<!-- s:1981291f42 -->
مقدار `variant` یکی از `primary`، `secondary`، `ghost` یا `danger` است. فوکوس، دکمه را با رنگ تأکیدی پر می‌کند، بدون آنکه اندازهٔ آن تغییر کند.

<!-- s:56be122300 -->
`<Dialog>`

<!-- s:30940c6b5c -->
یک `<Modal>` با توضیح و ردیفی از کنش‌ها.

<!-- s:7cfec2b258 -->
`<Confirm>`

<!-- s:7e0406516a -->
بله یا خیر. کلیدهای `y` و `n` مستقیماً پاسخ می‌دهند؛ کلیدهای `←` `→` بین دکمه‌ها جابه‌جا می‌شوند. ویژگی `destructive` به دکمهٔ تأیید سبک می‌دهد و ابتدا فوکوس را روی «لغو» قرار می‌دهد.

<!-- s:fecae30a60 -->
اعلان‌های گذرا

<!-- s:76abda6137 -->
یک کامپوننت `<Toaster />` رندر کنید، سپس هوک `useToast()` را در هر جای همان ریشه فراخوانی کنید.

<!-- s:d5c6b1208e -->
| گزینه | توضیح |
| :-- | :-- |
| `duration` | میلی‌ثانیه (پیش‌فرض `4000`؛ اعلان‌های گذرای بارگذاری باقی می‌مانند) |
| `id` | استفادهٔ مجدد برای به‌روزرسانی اعلان گذرا در همان محل |
| `position` | در `<Toaster>`: `bottom-right` (پیش‌فرض)، `top-center`، … |
| `max` | در `<Toaster>`: تعداد قابل نمایش هم‌زمان (پیش‌فرض `3`) |

<!-- s:476f42f2b3 -->
اعلان‌های گذرا بالای مودال‌ها رندر می‌شوند و هرگز فوکوس را نمی‌گیرند.
