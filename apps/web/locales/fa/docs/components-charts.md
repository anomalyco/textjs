نمودارها با عناصر بلوکی رسم می‌شوند. میله‌ها از هشت سطح در هر سلول و خط‌ها از شبکه‌ای با 2×2 نقطه در هر سلول استفاده می‌کنند.

<!-- s:9bd48fe162 -->
`<LineChart>`

<!-- s:79abfce919 -->
نمودارهای خطی ماتریس نقطه‌ای با محور y و راهنمای نمودار.

<!-- s:977778a73f -->
| Prop | توضیحات |
| :-- | :-- |
| `series` | `{ data, label?, color? }[]` |
| `data` | شکل کوتاه برای یک سری |
| `height` | ردیف‌ها (پیش‌فرض `8`) |
| `min` / `max` | کران‌های ثابت (پیش‌فرض: داده‌ها) |
| `axis` | محور Y با برچسب‌های کمینه / بیشینه |
| `formatValue` | برچسب‌های محور (پیش‌فرض `1.2k`) |
| `marker` | `quadrant` (پیش‌فرض) یا `braille` |

<!-- s:3827b070cb -->
گزینهٔ `braille` در هر سلول 2×4 نقطه جای می‌دهد. از آن در ترمینال‌ها استفاده کنید: Menlo، فونت کنسول DevTools در macOS، نویسه‌های بریل ندارد و نویسه‌های جایگزین از یک سلول پهن‌ترند.

<!-- s:a1d8752203 -->
رنگ‌های پیش‌فرض سری‌ها `accent`، `success`، `warning`، `info` و `danger` هستند.

میله‌های افقی با برچسب‌ها و مقادیر هم‌تراز، با دقت یک‌هشتم سلول.

`<Sparkline>`

<!-- s:4bb495c66f -->

<!-- s:9b515e6ed1 -->
تابع `sparkline(values)` همان sparkline را به‌صورت رشته برمی‌گرداند.

`<Gradient>`

<!-- s:2239584d9f -->

<!-- s:22dc53f52a -->
`<Image>`

<!-- s:35a4098e50 -->
کنسول‌های Chromium و Firefox تصویر را به‌صورت یک اسپرایت پیکسلی رسم می‌کنند. پیکسل‌آرت (256 رنگ یا کمتر، بدون پیکسل‌های نیمه‌شفاف) تا 8 × 16 پیکسل در هر سلول و عکس‌ها تا 4 × 8 پیکسل را حفظ می‌کنند. Safari، ترمینال‌ها، نسخه‌های متن ساده و صفحه‌های دارای [`runtime = "server"`](/docs/server-rendering) نیم‌بلوک‌های `▀` دریافت می‌کنند: هر سلول دو پیکسل دارد، بالایی در پیش‌زمینه و پایینی در پس‌زمینه. برای رسم نیم‌بلوک‌ها در همه‌جا، مقدار `renderMode="halfblock"` را بدهید، همان‌طور که `<Image>` در نسخهٔ 1.3 عمل می‌کرد.

<!-- s:70bb4fc454 -->
| Prop | توضیحات |
| :-- | :-- |
| `src` | URL تصویر (فقط مرورگر) |
| `pixels` | RGBA خام به‌صورت `{ width, height, data }`، با 4 بایت برای هر پیکسل به‌ترتیب ردیف‌ها |
| `width` / `height` | عرض برحسب سلول و ارتفاع برحسب ردیف. برای حفظ نسبت ابعاد، یکی را بدهید؛ برای 1 × 2 پیکسل در هر سلول، هیچ‌کدام را ندهید (`src` حداکثر به 256 × 256 px تغییر اندازه می‌دهد) |
| `fit` | `contain` (پیش‌فرض)، `cover` یا `fill` |
| `alt` | متن نمایشی هنگام بارگیری `src` یا در صورت شکست آن |
| `renderMode` | `auto` (پیش‌فرض: اسپرایت در محل‌های پشتیبانی‌شده، نیم‌بلوک‌های `▀` در جاهای دیگر) یا `halfblock` |

<!-- s:c106665c64 -->
کامپوننت `<Image>` ویژگی‌های چیدمان را هم می‌پذیرد.

<!-- s:20dac26bff -->
بارگیری `src` از طریق canvas انجام می‌شود، پس تصاویر با مبدأ متفاوت به CORS نیاز دارند. ویژگی `pixels` در همه‌جا، از جمله ترمینال، RGBA خام می‌پذیرد.

<!-- s:4e3b06ef0e -->
در Chromium و Firefox نیز وقتی تصویر نتواند یک اسپرایت واحد باشد، به‌صورت نیم‌بلوک رسم می‌شود:

<!-- s:00d2e660eb -->
- دو تصویر کنار هم در ردیف‌های یکسان، مانند گالری.
- عکسی با متن در کنار آن. پیکسل‌آرت کنار متن همچنان اسپرایت می‌ماند.
- تصویری که یک کادر `overflow="hidden"` آن را برش داده یا کادر دیگری بخشی از آن را پوشانده است.
- پیکسل‌های شفاف روی متن یا روی بیش از یک رنگ پس‌زمینه.

<!-- s:dd4fefaac0 -->
`<Pixels>` (آزمایشی)

<!-- s:71eeeca05d -->
ماژول `@textjs/react/experimental` کامپوننت `<Pixels>` را برای بافرهای فریم زندهٔ `0xRRGGBBAA` مانند بازی‌ها، شبیه‌سازها و ویدئو صادر می‌کند. پیکسل‌های بسته‌بندی‌شده را درجا در `source.data` بنویسید و برای بازترسیم، مقدار `frame` را افزایش دهید.

<!-- s:2d12b69e81 -->
| Prop | توضیحات |
| :-- | :-- |
| `source` | `{ width, height, data: Uint32Array }` با ترتیب `0xRRGGBBAA` |
| `frame` | شمارندهٔ فریم؛ پس از تغییر `source.data` افزایش دهید |
| `width` / `height` | اندازهٔ کادر برحسب سلول و ردیف |
| `fit` | `contain` (پیش‌فرض) یا `fill` |
| `pixelAspect` | عرض نمایشی تقسیم بر ارتفاع یک پیکسل منبع (پیش‌فرض `1`) |
| `palette` | پالت اختیاری `PackedColor[]` برای کوانتیزه کردن رنگ‌ها بر اساس آن |
| `sample` | فیلتر جایگزین نیم‌بلوک: `nearest` (پیش‌فرض) یا `average` |
| `renderMode` | `auto` (پیش‌فرض: اسپرایت در محل‌های پشتیبانی‌شده، نیم‌بلوک‌های `▀` در جاهای دیگر) یا `halfblock` |

<!-- s:2164b4fe56 -->
گزینهٔ `renderMode="auto"` در Chromium و در Firefox مطابق قواعد سبک‌دهی کنسول آن (بدون بنچمارک)، یک اسپرایت پیکسلی رسم می‌کند و در Safari، ترمینال‌ها، نسخه‌های متن ساده و صفحه‌های دارای [`runtime = "server"`](/docs/server-rendering) از نیم‌بلوک‌های `▀` به‌عنوان جایگزین استفاده می‌کند. برای رسم نیم‌بلوک‌ها در همه‌جا، مقدار `renderMode="halfblock"` را بدهید.

<!-- s:5d2bbbc47b -->
برای رسم پیکسل‌ها بدون React، تابع `drawPixels` را از `@textjs/core/experimental` همراه با `DrawPixelsOptions`، `PixelSource`، `PixelFit`، `PixelSample`، `PixelRenderMode`، `PixelEncoding` و `PixelRect` وارد کنید. گزینهٔ `encoding: "rgba"` آن، بیش از 256 رنگ و آلفای نرم را برای تصاویر ثابت حفظ می‌کند و `fallback` هرجا که نمایش اسپرایت ممکن نباشد، سلول‌های دلخواه شما را رسم می‌کند. برای آگاهی از نحوهٔ نسخه‌بندی خروجی‌های آزمایشی، [تغییرات ناسازگار](/docs/support-policy#breaking-changes) را ببینید.
