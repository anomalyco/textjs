<!-- s:3bfcfe41ce -->
میان‌برها را یک بار با هوک `useKeymap` تعریف کنید. Text.js آن‌ها را مسیریابی می‌کند، در یک لایهٔ رویی `?` فهرست می‌کند، در پابرگ شما نمایش می‌دهد و امکان جست‌وجوی آن‌ها را در پالت فرمان فراهم می‌کند.

<!-- s:b084dfc727 -->
`useKeymap`

<!-- s:f944f97e4b -->
| نحو | معنی |
| :-- | :-- |
| `ctrl+k` | کلیدهای تغییردهنده: `ctrl` `alt` `shift` `meta` `mod` |
| `mod+k` | `⌘` یا `Ctrl`، هرکدام که نگه داشته شود |
| `j, down` | گزینه‌های جایگزین |
| `g g` | یک توالی (1 ثانیه فاصله بین کلیدها) |
| `G` | حرف بزرگ به معنی استفاده از `Shift` است |
| `?` | کلیدهای چاپ‌پذیر با نویسه تطبیق داده می‌شوند |

<!-- s:ef55b4b9de -->
مقدارها یک تابع رسیدگی یا یک اتصال کلید با فیلدهای `label`، `group`، `hint`، `disabled` و `noRepeat` هستند. اتصال‌های بدون برچسب کار می‌کنند اما در لایهٔ راهنما نمایش داده نمی‌شوند.

<!-- s:01f344cdbe -->
هوک `useKeymapBindings()` اتصال‌های برچسب‌داری را که در حال حاضر فعال هستند، برای استفاده در پابرگ‌ها و منوهای خودتان برمی‌گرداند.

<!-- s:dd8af5eb69 -->
نقشه‌های کلیدها از طریق هوک `useInput` اجرا می‌شوند، پس قواعد معمول برقرار است: ورودی‌های دارای تمرکز اولویت دارند، کلید منطبق انتشار رویداد را متوقف می‌کند و یک `<Modal>` باز، اتصال‌های بیرون از خود را غیرفعال می‌کند. برای تغییر این رفتار، مقدار `{ priority, global, isActive }` را ارسال کنید.

<!-- s:da19075700 -->
`<KeyHelp>`

<!-- s:907e2eedda -->
برای دیدن همهٔ اتصال‌های برچسب‌دار به‌صورت گروه‌بندی‌شده، کلید `?` را فشار دهید. این راهنما موارد فعال در محل باز شدن خود را فهرست می‌کند.

<!-- s:3cebb95bfc -->
`<KeyHints>` و `<StatusBar>`

<!-- s:04fa34bd49 -->
کامپوننت `<KeyHints />` اتصال‌های دارای `hint: true` یا موارد صریح `items` را نمایش می‌دهد. کامپوننت `<StatusBar>` یک پابرگ تک‌ردیفی با جایگاه `right` است.

<!-- s:b9ded39a0a -->
کامپوننت `<Kbd>mod+k</Kbd>` یک کلید را رندر می‌کند. تابع `formatKeys("ctrl+shift+p")` در macOS مقدار `⌃⇧P` و در محیط‌های دیگر مقدار `ctrl+shift+P` را می‌دهد.

<!-- s:8b6afd6178 -->
`<CommandPalette>`

<!-- s:65192cd436 -->
میان‌بر `Ctrl+K` (یا `Ctrl+P`) یک اجراگر با جست‌وجوی فازی برای فرمان‌های شما و همهٔ اتصال‌های برچسب‌دار باز می‌کند و حروف منطبق را برجسته نشان می‌دهد.

<!-- s:e88bab4eab -->
| Prop | توضیح |
| :-- | :-- |
| `commands` | `{ id, label, group?, keys?, keywords?, run }[]` |
| `keys` | میان‌بر باز کردن (پیش‌فرض `ctrl+k, ctrl+p`؛ مقدار `null` برای غیرفعال کردن) |
| `includeKeymap` | فهرست کردن اتصال‌های نقشهٔ کلیدها (پیش‌فرض `true`) |
| `open` / `onOpenChange` | کنترل‌شده |

<!-- s:ddd093fe85 -->
پالت پیش از اجرای فرمان بسته می‌شود، بنابراین فرمان‌ها می‌توانند پنجره‌های مودال خود را باز کنند. توابع `fuzzyMatch` و `fuzzyFilter` برای استفاده در فهرست‌های خودتان صادر می‌شوند.
