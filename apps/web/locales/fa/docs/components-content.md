این کامپوننت‌ها Markdown، کد، تفاوت‌ها و حروف بزرگ را روی شبکهٔ سلول‌ها رندر می‌کنند.

<!-- s:10d1e663ca -->
`<Markdown>`

<!-- s:842bba9c18 -->
Markdown سازگار با جریان داده. رشته‌ای رو به رشد به آن بدهید تا فریم پایدار بماند.

<!-- s:f6f3074d02 -->
`<Code>`

<!-- s:e3dec08834 -->
برجسته‌سازی نحوی برای `ts`، `tsx`، `json`، `bash`، `python`، `rust`، `go` و زبان‌های دیگر.

<!-- s:e75addc84e -->
| Prop | توضیحات |
| :-- | :-- |
| `language` | شناسهٔ زبان |
| `showLineNumbers` | حاشیهٔ شمارهٔ خطوط |
| `highlightLines` | خطوط برای رنگ‌آمیزی |
| `maxHeight` | برش با پانوشت «خطوط بیشتر» |

<!-- s:14338ded97 -->
`<Diff>`

<!-- s:ec6578a933 -->
تفاوت‌ها در قالب یکپارچه یا محاسبه‌شده از `{ before, after }`.

<!-- s:4fb43d4ba9 -->
`<Spinner>`

<!-- s:502520871a -->
گونه‌ها: `dots`، `pulse`، `matrix`، `line` و `braille` (برای ترمینال‌ها؛ Menlo نویسه‌های بریل ندارد). زمان‌سنج‌ها هنگام مکث متوقف می‌شوند.

<!-- s:b252598191 -->
`<AsciiFont>`

<!-- s:2cf13f8260 -->
حروف پیکسلی بزرگ برای عنوان‌ها.

<!-- s:d3f90f7b9b -->
برای گونهٔ 3 ردیفی از `font="compact"` استفاده کنید. برای حروف‌چینی figlet، یک فونت FIGlet از [`@textjs/font`](/docs/fonts)، مانند `font={slant}`، به آن بدهید.
