پوشه‌های `app/` مسیرها را تعریف می‌کنند و فایل‌های ویژه رابط کاربری هر مسیر را تعریف می‌کنند.

<!-- s:11f7d9178c -->
پوشه‌ها

<!-- s:8bda4d61c2 -->
| پوشه | کاربرد |
| :-- | :-- |
| `app` | مسیرها، چیدمان‌ها و کنترل‌گرهای مسیر |
| `lib` | ماژول‌های مشترک، بدون مسیریابی |
| `public` | منابع ایستا |

<!-- s:25756fa68d -->
فایل‌های مسیریابی

<!-- s:8d1e739d99 -->
| فایل | کاربرد |
| :-- | :-- |
| `layout.tsx` | رابط کاربری مشترک برای یک بخش |
| `page.tsx` | صفحه‌ای با قابلیت مسیریابی |
| `loading.tsx` | جایگزین Suspense |
| `error.tsx` | مرز خطا |
| `not-found.tsx` | نشانی‌های URL بدون تطابق |
| `route.ts` | نقطهٔ پایانی API |

text.config.ts

<!-- s:1baaf058bb -->
| گزینه | پیش‌فرض | توضیح |
| :-- | :-- | :-- |
| `title` | `""` | عنوان صفحه و FocusPad |
| `viewport` | متناسب با کنسول، در غیر این صورت `120×36` | `responsive` (پیش‌فرض `true`)، مقدار جایگزین `width × height`، `theme` |
| `hints` | `[]` | دو یا سه کلید که روی FocusPad صفحه نمایش داده می‌شوند |
| `action` | `press <first hint>` | کاری که پس از دریافت فوکوس باید انجام دهید، مثلاً `"type a prompt"` |
| `devIndicators` | `true` | پوشش توسعه در کنسول (`[▼]`) |
| `focusHint` | `true` | نمایش «برای استفاده از صفحه‌کلید روی صفحه کلیک کنید» روی آخرین ردیف کنسول، وقتی صفحه فوکوس ندارد |
| `rewrites` | `[]` | بازنویسی‌ها و پراکسی‌ها |
| `ansi` | `{ cols: 80, rows: 24 }` | اندازه فریم برای [curl و کلاینت‌های ترمینال](/docs/curl)، یا `false` برای ارائه HTML به آن‌ها |
| `embed` | `false` | ساخت برنامه برای افزودن به سایت‌های دیگر با یک تگ اسکریپت ([جاسازی](/docs/embedding)، آزمایشی) |
