با ابزارهای `className` یا پراپ‌های نوع‌دار به کامپوننت‌ها استایل بدهید. برنامه‌های Text.js شیوه‌نامه ندارند.

<!-- s:e0ac1db626 -->
ابزارها

<!-- s:2de571e2bf -->
ویژگی `className` ابزارهایی به سبک Tailwind می‌پذیرد. هر واحد برابر با یک سلول است.

<!-- s:785b2c3db0 -->
| دسته | نمونه‌ها |
| :-- | :-- |
| چیدمان | `flex-row` `grow` `items-center` `gap-1` |
| فاصله‌گذاری | `p-1` `px-2` `mt-1` |
| حاشیه‌ها | `border` `rounded` `border-accent` |
| رنگ | `bg-surface` `text-muted` |

<!-- s:0b98e5506b -->
پراپ‌های نوع‌دار

<!-- s:4963259a42 -->
هر ابزار یک پراپ دارد. پراپ‌ها بر ویژگی `className` اولویت دارند.

<!-- s:15a3834a24 -->
رنگ‌ها

<!-- s:d333dad27a -->
از مقادیر هگز، نام‌های Tailwind یا توکن‌های پوسته مانند `fg`، `muted`، `surface`، `accent`، `success` و `danger` استفاده کنید. توکن‌ها از پوستهٔ فعال پیروی می‌کنند.

<!-- s:087abce968 -->
پوسته‌ها

<!-- s:abba2a3188 -->
پنج پیش‌تنظیم داخلی ارائه می‌شود: `geistDark`، `geistLight`، `opencodeDark`، `tokyoNight` و `amberCrt`.
