היום אנחנו משחררים את Text.js 1.0, פריימוורק המסוף לווב.

<!-- s:e4787165f5 -->
Text.js מרנדר אפליקציות React 19 בתוך המסוף של Chrome DevTools, עם layout, ניתוב, מיקוד, קלט, טפסים, תרשימים ו-Markdown בהזרמה שמצוירים באמצעות `console.log`.

<!-- s:48b184a262 -->
מה כלול ב-1.0

<!-- s:7f7f2a9a76 -->
- **App Router.** `layout.tsx`, `page.tsx`, `[param]`, `loading.tsx`, `error.tsx`, `not-found.tsx` ו-`api/*/route.ts`, מסונכרנים עם `window.location`. הוא פועל לפי המוסכמות של App Router ב-Next.js.
- **Turbolog.** Yoga flexbox מסדר רשת תאים, `CellBuffer` המבוסס על מערך מטיפוס מוגדר מחזיק אותה, ומקודד אורכי רצף הופך אותה לקריאת `console.log(format, ...css)` יחידה. פריימים ללא פעילות אינם מבצעים קריאות למסוף.
- **ערכת רכיבים.** `Box`, `Text`, `ScrollBox`, `Input`, `Select`, `Tabs`, `Markdown`, `Diff`, רכיב `List` עם וירטואליזציה, `Table`, `Tree`, תרשימים, תיבות דו-שיח, התראות צפות ולוח פקודות `Ctrl+K` מתוך `useKeymap`.
- **הוספת פריימים לסוף.** פריימים מתווספים מתחת לפריים הקודם, כך שהמסוף לא מהבהב כשהוא ריק בין פריימים. פרטים נוספים ב-[Turbolog: ביטול ההבהוב](/blog/turbolog-eliminating-the-flash).
- **טקסט מימין לשמאל.** עברית וערבית מרונדרות בסדר חזותי עם עיצוב אותיות בערבית, באמצעות מימוש של UAX #9 שעובר את כל 770,241 מקרי הבדיקה של `BidiTest.txt`. ראו [טקסט מימין לשמאל במסוף](/blog/right-to-left-text).
- **מסוף רספונסיבי.** Text.js מתאים את עצמו לחלונית DevTools המעוגנת, כולל שינוי קנה המידה של הדף וסרגל כלים שנגלל לשורה נוספת. כשהחלונית אינה מעוגנת, הוא משתמש ב-`120×36` כברירת מחדל.
- **`text run`.** אותו יישום App Router מרונדר בטרמינל אמיתי.
- **כלים לסוכנים ולעורכים.** `text mcp` מגיש את היישום לסוכני קוד באמצעות Model Context Protocol, ותוסף DevTools של Text.js מוסיף חלונית לצד "מסוף". גם `eslint-plugin-textjs` ותוסף ל-VS Code הם חלק מ-1.0.

שינוי שם אחד

<!-- s:b47aa37902 -->
חבילת הפריימוורק נקראת כעת `@textjs/next`. השם `textjs` היה תפוס ב-npm. יש לעדכן את הייבואים:

<!-- s:e4005009f1 -->
**עדכון, 1.0.2:** החבילה נקראת כעת `@textjs/app`, והשימוש ב-`@textjs/next` הוצא משימוש. כדי לעבור, יש להריץ `bun remove @textjs/next && bun add @textjs/app` ולייבא מתוך `@textjs/app`.

התנסות

<!-- s:aeb9cc2b5d -->
