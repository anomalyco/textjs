טעינה בעקבות כוונה להשתמש במסוף (ניסיוני)

<!-- s:97014ecad1 -->
`@textjs/core/experimental` מייצא את `onConsoleIntent` עבור דפים שמורידים את אפליקציית המסוף שלהם רק כשמבקרים רוצים להשתמש בה. הוא קורא לפונקציה שהוגדרה פעם אחת, עם הסיבה:

<!-- s:444b1ebdd7 -->
| סיבה | מתי |
| :-- | :-- |
| `dock` | DevTools מעוגן בעת טעינת הדף, או מעוגן בהמשך. Text.js מזהה זאת לפי גודל החלון |
| `shortcut` | מתבצעת לחיצה על F12 או Ctrl+Shift+J, I, C או K, או על ⌘⌥J, I, C או K ב-Mac. הדפדפן עדיין פותח את DevTools |
| `engage` | לחיצה ראשית על אלמנט שתואם ל-`engageSelector`, לחיצה על Enter או Space בכפתור `[data-textjs-engage]`, או בחירת גודל ב-`<ViewportControl>` לפני הפעלת האפליקציה. לחיצות על קישורים, כפתורים ושדות טופס בתוך אלמנט תואם אינן נספרות, אלא אם גם להם יש `data-textjs-engage` |
| `session` | אחד מהאירועים שלעיל כבר התרחש בכרטיסייה הזו, ולכן טעינה מחדש מפעילה את האפליקציה מיד |
| `manual` | בוצעה קריאה ל-`trigger()` על אובייקט השליטה שהוחזר |

<!-- s:894b97fac4 -->
פתיחת DevTools בחלון נפרד דרך תפריט הדפדפן אינה משתקפת בגודל החלון. במקרה הזה, מבקרים מפעילים את האפליקציה דרך אלמנט `engage`, ו-`session` ממשיך להפעיל אותה בטעינות מחדש באותה כרטיסייה.

<!-- s:06cdcf713e -->
במסכי מגע שום אירוע לא מופעל אוטומטית. יש לקרוא ל-`trigger()` מפקד שהוגדר באפליקציה.

<!-- s:d7006796c2 -->
| אפשרות | תיאור |
| :-- | :-- |
| `engageSelector` | אלמנטים שמפעילים את האפליקציה בלחיצה (ברירת המחדל היא `[data-textjs-engage], [data-textjs-focus-pad], text-console`). הערך `false` אינו מוסיף מאזינים |
| `persist` | שמירת הכוונה עבור הכרטיסייה ב-`sessionStorage` תחת `CONSOLE_INTENT_KEY` (ברירת המחדל היא `true`) |
| `prefetch` | קריאה לכל היותר פעם אחת, כשהסמן או המיקוד נכנסים לאלמנט `engageSelector` |
| `idlePrefetch` | קריאה ל-`prefetch` גם כשהדפדפן במצב סרק אחרי `load` (ברירת המחדל היא `false`) |

<!-- s:4460da3205 -->
`prefetch` לעולם אינו רץ במסכי מגע, כשחיסכון בנתונים מופעל, או בחיבורים איטיים יותר מ-4G. הפונקציה `canPrefetchConsole()` מחזירה את תוצאת אותה בדיקה. המתודה `dispose()` של אובייקט השליטה מסירה את כל המאזינים.

<!-- s:9128a9d98f -->
`<ViewportControl>` פועל לפני ששורש המסוף קיים. בחירת גודל שומרת אותו, מפעילה את `engage` כדי ש-`onConsoleIntent` יפעיל את האפליקציה, ומחילה את הגודל ברגע ש-`root` מוגדר. מידע על ניהול הגרסאות של יצואים ניסיוניים מופיע ב[שינויים שוברי תאימות](/docs/support-policy#breaking-changes).
