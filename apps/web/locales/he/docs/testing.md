<!-- s:9bc71b1ad2 -->

רינדור

<!-- s:fc969a7928 -->
| מתודה | תיאור |
| :-- | :-- |
| `render(el, { cols, rows, theme })` | הרכבה מחוץ למסך (ברירת מחדל 80×24) |
| `lastFrame()` | הפריים כטקסט רגיל |
| `lines()` | הפריים כמערך שורות |
| `frames` | כל פריים ייחודי עד כה |
| `toAnsi()` | ANSI בצבע מלא, לצילומי מצב |
| `cell(x, y)` | `{ char, fg, bg, attrs }` |
| `locate(text)` | `{ x, y }` של ההתאמה הראשונה |
| `rerender(el)` / `unmount()` | עדכון או פירוק |
