יש להגדיר קיצורי מקשים פעם אחת עם `useKeymap`. Text.js מנתב אותם, מציג אותם בשכבת `?`, מציג אותם בכותרת התחתונה ומאפשר לחפש אותם בלוח פקודות.

<!-- s:b084dfc727 -->
`useKeymap`

<!-- s:f944f97e4b -->
| תחביר | משמעות |
| :-- | :-- |
| `ctrl+k` | מקשי שינוי: `ctrl` `alt` `shift` `meta` `mod` |
| `mod+k` | `⌘` או `Ctrl`, לפי המקש המוחזק |
| `j, down` | חלופות |
| `g g` | רצף (1 שנייה בין מקשים) |
| `G` | אות גדולה מציינת `Shift` |
| `?` | מקשים הניתנים להדפסה מותאמים לפי התו |

<!-- s:ef55b4b9de -->
הערכים הם פונקציית טיפול, או שיוך מקשים עם `label`, `group`, `hint`, `disabled` ו-`noRepeat`. שיוכים ללא תווית פועלים אך אינם מופיעים בשכבת העזרה.

<!-- s:01f344cdbe -->
`useKeymapBindings()` מחזיר את השיוכים בעלי התווית שפעילים כעת, לשימוש בכותרות תחתונות ובתפריטים משלכם.

<!-- s:dd8af5eb69 -->
מפות מקשים פועלות דרך `useInput`, ולכן הכללים הרגילים חלים: שדות קלט במיקוד מקבלים עדיפות, מקש שנמצאה לו התאמה עוצר את הפצת האירוע, ורכיב `<Modal>` פתוח משבית שיוכים מחוץ לו. כדי לשנות זאת, יש להעביר `{ priority, global, isActive }`.

<!-- s:da19075700 -->
`<KeyHelp>`

<!-- s:907e2eedda -->
יש ללחוץ על `?` להצגת כל השיוכים בעלי התווית, לפי קבוצות. הרשימה מציגה את השיוכים הפעילים במקום שבו נפתחה.

<!-- s:3cebb95bfc -->
`<KeyHints>` ו-`<StatusBar>`

<!-- s:04fa34bd49 -->
`<KeyHints />` מציג שיוכים המסומנים ב-`hint: true`, או `items` מפורשים. `<StatusBar>` הוא כותרת תחתונה בת שורה אחת עם אזור `right`.

<!-- s:b9ded39a0a -->
`<Kbd>mod+k</Kbd>` מרנדר מקש יחיד. `formatKeys("ctrl+shift+p")` מחזיר `⌃⇧P` ב-macOS ו-`ctrl+shift+P` במערכות אחרות.

<!-- s:8b6afd6178 -->
`<CommandPalette>`

<!-- s:65192cd436 -->
`Ctrl+K` (או `Ctrl+P`) פותח ממשק הפעלה עם חיפוש מקורב בפקודות ובכל השיוכים בעלי התווית, עם הדגשה של האותיות התואמות.

<!-- s:e88bab4eab -->
| Prop | תיאור |
| :-- | :-- |
| `commands` | `{ id, label, group?, keys?, keywords?, run }[]` |
| `keys` | קיצור מקשים לפתיחה (ברירת המחדל היא `ctrl+k, ctrl+p`; להשבתה יש להשתמש ב-`null`) |
| `includeKeymap` | הצגת שיוכי מפת המקשים (ברירת המחדל היא `true`) |
| `open` / `onOpenChange` | מצב מבוקר |

<!-- s:ddd093fe85 -->
לוח הפקודות נסגר לפני שהוא מפעיל פקודה, כך שפקודות יכולות לפתוח חלונות מודאליים משלהן. הספרייה מייצאת את `fuzzyMatch` ואת `fuzzyFilter` לשימוש ברשימות משלכם.
