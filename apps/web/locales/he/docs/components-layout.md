רכיבי הבסיס האלה מסדרים את רשת התאים באמצעות Yoga flexbox.

<!-- s:00be928124 -->
`<Box>`

<!-- s:cdedc6ec73 -->
מכל ה-layout.

<!-- s:b2726c7ef5 -->
| Prop | תיאור |
| :-- | :-- |
| `className` | מחלקות עזר לתאים |
| `border` | `single` `rounded` `double` `heavy` `dashed` |
| `title` | טקסט המשובץ במסגרת העליונה |
| `bg` / `fg` | צבע הרקע והטקסט |
| `overflow` | `hidden` או `scroll` |

<!-- s:a83221d138 -->
`<Text>`

<!-- s:ea0876c03f -->
טקסט בתוך השורה. `<Text>` מקונן הופך למקטעי span מעוצבים.

<!-- s:d078a242d3 -->
| Prop | תיאור |
| :-- | :-- |
| `color` | צבע הטקסט |
| `bold` `italic` `underline` `dim` | מאפיינים |
| `wrap` | `wrap` `nowrap` `truncate-end` |

<!-- s:e9a9218253 -->
`<ScrollBox>`

<!-- s:51162fc3b2 -->
עמודה נגללת. `stickyScroll` מצמיד את הגלילה לתחתית ככל שהתוכן גדל.

<!-- s:9029b4d81b -->
`<Modal>`

<!-- s:3804dec517 -->
שכבה ממורכזת שמעמעמת את מה שמתחתיה ומשאירה את המיקוד בתוכה.

<!-- s:7a128a8b11 -->
Spacer, Divider ו-Badge

<!-- s:72e5d35050 -->
כלי עזר ל-layout

<!-- s:e76299d593 -->
קיצורים לסידורי flex נפוצים.

<!-- s:0f066fb217 -->
`<SplitPane>`

<!-- s:20cd99b8e7 -->
שתי חלוניות ומפריד. עם `resizable`, המפריד מצטרף לסדר ה-`Tab` והמקשים `←` `→` משנים את מיקומו (`Shift` לתזוזה של חמישה תאים).

<!-- s:2143924860 -->
`size` הוא שבר (`0.3`) או מספר תאים (`24`). `direction="column"` מסדר את החלוניות זו מעל זו.
