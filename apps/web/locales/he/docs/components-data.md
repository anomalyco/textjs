`<List>`, `<Table>` ו-`<Tree>` מציגים מערכי נתונים גדולים. רק שורות גלויות עוברות רינדור.

<!-- s:44ffd1d0a7 -->
ניווט

<!-- s:e3dca4574c -->
`<List>`, `<Table>` ו-`<Tree>` משתמשים באותו מודל מקלדת.

<!-- s:cdac0643be -->
| מקשים | פעולה |
| :-- | :-- |
| `↑` `↓` / `j` `k` | תנועה |
| `PgUp` `PgDn`, `Ctrl+U` `Ctrl+D` | מעבר עמוד, חצי עמוד |
| `Home` `End` / `g` `G` | מעבר לראשון, לאחרון |
| `↵` | `onSelect` |
| גלגלת | הזזת הסמן |

<!-- s:1c65c42a4d -->
הם ממלאים את רכיב האב כברירת מחדל. יש להעביר `height` למספר קבוע של שורות.

<!-- s:3a828804bb -->
`<List>`

<!-- s:2603a57dc8 -->
רשימה וירטואלית. גובה כל שורה הוא תא אחד.

<!-- s:3408e68b29 -->
| Prop | תיאור |
| :-- | :-- |
| `items` | מערך כלשהו |
| `renderItem` | `(item, { highlighted, focused }) => ReactNode` |
| `isItemDisabled` | דילוג של הסמן על הפריט |
| `height` | שורות גלויות (ברירת מחדל: מילוי) |
| `highlightedIndex` / `onHighlight` | סמן מבוקר |
| `vimKeys` | `j` `k` `g` `G` (ברירת מחדל `true`) |

<!-- s:55759482eb -->
`<Table>`

<!-- s:ff77c49577 -->
העמודות חולקות את הרוחב הנותר, אלא אם מוגדר להן `width`. הכותרות והתאים משתמשים באותם כללי flex, ולכן הם תמיד מיושרים.

<!-- s:e9719839f0 -->
| שדה עמודה | תיאור |
| :-- | :-- |
| `key` | מזהה ומנגנון גישה לערך כברירת מחדל |
| `width` / `grow` | מספר תאים קבוע או חלק מהרוחב הנותר |
| `align` | `left` `right` `center` |
| `value` | ערך לתצוגה ולמיון |
| `render` | תוכן תא מותאם אישית |
| `compare` | מיון מותאם אישית |

<!-- s:045ee40857 -->
מיון

<!-- s:d04de39344 -->
עם `sortable`, יש ללחוץ על מספר העמודה כדי למיין לפיה (ושוב כדי להפוך את הכיוון), על `s` כדי לעבור בין העמודות ועל `S` כדי להפוך את הכיוון. המיון יציב. לשליטה בו יש להשתמש ב-`sort` וב-`onSortChange`.

<!-- s:6d625a19ed -->
בחירה

<!-- s:2132bc20a2 -->
`selectionMode="multiple"` מוסיף עמודת סימון; `Space` משנה את מצב הבחירה של השורה המודגשת. לשליטה בבחירה יש להשתמש ב-`selectedKeys` וב-`onSelectionChange`, וב-`getRowKey` למפתחות יציבים.

<!-- s:3bd95f58e2 -->
`<Tree>`

<!-- s:ec4c582ab8 -->
עץ שניתן להרחיב עם קווי עזר.

<!-- s:eeb148154f -->
`→` מרחיב ענף או נכנס אליו. `←` מכווץ או קופץ לרכיב האב. `Space` מחליף בין הרחבה לכיווץ. `flattenTree(data, expanded)` חושף את השורות הגלויות אם נדרש מנגנון רינדור משלכם.
