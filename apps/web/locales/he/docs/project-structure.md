text.config.ts

<!-- s:144c0672ce -->
| אפשרות | ברירת מחדל | תיאור |
| :-- | :-- | :-- |
| `title` | `""` | כותרת הדף וה-FocusPad |
| `viewport` | התאמה למסוף, אחרת `120×36` | `responsive` (ברירת מחדל `true`), גודל גיבוי `width × height`, `theme` |
| `hints` | `[]` | שניים או שלושה מקשים המוצגים ב-FocusPad של הדף |
| `action` | `press <first hint>` | הפעולה לביצוע לאחר קבלת המיקוד, למשל `"type a prompt"` |
| `devIndicators` | `true` | שכבת פיתוח במסוף (`[▼]`) |
| `focusHint` | `true` | "ללחוץ על הדף כדי להשתמש במקלדת" מעל השורה האחרונה במסוף כשהדף אינו ממוקד |
| `rewrites` | `[]` | שכתובי כתובות ושרתי פרוקסי |
| `ansi` | `{ cols: 80, rows: 24 }` | גודל הפריים עבור [curl ולקוחות טרמינל](/docs/curl), או `false` כדי להגיש להם HTML |
