<!-- s:19aa9fdfd3 -->
| מצב | עדכונים | משך התמיכה |
| :-- | :-- | :-- |
| פעילה | תכונות, תיקונים, תיקוני אבטחה | עד הגרסה הראשית הבאה |

| סוף חיי התמיכה | ללא עדכונים | — |

<!-- s:d5987f6ecf -->
רק גרסת המשנה האחרונה של כל גרסה ראשית מקבלת תיקונים: עם שחרור `1.5.0`, התיקונים מתווספים ל-`1.5.x`, ולא ל-`1.4.x`. עם שחרור `2.0.0`, גרסת המשנה האחרונה של `1.x` הופכת לסדרת LTS בתחזוקה ומתפרסמת תחת תגיות ההפצה `lts` ו-`v1-lts`.

תיקונים ב-LTS

<!-- s:043b92b499 -->
- פרצות אבטחה בחבילות Text.js
- קריסות, אובדן נתונים וכשלי בנייה שאין להם פתרון עוקף
- תאימות לגרסאות חדשות של Chrome, Edge, Firefox ו-Safari שמשבשות את הרינדור במסוף
- תאימות לסביבות ריצה וליעדי פריסה נתמכים

<!-- s:e01d1121d2 -->
תכונות חדשות, שיפורי ביצועים ושינויים במבנה הקוד מתווספים לסדרה הפעילה בלבד.

<!-- s:d1c69ba9bc -->
שינויים שוברי תאימות

<!-- s:82596fcd52 -->
הפריטים הבאים משתנים רק בגרסה ראשית, לאחר אזהרה על הוצאה משימוש בגרסת משנה אחת לפחות:

<!-- s:4ca9fd7807 -->
- ייצואים ציבוריים של `@textjs/app`, `@textjs/react` ו-`@textjs/core`, כולל `@textjs/app/server` ו-`@textjs/app/cache`
- אפשרויות `text.config.ts`, פקודות ודגלים של כלי שורת הפקודה `text`
- מוסכמות קבצים בתיקייה `app/`, בקובץ `middleware.ts` ובהגדרות מקטעי נתיב
- מבני הפלט של מתאמים (`.vercel/output`, `_worker.js`, `dist/server.js`)

<!-- s:883f3eeb26 -->
לא נכללים: ממשקי API המסומנים כניסיוניים או כ-`unstable_`, כולל כל מה שתחת `@textjs/core/experimental`, `@textjs/react/experimental` ו-`@textjs/app/experimental` (הם עשויים להשתנות בגרסת משנה, עם הערות ביומן השינויים), פרטים פנימיים כגון `@textjs/core/internal`, כותרות `x-middleware-*` ומטא-נתונים של הבנייה בתיקייה `.text/`, גרסאות canary, ומחרוזות הפורמט וה-CSS המדויקים של `console.log` (הפריימים נשארים זהים מבחינה חזותית; הקידוד שלהם עשוי להיות מהיר יותר).

תמיכה בסביבות ריצה

<!-- s:30122ce1bb -->
| סביבת ריצה | גרסאות נתמכות |
| :-- | :-- |
| DevTools של Chrome / Edge | הגרסה היציבה הנוכחית ושתי הגרסאות היציבות הקודמות |
| המסופים של Firefox ו-Safari | הגרסה היציבה הנוכחית |
| Node.js | גרסאות LTS פעילות ובתחזוקה (`text start`, פונקציות Vercel) |
| Bun | גרסת 1.x האחרונה |
| Cloudflare Workers | `compatibility_date` בערך 2025-01-01 ואילך, `nodejs_compat` |

<!-- s:509c18536b -->
הפסקת התמיכה בגרסת סביבת ריצה שהגיעה לסוף חיי התמיכה שלה אינה שינוי שובר תאימות.
