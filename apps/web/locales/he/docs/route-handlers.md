מטפלי נתיבים מגדירים נקודות קצה של API בספרייה `app` באמצעות ממשקי ה-API של Web, ‏`Request` ו-`Response`.

<!-- s:895d99d1b5 -->
מוסכמות

<!-- s:ac1d1b9fcb -->
יש לייצא את `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD` או `OPTIONS`. המטפלים רצים ב-`text dev`, ב-`text start` ובכל [מתאם פריסה](/docs/deploying) לשרת, אחרי [middleware](/docs/middleware). לשמירת מטפלי `GET` במטמון יש להשתמש ב[תצורת מקטע נתיב](/docs/caching).

<!-- s:53eeba0ff3 -->
מטפלים דינמיים

<!-- s:bfa759b36e -->
ערכי `params` עוברים פענוח. נתיב עם לוכסן או לוכסן הפוך מקודד (`%2F`, `%5C`) מקבל `400`, ולכן יש להעביר מזהים שעשויים להכיל `/` בפרמטר שאילתה או לקודד אותם כ-base64url.
