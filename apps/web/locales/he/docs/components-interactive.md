שדות הקלט האלה מופעלים באמצעות המקלדת ומנהלים את המיקוד שלהם בעצמם.

<!-- s:1d0d345c65 -->
מיקוד

<!-- s:bc06482880 -->
`Tab` ו-`Shift+Tab` מעבירים את המיקוד במחזוריות. `autoFocus` מקבל מיקוד בעת הטעינה של הרכיב.

<!-- s:fca23dd943 -->
עורכים ממוקדים לוכדים את הקשות המקשים שלהם, כך שהקלדת `1` לעולם אינה מפעילה קיצור מקשים גלובלי.

<!-- s:7c862ee98e -->
`<Input>`

<!-- s:fdde26d4d9 -->
שדה קלט בשורה אחת עם עריכה בסגנון readline.

<!-- s:88cdcfc0ea -->
| Prop | תיאור |
| :-- | :-- |
| `value` / `onChange` | ערך מבוקר |
| `onSubmit` | נקרא בלחיצה על `Enter` |
| `placeholder` | מוצג כשהשדה ריק |
| `mask` | תו מיסוך לערכים סודיים |

<!-- s:995d41e175 -->
`<Textarea>`

<!-- s:cf370a7f95 -->
עורך טקסט מרובה שורות. `Enter` שולח, `Shift+Enter` מוסיף שורה חדשה.

<!-- s:667b32bc16 -->
`<Select>`

<!-- s:1c8033c766 -->
רשימת אפשרויות לניווט במקלדת עם חיפוש מקורב אופציונלי.

<!-- s:70fe7d6c9b -->
| Prop | תיאור |
| :-- | :-- |
| `options` | `{ value, label, hint?, badge? }[]` |
| `onChange` | נקרא בלחיצה על `Enter` |
| `searchable` | הקלדה מסננת אפשרויות |

<!-- s:958ee46fb6 -->
`<Tabs>`

<!-- s:f61cb509c5 -->
סמן ללא מיקוד

<!-- s:f0552feed5 -->
כשהדף מאבד מיקוד, הסמנים קופאים והפריימים נעצרים, כך שאפשר לבחור ולהעתיק טקסט מהמסוף.
