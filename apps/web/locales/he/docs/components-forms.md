Text.js כולל פקדי טפסים, תיבות דו-שיח והודעות צצות. כל פקד מצטרף לסדר הניווט של `Tab` ומגיב ל-`Space` או ל-`Enter`.

<!-- s:0c4878f82e -->
פקדים

<!-- s:920d5e74e5 -->
| רכיב | מקשים | ערך |
| :-- | :-- | :-- |
| `<Button>` | `↵` `Space` | `onPress` |
| `<Checkbox>` | `Space` `↵` | `checked` / `onChange` |
| `<Switch>` | `Space` `←` `→` | `checked` / `onChange` |
| `<RadioGroup>` | `↑` `↓` (או `←` `→`) | `value` / `onChange` |
| `<Slider>` | `←` `→`, `Shift` ×5, `Home` `End` | `value` / `onChange` |

<!-- s:1c3c5ba8fd -->
כולם מקבלים `autoFocus`, `focused`, `id` ו-`disabled`. הם פועלים גם במצב מבוקר וגם במצב לא מבוקר (`defaultChecked`, `defaultValue`).

<!-- s:0a2857b66b -->
כפתורים

<!-- s:1981291f42 -->
הערך של `variant` הוא `primary`, `secondary`, `ghost` או `danger`. המיקוד ממלא את הכפתור בצבע ההדגשה בלי לשנות את גודלו.

<!-- s:56be122300 -->
`<Dialog>`

<!-- s:30940c6b5c -->
רכיב `<Modal>` עם תיאור ושורת פעולות.

<!-- s:7cfec2b258 -->
`<Confirm>`

<!-- s:7e0406516a -->
כן או לא. `y` ו-`n` משיבים ישירות; `←` `→` מעבירים בין הכפתורים. `destructive` מעצב את כפתור האישור וממקד תחילה את כפתור הביטול.

הודעות צצות

<!-- s:76abda6137 -->
יש לרנדר רכיב `<Toaster />` אחד, ואז לקרוא ל-`useToast()` מכל מקום באותו שורש.

<!-- s:d5c6b1208e -->
| אפשרות | תיאור |
| :-- | :-- |
| `duration` | אלפיות שנייה (ברירת מחדל `4000`; הודעות טעינה נשארות) |
| `id` | שימוש חוזר לעדכון הודעה צצה במקומה |
| `position` | ברכיב `<Toaster>`: `bottom-right` (ברירת מחדל), `top-center`, … |
| `max` | ברכיב `<Toaster>`: מספר ההודעות הגלויות בו-זמנית (ברירת מחדל `3`) |

<!-- s:476f42f2b3 -->
הודעות צצות מרונדרות מעל תיבות מודאליות ולעולם אינן מקבלות מיקוד.
