Configurações do console

<!-- s:803094bd72 -->
Desative **Preservar registro** nas configurações do console. Text.js anexa uma mensagem por quadro e limpa o console para liberar quadros antigos. Com “Preservar registro” ativado, o DevTools ignora a limpeza e os quadros antigos se acumulam.
