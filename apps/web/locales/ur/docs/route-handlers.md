روٹ ہینڈلرز Web کی `Request` اور `Response` APIs کے ساتھ `app` ڈائریکٹری میں API اینڈ پوائنٹس متعین کرتے ہیں۔

<!-- s:895d99d1b5 -->
کنونشن

<!-- s:ac1d1b9fcb -->
`GET`، `POST`، `PUT`، `PATCH`، `DELETE`، `HEAD` یا `OPTIONS` ایکسپورٹ کریں۔ ہینڈلرز [مڈل ویئر](/docs/middleware) کے بعد `text dev`، `text start` اور ہر سرور [ڈیپلائے اڈاپٹر](/docs/deploying) پر چلتے ہیں۔ [روٹ سیگمنٹ کی ترتیب](/docs/caching) کے ساتھ `GET` ہینڈلرز کو کیش کریں۔

<!-- s:53eeba0ff3 -->
ڈائنامک ہینڈلرز

<!-- s:bfa759b36e -->
`params` کی ویلیوز ڈی کوڈ ہوتی ہیں۔ ان کوڈ شدہ سلیش یا بیک سلیش (`%2F`، `%5C`) والے پاتھ کو `400` ملتا ہے، اس لیے ایسی IDs جن میں `/` ہو سکتا ہے، کوئری پیرامیٹر میں پاس کریں یا انہیں base64url کے طور پر ان کوڈ کریں۔
