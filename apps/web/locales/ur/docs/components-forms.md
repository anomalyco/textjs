Text.js میں فارم کنٹرولز، ڈائیلاگز اور ٹوسٹس شامل ہیں۔ ہر کنٹرول `Tab` کی ترتیب میں شامل ہوتا ہے اور `Space` یا `Enter` پر ردعمل دیتا ہے۔

<!-- s:0c4878f82e -->
کنٹرولز

<!-- s:920d5e74e5 -->
| کمپوننٹ | کیز | ویلیو |
| :-- | :-- | :-- |
| `<Button>` | `↵` `Space` | `onPress` |
| `<Checkbox>` | `Space` `↵` | `checked` / `onChange` |
| `<Switch>` | `Space` `←` `→` | `checked` / `onChange` |
| `<RadioGroup>` | `↑` `↓` (یا `←` `→`) | `value` / `onChange` |
| `<Slider>` | `←` `→`، `Shift` ×5، `Home` `End` | `value` / `onChange` |

<!-- s:1c3c5ba8fd -->
یہ سب `autoFocus`، `focused`، `id` اور `disabled` قبول کرتے ہیں۔ کنٹرولڈ اور اَن کنٹرولڈ (`defaultChecked`، `defaultValue`) دونوں کام کرتے ہیں۔

<!-- s:0a2857b66b -->
بٹنز

<!-- s:1981291f42 -->
`variant` کی ویلیو `primary`، `secondary`، `ghost` یا `danger` ہوتی ہے۔ فوکس بٹن کا سائز بدلے بغیر اسے ایکسنٹ رنگ سے بھر دیتا ہے۔

<!-- s:56be122300 -->
`<Dialog>`

<!-- s:30940c6b5c -->
تفصیل اور ایکشنز کی ایک قطار والا `<Modal>`۔

<!-- s:7cfec2b258 -->
`<Confirm>`

<!-- s:7e0406516a -->
ہاں یا نہیں۔ `y` اور `n` براہ راست جواب دیتے ہیں؛ `←` `→` بٹنز کے درمیان منتقل کرتے ہیں۔ `destructive` تصدیق کے بٹن کا اسٹائل بدلتا ہے اور پہلے “منسوخ کریں” پر فوکس کرتا ہے۔

<!-- s:fecae30a60 -->
ٹوسٹس

<!-- s:76abda6137 -->
ایک `<Toaster />` رینڈر کریں، پھر اسی روٹ میں کہیں بھی `useToast()` کال کریں۔

<!-- s:d5c6b1208e -->
| آپشن | تفصیل |
| :-- | :-- |
| `duration` | ملی سیکنڈ (ڈیفالٹ `4000`؛ لوڈنگ ٹوسٹس برقرار رہتے ہیں) |
| `id` | ٹوسٹ کو اسی جگہ اپ ڈیٹ کرنے کے لیے دوبارہ استعمال کریں |
| `position` | `<Toaster>` پر: `bottom-right` (ڈیفالٹ)، `top-center`، … |
| `max` | `<Toaster>` پر: ایک وقت میں نظر آنے والے ٹوسٹس (ڈیفالٹ `3`) |

<!-- s:476f42f2b3 -->
ٹوسٹس موڈلز کے اوپر رینڈر ہوتے ہیں اور کبھی فوکس نہیں لیتے۔
