یہ ان پٹس کی بورڈ سے چلتے ہیں اور اپنا فوکس خود سنبھالتے ہیں۔

<!-- s:1d0d345c65 -->
فوکس

<!-- s:bc06482880 -->
`Tab` اور `Shift+Tab` فوکس کو باری باری منتقل کرتے ہیں۔ `autoFocus` ماؤنٹ ہونے پر فوکس حاصل کرتا ہے۔

<!-- s:fca23dd943 -->
فوکس والے ایڈیٹرز اپنی کیز خود استعمال کرتے ہیں، اس لیے `1` ٹائپ کرنے سے کبھی کوئی گلوبل شارٹ کٹ فعال نہیں ہوتا۔

<!-- s:7c862ee98e -->
`<Input>`

<!-- s:fdde26d4d9 -->
readline طرز کی ایڈیٹنگ کے ساتھ ایک لائن کا ان پٹ۔

<!-- s:88cdcfc0ea -->
| Prop | تفصیل |
| :-- | :-- |
| `value` / `onChange` | کنٹرول شدہ ویلیو |
| `onSubmit` | `Enter` دبانے پر کال |
| `placeholder` | خالی ہونے پر ظاہر ہونے والا متن |
| `mask` | خفیہ معلومات چھپانے کا کریکٹر |

<!-- s:995d41e175 -->
`<Textarea>`

<!-- s:cf370a7f95 -->
کئی لائنوں کا کمپوزر۔ `Enter` سبمٹ کرتا ہے، `Shift+Enter` نئی لائن شامل کرتا ہے۔

<!-- s:667b32bc16 -->
`<Select>`

<!-- s:1c8033c766 -->
کی بورڈ سے چلنے والی آپشنز کی فہرست جس میں اختیاری فزی سرچ ہے۔

<!-- s:70fe7d6c9b -->
| Prop | تفصیل |
| :-- | :-- |
| `options` | `{ value, label, hint?, badge? }[]` |
| `onChange` | `Enter` دبانے پر کال |
| `searchable` | ٹائپ کرنے پر آپشنز کی فلٹرنگ |

<!-- s:958ee46fb6 -->
`<Tabs>`

<!-- s:f61cb509c5 -->
فوکس کے بغیر کرسر

<!-- s:f0552feed5 -->
جب صفحے کا فوکس ہٹتا ہے تو کرسر ساکن ہو جاتے ہیں اور فریم رک جاتے ہیں، تاکہ آپ کونسول کا متن منتخب اور کاپی کر سکیں۔
