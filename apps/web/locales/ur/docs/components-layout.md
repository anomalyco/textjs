یہ بنیادی کمپوننٹس Yoga flexbox سے سیل گرڈ کا لے آؤٹ بناتے ہیں۔

<!-- s:00be928124 -->
`<Box>`

<!-- s:cdedc6ec73 -->
لے آؤٹ کا کنٹینر۔

<!-- s:b2726c7ef5 -->
| Prop | تفصیل |
| :-- | :-- |
| `className` | سیل یوٹیلٹیز |
| `border` | `single` `rounded` `double` `heavy` `dashed` |
| `title` | اوپری بارڈر میں شامل متن |
| `bg` / `fg` | پس منظر اور متن کا رنگ |
| `overflow` | `hidden` یا `scroll` |

<!-- s:a83221d138 -->
`<Text>`

<!-- s:ea0876c03f -->
ان لائن متن۔ نیسٹڈ `<Text>` اسٹائل والے spans میں بدل جاتا ہے۔

<!-- s:d078a242d3 -->
| Prop | تفصیل |
| :-- | :-- |
| `color` | متن کا رنگ |
| `bold` `italic` `underline` `dim` | خصوصیات |
| `wrap` | `wrap` `nowrap` `truncate-end` |

<!-- s:e9a9218253 -->
`<ScrollBox>`

<!-- s:51162fc3b2 -->
اسکرول ہونے والا کالم۔ مواد بڑھنے پر `stickyScroll` اسکرول کو نچلے سرے پر رکھتا ہے۔

<!-- s:9029b4d81b -->
`<Modal>`

<!-- s:3804dec517 -->
درمیان میں موجود اوورلے جو نیچے کے مواد کو مدھم کرتا ہے اور فوکس کو اپنے اندر رکھتا ہے۔

<!-- s:7a128a8b11 -->
Spacer، Divider اور Badge

<!-- s:72e5d35050 -->
لے آؤٹ ہیلپرز

<!-- s:e76299d593 -->
عام flex ترتیبوں کے لیے مختصر طریقے۔

<!-- s:0f066fb217 -->
`<SplitPane>`

<!-- s:20cd99b8e7 -->
دو پین اور ایک ڈیوائیڈر۔ `resizable` کے ساتھ ڈیوائیڈر `Tab` کی ترتیب میں شامل ہو جاتا ہے اور `←` `→` اس کا سائز بدلتے ہیں (پانچ سیل کے لیے `Shift`)۔

<!-- s:2143924860 -->
`size` ایک کسر (`0.3`) یا سیل کی تعداد (`24`) ہے۔ `direction="column"` پین کو ایک کے نیچے ایک رکھتا ہے۔
