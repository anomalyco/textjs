`<LineChart>`

<!-- s:79abfce919 -->
y محور اور لیجنڈ کے ساتھ ڈاٹ میٹرکس لائن پلاٹس۔

<!-- s:977778a73f -->
| Prop | تفصیل |
| :-- | :-- |
| `series` | `{ data, label?, color? }[]` |
| `data` | ایک سیریز کا مختصر طریقہ |
| `height` | قطاریں (ڈیفالٹ `8`) |
| `min` / `max` | مقررہ حدیں (ڈیفالٹ: ڈیٹا) |
| `axis` | کم سے کم / زیادہ سے زیادہ کے لیبلز کے ساتھ Y محور |
| `formatValue` | محور کے لیبلز (ڈیفالٹ `1.2k`) |
| `marker` | `quadrant` (ڈیفالٹ) یا `braille` |

<!-- s:3827b070cb -->
`braille` ہر سیل میں 2×4 نقطے رکھتا ہے۔ اسے ٹرمینلز میں استعمال کریں: macOS پر DevTools کونسول کے فونٹ Menlo میں بریل نہیں ہے، اور فال بیک گلفس ایک سیل سے زیادہ چوڑے ہیں۔

<!-- s:a1d8752203 -->
سیریز کے ڈیفالٹ رنگ `accent`، `success`، `warning`، `info` اور `danger` ہیں۔

`<Image>`

<!-- s:35a4098e50 -->
Chromium اور Firefox کے کونسول تصویر کو پکسل اسپرائٹ کی صورت میں بناتے ہیں۔ پکسل آرٹ (256 یا اس سے کم رنگ، جزوی شفاف پکسلز کے بغیر) ہر سیل میں 8 × 16 تک پکسلز رکھتا ہے، اور تصاویر 4 × 8 تک۔ Safari، ٹرمینلز، سادہ متن کی کاپیوں اور [`runtime = "server"`](/docs/server-rendering) والے صفحات میں `▀` نصف بلاکس ملتے ہیں: ہر سیل میں دو پکسلز ہوتے ہیں، اوپر والا پیش منظر میں اور نیچے والا پس منظر میں۔ ہر جگہ نصف بلاکس بنانے کے لیے `renderMode="halfblock"` دیں، جیسے `<Image>` ورژن 1.3 میں کرتا تھا۔

<!-- s:70bb4fc454 -->
| Prop | تفصیل |
| :-- | :-- |
| `src` | تصویر کا URL (صرف براؤزر) |
| `pixels` | خام RGBA بصورت `{ width, height, data }`، قطاروں کی ترتیب میں ہر پکسل کے لیے 4 بائٹس |
| `width` / `height` | چوڑائی سیلز میں، اونچائی قطاروں میں۔ تناسب برقرار رکھنے کے لیے ایک دیں، یا ہر سیل میں 1 × 2 پکسلز کے لیے دونوں چھوڑ دیں (`src` زیادہ سے زیادہ 256 × 256 px تک اسکیل ہوتا ہے) |
| `fit` | `contain` (ڈیفالٹ)، `cover` یا `fill` |
| `alt` | `src` لوڈ ہوتے وقت یا ناکام ہونے پر دکھایا جانے والا متن |
| `renderMode` | `auto` (ڈیفالٹ: جہاں سپورٹ ہو وہاں اسپرائٹ، باقی جگہ `▀` نصف بلاکس) یا `halfblock` |

<!-- s:c106665c64 -->
`<Image>` لے آؤٹ پراپس بھی لیتا ہے۔

<!-- s:20dac26bff -->
`src` کینوس سے لوڈ ہوتا ہے، اس لیے کراس اوریجن تصاویر کو CORS درکار ہے۔ `pixels` ہر جگہ خام RGBA لیتا ہے، ٹرمینل میں بھی۔

<!-- s:4e3b06ef0e -->
Chromium اور Firefox میں بھی تصویر نصف بلاکس کی صورت میں بنتی ہے جب وہ ایک اسپرائٹ نہ بن سکے:

<!-- s:00d2e660eb -->
- ایک ہی قطاروں میں ساتھ ساتھ دو تصاویر، جیسے گیلری میں۔
- ایک تصویر جس کے ساتھ متن ہو۔ متن کے ساتھ پکسل آرٹ اسپرائٹ ہی رہتا ہے۔
- `overflow="hidden"` باکس سے کٹی ہوئی تصویر، یا کسی دوسرے باکس سے جزوی طور پر ڈھکی ہوئی تصویر۔
- متن کے اوپر یا ایک سے زیادہ پس منظر کے رنگوں کے اوپر شفاف پکسلز۔

<!-- s:dd4fefaac0 -->
`<Pixels>` (تجرباتی)

<!-- s:71eeeca05d -->
`@textjs/react/experimental` گیمز، ایمولیٹرز اور ویڈیو جیسے لائیو `0xRRGGBBAA` فریم بفرز کے لیے `<Pixels>` ایکسپورٹ کرتا ہے۔ پیک کیے ہوئے پکسلز براہ راست `source.data` میں لکھیں اور دوبارہ پینٹ کرنے کے لیے `frame` بڑھائیں۔

<!-- s:2d12b69e81 -->
| Prop | تفصیل |
| :-- | :-- |
| `source` | `0xRRGGBBAA` ترتیب میں `{ width, height, data: Uint32Array }` |
| `frame` | فریم کاؤنٹر؛ `source.data` میں تبدیلی کے بعد بڑھائیں |
| `width` / `height` | سیلز اور قطاروں میں باکس کا سائز |
| `fit` | `contain` (ڈیفالٹ) یا `fill` |
| `pixelAspect` | ماخذ کے ایک پکسل کی دکھائی گئی چوڑائی کو اونچائی سے تقسیم کرنے کا حاصل (ڈیفالٹ `1`) |
| `palette` | رنگوں کو کوانٹائز کرنے کے لیے اختیاری `PackedColor[]` پیلیٹ |
| `sample` | نصف بلاک فال بیک فلٹر: `nearest` (ڈیفالٹ) یا `average` |
| `renderMode` | `auto` (ڈیفالٹ: جہاں سپورٹ ہو وہاں اسپرائٹ، باقی جگہ `▀` نصف بلاکس) یا `halfblock` |

<!-- s:2164b4fe56 -->
`renderMode="auto"` Chromium میں، اور Firefox میں اس کے کونسول کے اسٹائل کے قواعد کے مطابق، پکسل نما اسپرائٹ بناتا ہے (بینچ مارک نہیں کیا گیا)، اور Safari، ٹرمینلز، سادہ متن کی کاپیوں اور [`runtime = "server"`](/docs/server-rendering) والے صفحات میں `▀` نصف بلاکس پر منتقل ہوتا ہے۔ ہر جگہ نصف بلاکس بنانے کے لیے `renderMode="halfblock"` دیں۔

<!-- s:5d2bbbc47b -->
React کے بغیر پکسلز بنانے کے لیے `@textjs/core/experimental` سے `drawPixels` کے ساتھ `DrawPixelsOptions`، `PixelSource`، `PixelFit`، `PixelSample`، `PixelRenderMode`، `PixelEncoding` اور `PixelRect` امپورٹ کریں۔ اس کا `encoding: "rgba"` آپشن ساکن تصاویر کے لیے 256 سے زیادہ رنگ اور نرم الفا برقرار رکھتا ہے، اور جہاں اسپرائٹ نہیں دکھایا جا سکتا وہاں `fallback` آپ کے اپنے سیلز پینٹ کرتا ہے۔ تجرباتی ایکسپورٹس کی ورژن بندی کے طریقے کے لیے [مطابقت توڑنے والی تبدیلیاں](/docs/support-policy#breaking-changes) دیکھیں۔
