`<List>`، `<Table>` اور `<Tree>` بڑے ڈیٹا سیٹ دکھاتے ہیں۔ صرف نظر آنے والی قطاریں رینڈر ہوتی ہیں۔

<!-- s:44ffd1d0a7 -->
نیویگیشن

<!-- s:e3dca4574c -->
`<List>`، `<Table>` اور `<Tree>` ایک ہی کی بورڈ ماڈل استعمال کرتے ہیں۔

<!-- s:cdac0643be -->
| کلیدیں | عمل |
| :-- | :-- |
| `↑` `↓` / `j` `k` | حرکت |
| `PgUp` `PgDn`، `Ctrl+U` `Ctrl+D` | صفحہ، آدھا صفحہ |
| `Home` `End` / `g` `G` | پہلا، آخری |
| `↵` | `onSelect` |
| وہیل | کرسر کی حرکت |

<!-- s:1c65c42a4d -->
یہ ڈیفالٹ طور پر اپنے پیرنٹ کو بھر دیتے ہیں۔ قطاروں کی مقررہ تعداد کے لیے `height` دیں۔

<!-- s:3a828804bb -->
`<List>`

<!-- s:2603a57dc8 -->
ایک ورچوئلائزڈ فہرست۔ ہر قطار کی اونچائی ایک سیل ہے۔

<!-- s:3408e68b29 -->
| Prop | تفصیل |
| :-- | :-- |
| `items` | کوئی بھی ایرے |
| `renderItem` | `(item, { highlighted, focused }) => ReactNode` |
| `isItemDisabled` | کرسر سے نظرانداز |
| `height` | نظر آنے والی قطاریں (ڈیفالٹ: بھرنا) |
| `highlightedIndex` / `onHighlight` | کنٹرول شدہ کرسر |
| `vimKeys` | `j` `k` `g` `G` (ڈیفالٹ `true`) |

<!-- s:55759482eb -->
`<Table>`

<!-- s:ff77c49577 -->
جن کالموں میں `width` مقرر نہیں، وہ باقی چوڑائی بانٹ لیتے ہیں۔ ہیڈر اور سیل ایک ہی فلیکس اصول استعمال کرتے ہیں، اس لیے وہ ہمیشہ سیدھ میں رہتے ہیں۔

<!-- s:e9719839f0 -->
| کالم فیلڈ | تفصیل |
| :-- | :-- |
| `key` | آئی ڈی اور ڈیفالٹ ایکسیسر |
| `width` / `grow` | سیل کی مقررہ تعداد یا باقی جگہ میں حصہ |
| `align` | `left` `right` `center` |
| `value` | دکھانے اور ترتیب دینے کی ویلیو |
| `render` | سیل کا کسٹم مواد |
| `compare` | کسٹم ترتیب |

<!-- s:045ee40857 -->
ترتیب دینا

<!-- s:d04de39344 -->
`sortable` کے ساتھ، کسی کالم کے مطابق ترتیب دینے کے لیے اس کا نمبر دبائیں (ترتیب الٹنے کے لیے دوبارہ)، کالم بدلنے کے لیے `s` اور سمت الٹنے کے لیے `S` دبائیں۔ ترتیب مستحکم رہتی ہے۔ اسے `sort` اور `onSortChange` سے کنٹرول کریں۔

<!-- s:6d625a19ed -->
انتخاب

<!-- s:2132bc20a2 -->
`selectionMode="multiple"` ایک چیک کالم شامل کرتا ہے؛ `Space` ہائی لائٹ شدہ قطار کا انتخاب بدلتا ہے۔ اسے کنٹرول کرنے کے لیے `selectedKeys` اور `onSelectionChange`، اور مستقل کلیدوں کے لیے `getRowKey` استعمال کریں۔

<!-- s:3bd95f58e2 -->
`<Tree>`

<!-- s:ec4c582ab8 -->
رہنما لکیروں کے ساتھ ایک قابل توسیع ٹری۔

<!-- s:eeb148154f -->
`→` شاخ کو کھولتا ہے یا اس کے اندر جاتا ہے۔ `←` شاخ کو سمیٹتا ہے یا پیرنٹ پر جاتا ہے۔ `Space` کھولنے اور سمیٹنے کی حالت بدلتا ہے۔ اگر آپ کو اپنا رینڈرر چاہیے تو `flattenTree(data, expanded)` نظر آنے والی قطاریں فراہم کرتا ہے۔
