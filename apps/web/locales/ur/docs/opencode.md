[OpenCode](https://opencode.ai) ایک اوپن سورس کوڈنگ ایجنٹ ہے۔ **OpenCode Lite** اس کا کونسول کلائنٹ ہے، جو Text.js سے بنایا گیا ہے۔

<!-- s:a0fa47c98f -->
آزمانا

<!-- s:8b5f5ed2de -->
- اس سائٹ پر: [OpenCode](/opencode) پر جائیں اور DevTools کھولیں۔
- مقامی طور پر: `bunx create-text-app my-app --template opencode`۔

<!-- s:db57075dd8 -->
سائٹ پر اسکرپٹڈ ایجنٹ کے ساتھ ایک سینڈ باکس چلتا ہے۔ کوئی بھی پرامپٹ ٹائپ کریں۔

<!-- s:867840c638 -->
ساخت

<!-- s:7b522f9378 -->
| حصہ | کمپوننٹس |
| :-- | :-- |
| گفتگو کا ریکارڈ | `<ScrollBox stickyScroll>` + `<Markdown>` |
| ٹول کارڈز | `<Code>` اور `<Diff>` |
| پرامپٹ | `<Textarea>` |
| پیلیٹ | `<Modal>` + `<Select searchable>` |

مقامی سرور سے کنکشن

<!-- s:a98495bd7f -->
برج کو چلتا رہنے دیں۔ [OpenCode صفحے](/opencode) پر `http://127.0.0.1:4096` درج کریں، **کنیکٹ کریں** دبائیں، اور اگر Chrome پوچھے تو مقامی نیٹ ورک تک رسائی کی اجازت دیں۔ پھر برج کا پرنٹ کردہ پیئرنگ کوڈ درج کریں۔ صفحہ اس وقت تک پیئر رہتا ہے جب تک برج دوبارہ شروع نہ ہو یا آپ **ڈس کنیکٹ کریں** نہ دبائیں۔ برج کا URL استعمال کریں، سروس کا پورٹ نہیں: برج سروس کی سند اور CORS ہیڈرز فراہم کرتا ہے۔ کام مکمل ہونے پر اسے Ctrl+C سے بند کریں۔

<!-- s:7c6a89edc5 -->
اگر فورگراؤنڈ سرور پہلے ہی پورٹ 4096 پر چل رہا ہے تو `bunx @textjs/opencode@latest proxy --port 4097 --target http://127.0.0.1:4096` چلائیں اور صفحے کو پورٹ **4097** سے کنیکٹ کریں۔ پاس ورڈ سے محفوظ فورگراؤنڈ سرور کے لیے، برج کی شیل میں اس کا `OPENCODE_PASSWORD` ایکسپورٹ کریں؛ براؤزر کے URL میں پاس ورڈ نہ ڈالیں۔

<!-- s:951b1ef5cb -->
برج `@textjs/opencode` پیکیج ہے۔ اس کی کوئی ڈیپنڈنسی نہیں اور یہ Node 22 یا اس کے بعد کے ورژن پر `npx` کے ساتھ بھی چلتا ہے۔ Text.js پروجیکٹ کے اندر، `text proxy` کمانڈ یہی برج شروع کرتی ہے۔
