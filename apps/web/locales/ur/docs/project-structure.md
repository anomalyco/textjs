`app/` میں فولڈرز روٹس کی تعریف کرتے ہیں، اور خاص فائلیں ہر روٹ کے UI کی تعریف کرتی ہیں۔

<!-- s:11f7d9178c -->
فولڈرز

<!-- s:8bda4d61c2 -->
| فولڈر | مقصد |
| :-- | :-- |
| `app` | روٹس، لے آؤٹس اور روٹ ہینڈلرز |
| `lib` | مشترکہ ماڈیولز، روٹنگ میں شامل نہیں |
| `public` | اسٹیٹک اثاثے |

<!-- s:25756fa68d -->
روٹنگ فائلیں

<!-- s:8d1e739d99 -->
| فائل | مقصد |
| :-- | :-- |
| `layout.tsx` | سیگمنٹ کا مشترکہ UI |
| `page.tsx` | روٹ سے قابل رسائی اسکرین |
| `loading.tsx` | Suspense فال بیک |
| `error.tsx` | ایرر باؤنڈری |
| `not-found.tsx` | کسی روٹ سے میل نہ کھانے والے URLs |
| `route.ts` | API اینڈ پوائنٹ |

text.config.ts

<!-- s:1baaf058bb -->
| آپشن | ڈیفالٹ | تفصیل |
| :-- | :-- | :-- |
| `title` | `""` | صفحے اور FocusPad کا عنوان |
| `viewport` | کونسول کے مطابق، ورنہ `120×36` | `responsive` (ڈیفالٹ `true`)، فال بیک `width × height`، `theme` |
| `hints` | `[]` | صفحے کے FocusPad پر دکھائی جانے والی دو یا تین کلیدیں |
| `action` | `press <first hint>` | فوکس ہونے پر کرنے کا کام، مثلاً `"type a prompt"` |
| `devIndicators` | `true` | کونسول میں Dev Overlay (`[▼]`) |
| `focusHint` | `true` | جب صفحے پر فوکس نہ ہو تو کونسول کی آخری قطار کے اوپر “کی بورڈ استعمال کرنے کے لیے صفحے پر کلک کریں” |
| `rewrites` | `[]` | ری رائٹس اور پراکسیز |
| `ansi` | `{ cols: 80, rows: 24 }` | [curl اور ٹرمینل کلائنٹس](/docs/curl) کے لیے فریم کا سائز، یا انہیں HTML فراہم کرنے کے لیے `false` |
| `embed` | `false` | دوسری سائٹس پر ایک اسکرپٹ ٹیگ سے شامل کرنے کے لیے ایپ بلڈ کرنا ([ایمبیڈنگ](/docs/embedding)، تجرباتی) |

CLI

<!-- s:86e6dffb86 -->
| کمانڈ | تفصیل |
| :-- | :-- |
| `text dev` | Fast Refresh کے ساتھ ڈیو سرور |

| `text mcp` | کوڈنگ ایجنٹس کو ایپ فراہم کریں ([MCP](/docs/mcp)) |
