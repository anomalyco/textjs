`@textjs/app/testing` (یا `@textjs/react/testing`) آپ کی ایپ کو آف اسکرین رینڈر کرتا ہے، کیز دباتا ہے اور فریم کو متن کی صورت میں واپس کرتا ہے۔ ٹیسٹ براؤزر یا DevTools کے بغیر چلتے ہیں۔

<!-- s:9bc71b1ad2 -->
یہ ہر ایسے رنر کے ساتھ کام کرتا ہے جو `async` ٹیسٹ سپورٹ کرتا ہو، بشمول Bun، Vitest اور Jest۔

<!-- s:f7898e6b92 -->
رینڈرنگ

<!-- s:fc969a7928 -->
| میتھڈ | تفصیل |
| :-- | :-- |
| `render(el, { cols, rows, theme })` | آف اسکرین ماؤنٹ کرنا (ڈیفالٹ 80×24) |
| `lastFrame()` | سادہ متن کی صورت میں فریم |
| `lines()` | قطاروں کی ایرے کی صورت میں فریم |
| `frames` | اب تک کا ہر منفرد فریم |
| `toAnsi()` | اسنیپ شاٹس کے لیے Truecolor ANSI |
| `cell(x, y)` | `{ char, fg, bg, attrs }` |
| `locate(text)` | پہلے میچ کا `{ x, y }` |
| `rerender(el)` / `unmount()` | اپ ڈیٹ کرنا یا ہٹانا |

<!-- s:893f22353a -->
`renderToString(el, options)` ایک بار رینڈر کرتا ہے اور متن واپس کرتا ہے۔

ان پٹ

<!-- s:105149560b -->
ہر کال `act()` کے اندر چلتی ہے اور نتیجے میں بننے والے فریم فلش کرتی ہے، اس لیے اگلا اسرشن اپ ڈیٹ دیکھتا ہے۔

<!-- s:1f65c071dc -->
وقت

<!-- s:ab365d9403 -->
اینیمیشنز، اسپنرز اور ٹوسٹس حقیقی ٹائمرز استعمال کرتے ہیں، اس لیے انہیں دیکھنے کے لیے `wait` اور `waitFor` قابل اعتماد طریقے ہیں۔
