یوٹیلٹیز

<!-- s:2de571e2bf -->
`className` میں Tailwind طرز کی یوٹیلٹیز استعمال ہوتی ہیں۔ ایک یونٹ ایک سیل کے برابر ہے۔

| زمرہ | مثالیں |
| :-- | :-- |
| لے آؤٹ | `flex-row` `grow` `items-center` `gap-1` |
| اسپیسنگ | `p-1` `px-2` `mt-1` |
| بارڈرز | `border` `rounded` `border-accent` |
| رنگ | `bg-surface` `text-muted` |
