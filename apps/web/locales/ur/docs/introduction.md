Text.js ایسی ایپس کے لیے React فریم ورک ہے جو `console.log` سے DevTools کونسول میں رینڈر ہوتی ہیں۔

<!-- s:34bf1ea7dd -->
پری ویو لائیو ہے۔ اس پر کلک کریں اور `↑` دبائیں۔

<!-- s:0bccbd98be -->
شامل خصوصیات

<!-- s:d3708efc68 -->
- **React 19**: کنکرنٹ رینڈرنگ، Suspense اور ایرر باؤنڈریز۔
- **App Router**: لے آؤٹس، صفحات، ڈائنامک سیگمنٹس اور روٹ ہینڈلرز۔
- **Yoga لے آؤٹ**: WebAssembly میں flexbox، صحیح عدد والے سیلز کے مطابق ترتیب دیا ہوا۔
- **Turbolog**: ہر تبدیل شدہ فریم پر ایک `console.log` کال۔
- **کونسول UI**: صفحے پر صرف ایک فوکس پیڈ اور ایک پوشیدہ ان پٹ ہوتا ہے۔

<!-- s:5ae438610c -->
کام کرنے کا طریقہ

<!-- s:75f47f9f8c -->
اسٹیٹ نیچے کی طرف بہتی ہے: React، پھر لے آؤٹ، پھر سیل بفر، پھر کونسول۔

<!-- s:25c55610d2 -->
غیر تبدیل شدہ فریم چھوڑ دیے جاتے ہیں، اس لیے غیر فعال ایپس کچھ لاگ نہیں کرتیں۔
