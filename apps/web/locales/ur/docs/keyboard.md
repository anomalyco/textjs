`useKeymap` کے ساتھ شارٹ کٹس ایک بار متعین کریں۔ Text.js انہیں روٹ کرتا ہے، `?` اوورلے میں ان کی فہرست دکھاتا ہے، آپ کے فوٹر میں دکھاتا ہے اور کمانڈ پیلیٹ میں انہیں تلاش کے قابل بناتا ہے۔

<!-- s:b084dfc727 -->
`useKeymap`

<!-- s:f944f97e4b -->
| سنٹیکس | مطلب |
| :-- | :-- |
| `ctrl+k` | موڈیفائرز: `ctrl` `alt` `shift` `meta` `mod` |
| `mod+k` | `⌘` یا `Ctrl`، جو بھی دبایا گیا ہو |
| `j, down` | متبادل |
| `g g` | ایک ترتیب (کیز کے درمیان 1 سیکنڈ) |
| `G` | بڑے حرف سے مراد `Shift` ہے |
| `?` | قابلِ طباعت کیز حرف سے میچ ہوتی ہیں |

<!-- s:ef55b4b9de -->
ویلیوز ایک ہینڈلر، یا `label`، `group`، `hint`، `disabled` اور `noRepeat` والی بائنڈنگ ہوتی ہیں۔ بغیر لیبل کی بائنڈنگز کام کرتی ہیں لیکن ہیلپ اوورلے میں نہیں دکھتیں۔

<!-- s:01f344cdbe -->
`useKeymapBindings()` آپ کے اپنے فوٹرز اور مینیوز کے لیے وہ لیبل والی بائنڈنگز واپس کرتا ہے جو اس وقت فعال ہیں۔

<!-- s:dd8af5eb69 -->
کی میپس `useInput` ہک سے چلتے ہیں، اس لیے معمول کے اصول لاگو ہوتے ہیں: فوکس والے ان پٹس کو ترجیح ملتی ہے، میچ ہونے والی کی ایونٹ کو آگے جانے سے روکتی ہے، اور کھلا ہوا `<Modal>` اپنے باہر کی بائنڈنگز غیر فعال کرتا ہے۔ اسے بدلنے کے لیے `{ priority, global, isActive }` پاس کریں۔

<!-- s:da19075700 -->
`<KeyHelp>`

<!-- s:907e2eedda -->
ہر لیبل والی بائنڈنگ کو گروپس میں دیکھنے کے لیے `?` دبائیں۔ یہ اس جگہ فعال بائنڈنگز کی فہرست دکھاتا ہے جہاں یہ کھلا تھا۔

<!-- s:3cebb95bfc -->
`<KeyHints>` اور `<StatusBar>`

<!-- s:04fa34bd49 -->
`<KeyHints />` ان بائنڈنگز کو دکھاتا ہے جن پر `hint: true` ہو، یا واضح طور پر دیے گئے `items` دکھاتا ہے۔ `<StatusBar>` ایک قطار کا فوٹر ہے جس میں `right` سلاٹ ہے۔

<!-- s:b9ded39a0a -->
`<Kbd>mod+k</Kbd>` ایک کی رینڈر کرتا ہے۔ `formatKeys("ctrl+shift+p")` سے macOS پر `⌃⇧P` اور دوسری جگہوں پر `ctrl+shift+P` ملتا ہے۔

<!-- s:8b6afd6178 -->
`<CommandPalette>`

<!-- s:65192cd436 -->
`Ctrl+K`‏ (یا `Ctrl+P`) آپ کی کمانڈز اور ہر لیبل والی بائنڈنگ کے لیے فزی لانچر کھولتا ہے، جس میں میچ ہونے والے حروف نمایاں ہوتے ہیں۔

<!-- s:e88bab4eab -->
| Prop | تفصیل |
| :-- | :-- |
| `commands` | `{ id, label, group?, keys?, keywords?, run }[]` |
| `keys` | کھولنے کا شارٹ کٹ (ڈیفالٹ `ctrl+k, ctrl+p`؛ غیر فعال کرنے کے لیے `null`) |
| `includeKeymap` | کی میپ بائنڈنگز کی فہرست دکھانا (ڈیفالٹ `true`) |
| `open` / `onOpenChange` | کنٹرولڈ |

<!-- s:ddd093fe85 -->
پیلیٹ کمانڈ چلانے سے پہلے بند ہو جاتا ہے، اس لیے کمانڈز اپنے موڈلز کھول سکتی ہیں۔ آپ کی اپنی فہرستوں کے لیے `fuzzyMatch` اور `fuzzyFilter` ایکسپورٹ ہوتے ہیں۔
