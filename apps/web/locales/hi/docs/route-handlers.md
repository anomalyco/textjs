रूट हैंडलर Web `Request` और `Response` API के साथ `app` डायरेक्टरी में API एंडपॉइंट तय करते हैं।

<!-- s:895d99d1b5 -->
कन्वेंशन

<!-- s:ac1d1b9fcb -->
`GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD` या `OPTIONS` एक्सपोर्ट करें। हैंडलर `text dev`, `text start` और हर सर्वर [डिप्लॉय अडैप्टर](/docs/deploying) पर [मिडलवेयर](/docs/middleware) के बाद चलते हैं। [रूट सेगमेंट कॉन्फ़िग](/docs/caching) से `GET` हैंडलर कैश करें।

<!-- s:53eeba0ff3 -->
डायनैमिक हैंडलर

<!-- s:bfa759b36e -->
`params` की वैल्यू डिकोड होती हैं। एन्कोड किए गए स्लैश या बैकस्लैश (`%2F`, `%5C`) वाले पाथ को `400` मिलता है, इसलिए जिन ID में `/` हो सकता है, उन्हें क्वेरी पैरामीटर में भेजें या base64url के रूप में एन्कोड करें।
