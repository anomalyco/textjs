`<Markdown>`

<!-- s:842bba9c18 -->
स्ट्रीमिंग के लिए सुरक्षित Markdown। बढ़ती हुई स्ट्रिंग पास करें और फ़्रेम स्थिर रहता है।

<!-- s:f6f3074d02 -->
`<Code>`

<!-- s:e3dec08834 -->
`ts`, `tsx`, `json`, `bash`, `python`, `rust`, `go` और अन्य के लिए सिंटैक्स हाइलाइटिंग।

<!-- s:e75addc84e -->
| Prop | विवरण |
| :-- | :-- |
| `language` | भाषा का आईडी |
| `showLineNumbers` | लाइन गटर |
| `highlightLines` | रंग देने वाली लाइनें |
| `maxHeight` | “और लाइनें” फ़ुटर के साथ क्लिप करना |

`<Diff>`

<!-- s:ec6578a933 -->

`<Spinner>`

<!-- s:502520871a -->
