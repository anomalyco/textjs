`@textjs/app/testing` (या `@textjs/react/testing`) आपके ऐप को ऑफ़स्क्रीन रेंडर करता है, कुंजियां दबाता है और फ़्रेम को टेक्स्ट के रूप में लौटाता है। टेस्ट ब्राउज़र या DevTools के बिना चलते हैं।

<!-- s:9bc71b1ad2 -->
यह `async` टेस्ट का समर्थन करने वाले किसी भी रनर के साथ काम करता है, जिनमें Bun, Vitest और Jest शामिल हैं।

<!-- s:f7898e6b92 -->
रेंडरिंग

<!-- s:fc969a7928 -->
| मेथड | विवरण |
| :-- | :-- |
| `render(el, { cols, rows, theme })` | ऑफ़स्क्रीन माउंट करना (डिफ़ॉल्ट 80×24) |
| `lastFrame()` | प्लेन टेक्स्ट के रूप में फ़्रेम |
| `lines()` | पंक्तियों के ऐरे के रूप में फ़्रेम |
| `frames` | अब तक का हर अलग फ़्रेम |
| `toAnsi()` | स्नैपशॉट के लिए Truecolor ANSI |
| `cell(x, y)` | `{ char, fg, bg, attrs }` |
| `locate(text)` | पहले मैच का `{ x, y }` |
| `rerender(el)` / `unmount()` | अपडेट करना या हटाना |

<!-- s:893f22353a -->
`renderToString(el, options)` एक बार रेंडर करता है और टेक्स्ट लौटाता है।

इनपुट

<!-- s:105149560b -->
हर कॉल `act()` के अंदर चलती है और उससे बने फ़्रेम फ़्लश करती है, इसलिए अगले असर्शन को अपडेट दिखता है।

<!-- s:1f65c071dc -->
समय

<!-- s:ab365d9403 -->
ऐनिमेशन, स्पिनर और टोस्ट असली टाइमर का इस्तेमाल करते हैं, इसलिए उन्हें देखने के लिए `wait` और `waitFor` भरोसेमंद तरीके हैं।
