`app/` में फ़ोल्डर रूट तय करते हैं, और विशेष फ़ाइलें हर रूट का UI तय करती हैं।

<!-- s:11f7d9178c -->
फ़ोल्डर

<!-- s:8bda4d61c2 -->
| फ़ोल्डर | उद्देश्य |
| :-- | :-- |
| `app` | रूट, लेआउट और रूट हैंडलर |
| `lib` | साझा मॉड्यूल, जिनकी रूटिंग नहीं होती |
| `public` | स्टैटिक एसेट |

<!-- s:25756fa68d -->
रूटिंग फ़ाइलें

<!-- s:8d1e739d99 -->
| फ़ाइल | उद्देश्य |
| :-- | :-- |
| `layout.tsx` | सेगमेंट का साझा UI |
| `page.tsx` | रूट की जा सकने वाली स्क्रीन |
| `loading.tsx` | Suspense फ़ॉलबैक |
| `error.tsx` | एरर बाउंड्री |
| `not-found.tsx` | किसी रूट से मेल न खाने वाले URL |
| `route.ts` | API एंडपॉइंट |

text.config.ts

<!-- s:1baaf058bb -->
| विकल्प | डिफ़ॉल्ट | विवरण |
| :-- | :-- | :-- |
| `title` | `""` | पेज और FocusPad का शीर्षक |
| `viewport` | कंसोल के आकार के अनुसार, वरना `120×36` | `responsive` (डिफ़ॉल्ट `true`), फ़ॉलबैक `width × height`, `theme` |
| `hints` | `[]` | पेज के FocusPad पर दिखने वाली दो या तीन कुंजियां |
| `action` | `press <first hint>` | फ़ोकस मिलने पर क्या करें, जैसे `"type a prompt"` |
| `devIndicators` | `true` | कंसोल में Dev Overlay (`[▼]`) |
| `focusHint` | `true` | जब पेज पर फ़ोकस न हो, तब कंसोल की आखिरी पंक्ति पर “कीबोर्ड इस्तेमाल करने के लिए पेज पर क्लिक करें” |
| `rewrites` | `[]` | रीराइट और प्रॉक्सी |
| `ansi` | `{ cols: 80, rows: 24 }` | [curl और टर्मिनल क्लाइंट](/docs/curl) के लिए फ़्रेम का आकार, या उन्हें HTML सर्व करने के लिए `false` |
| `embed` | `false` | ऐप को इस तरह बिल्ड करना कि दूसरी साइटें एक स्क्रिप्ट टैग से उसे जोड़ सकें ([एम्बेडिंग](/docs/embedding), प्रयोगात्मक) |

CLI

<!-- s:86e6dffb86 -->
| कमांड | विवरण |
| :-- | :-- |
| `text dev` | Fast Refresh के साथ डेव सर्वर |
| `text build` | प्रोडक्शन बिल्ड |
| `text start` | बिल्ड और रूट हैंडलर सर्व करें |
| `text run` | ऐप को टर्मिनल में रेंडर करें ([टर्मिनल](/docs/terminal)) |
| `text mcp` | कोडिंग एजेंट को ऐप सर्व करें ([MCP](/docs/mcp)) |
