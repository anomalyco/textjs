ये प्रिमिटिव Yoga flexbox से सेल ग्रिड का लेआउट बनाते हैं।

<!-- s:00be928124 -->
`<Box>`

<!-- s:cdedc6ec73 -->
लेआउट कंटेनर।

<!-- s:b2726c7ef5 -->
| Prop | विवरण |
| :-- | :-- |
| `className` | सेल यूटिलिटी |
| `border` | `single` `rounded` `double` `heavy` `dashed` |
| `title` | ऊपरी बॉर्डर में जड़ा टेक्स्ट |
| `bg` / `fg` | बैकग्राउंड और टेक्स्ट का रंग |
| `overflow` | `hidden` या `scroll` |

<!-- s:a83221d138 -->
`<Text>`

<!-- s:ea0876c03f -->
इनलाइन टेक्स्ट। नेस्ट किए गए `<Text>` स्टाइल वाले span बनते हैं।

<!-- s:d078a242d3 -->
| Prop | विवरण |
| :-- | :-- |
| `color` | टेक्स्ट का रंग |
| `bold` `italic` `underline` `dim` | एट्रिब्यूट |
| `wrap` | `wrap` `nowrap` `truncate-end` |

<!-- s:e9a9218253 -->
`<ScrollBox>`

<!-- s:51162fc3b2 -->
स्क्रॉल करने योग्य कॉलम। कॉन्टेंट बढ़ने पर `stickyScroll` नीचे पिन रखता है।

<!-- s:9029b4d81b -->
`<Modal>`

<!-- s:3804dec517 -->
बीच में दिखने वाला ओवरले, जो नीचे के कॉन्टेंट को धुंधला करता है और फ़ोकस को अपने अंदर रखता है।

<!-- s:7a128a8b11 -->
Spacer, Divider और Badge

<!-- s:72e5d35050 -->
लेआउट हेल्पर

<!-- s:e76299d593 -->
आम फ़्लेक्स व्यवस्थाओं के लिए शॉर्टहैंड।

<!-- s:0f066fb217 -->
`<SplitPane>`

<!-- s:20cd99b8e7 -->
दो पेन और एक डिवाइडर। `resizable` के साथ, डिवाइडर `Tab` क्रम में शामिल होता है और `←` `→` से उसका आकार बदलता है (पांच सेल के लिए `Shift`)।

<!-- s:2143924860 -->
`size` एक अंश (`0.3`) या सेल की संख्या (`24`) है। `direction="column"` पेन को एक के नीचे एक रखता है।
