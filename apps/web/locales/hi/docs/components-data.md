`<List>`, `<Table>` और `<Tree>` बड़े डेटा सेट दिखाते हैं। सिर्फ़ दिखाई देने वाली पंक्तियां रेंडर होती हैं।

<!-- s:44ffd1d0a7 -->
नेविगेशन

<!-- s:e3dca4574c -->
`<List>`, `<Table>` और `<Tree>` एक ही कीबोर्ड मॉडल का इस्तेमाल करते हैं।

<!-- s:cdac0643be -->
| कुंजियां | कार्रवाई |
| :-- | :-- |
| `↑` `↓` / `j` `k` | आगे-पीछे जाना |
| `PgUp` `PgDn`, `Ctrl+U` `Ctrl+D` | एक पेज, आधा पेज |
| `Home` `End` / `g` `G` | पहली, आखिरी पंक्ति |
| `↵` | `onSelect` |
| व्हील | कर्सर को आगे-पीछे करना |

<!-- s:1c65c42a4d -->
डिफ़ॉल्ट रूप से ये अपने पैरेंट को भरते हैं। पंक्तियों की संख्या तय करने के लिए `height` दें।

<!-- s:3a828804bb -->
`<List>`

<!-- s:2603a57dc8 -->
एक वर्चुअलाइज़्ड लिस्ट। हर पंक्ति की ऊंचाई एक सेल है।

<!-- s:3408e68b29 -->
| Prop | विवरण |
| :-- | :-- |
| `items` | कोई भी ऐरे |
| `renderItem` | `(item, { highlighted, focused }) => ReactNode` |
| `isItemDisabled` | कर्सर इसे छोड़कर आगे बढ़ता है |
| `height` | दिखाई देने वाली पंक्तियां (डिफ़ॉल्ट: उपलब्ध जगह भरना) |
| `highlightedIndex` / `onHighlight` | नियंत्रित कर्सर |
| `vimKeys` | `j` `k` `g` `G` (डिफ़ॉल्ट `true`) |

<!-- s:55759482eb -->
`<Table>`

<!-- s:ff77c49577 -->
जिन कॉलम की `width` सेट नहीं है, वे बची हुई चौड़ाई बांटते हैं। हेडर और सेल एक ही फ़्लेक्स नियम इस्तेमाल करते हैं, इसलिए वे हमेशा एक सीध में रहते हैं।

<!-- s:e9719839f0 -->
| कॉलम फ़ील्ड | विवरण |
| :-- | :-- |
| `key` | आईडी और डिफ़ॉल्ट ऐक्सेसर |
| `width` / `grow` | सेल की तय संख्या या बची हुई जगह का हिस्सा |
| `align` | `left` `right` `center` |
| `value` | दिखाने और सॉर्ट करने की वैल्यू |
| `render` | सेल का कस्टम कॉन्टेंट |
| `compare` | कस्टम सॉर्ट |

<!-- s:045ee40857 -->
सॉर्टिंग

<!-- s:d04de39344 -->
`sortable` के साथ, किसी कॉलम के हिसाब से सॉर्ट करने के लिए उसका नंबर दबाएं (क्रम उलटने के लिए दोबारा), कॉलम बदलने के लिए `s` और दिशा उलटने के लिए `S` दबाएं। सॉर्टिंग स्थिर है। इसे `sort` और `onSortChange` से नियंत्रित करें।

<!-- s:6d625a19ed -->
चयन

<!-- s:2132bc20a2 -->
`selectionMode="multiple"` एक चेक कॉलम जोड़ता है; `Space` हाइलाइट की गई पंक्ति का चयन टॉगल करता है। इसे नियंत्रित करने के लिए `selectedKeys` और `onSelectionChange` इस्तेमाल करें, और स्थिर कुंजियों के लिए `getRowKey` इस्तेमाल करें।

<!-- s:3bd95f58e2 -->
`<Tree>`

<!-- s:ec4c582ab8 -->
गाइड वाला एक ट्री जिसे फैलाया जा सकता है।

<!-- s:eeb148154f -->
`→` ब्रांच को फैलाता है या उसके अंदर ले जाता है। `←` ब्रांच को समेटता है या पैरेंट पर ले जाता है। `Space` टॉगल करता है। अगर आपको अपना रेंडरर चाहिए, तो `flattenTree(data, expanded)` दिखाई देने वाली पंक्तियां उपलब्ध कराता है।
