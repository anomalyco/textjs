कंसोल खोलना

<!-- s:14e4fdc5be -->
`http://localhost:3000` पर जाएं और कंसोल खोलें।

<!-- s:a370660339 -->
| ब्राउज़र | macOS | Windows / Linux |
| :-- | :-- | :-- |
| Chrome, Edge, Arc, Brave | `⌘` `⌥` `J` | `Ctrl` `Shift` `J` |
| Firefox | `⌘` `⌥` `K` | `Ctrl` `Shift` `K` |
| Safari | `⌘` `⌥` `C` | सिर्फ़ macOS |

<!-- s:de7134a591 -->
Safari में, पहले सेटिंग → एडवांस्ड में **वेब डेवलपर के लिए सुविधाएं दिखाएं** चालू करें।

<!-- s:8f6c6cf39e -->
पेज को फ़ोकस करने के लिए उस पर क्लिक करें, फिर टाइप करें। DevTools को नीचे डॉक करने से सबसे चौड़ा ग्रिड मिलता है।

<!-- s:9807a8b582 -->
कंसोल सेटिंग

<!-- s:803094bd72 -->
कंसोल सेटिंग में **लॉग सेव करें** बंद करें। Text.js हर फ़्रेम के लिए एक मैसेज जोड़ता है और पुराने फ़्रेम हटाने के लिए कंसोल साफ़ करता है। लॉग सेव करें चालू होने पर, DevTools कंसोल साफ़ करने के निर्देश को अनदेखा करता है और पुराने फ़्रेम जमा होते रहते हैं।
