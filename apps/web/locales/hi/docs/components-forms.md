Text.js में फ़ॉर्म कंट्रोल, डायलॉग और टोस्ट शामिल हैं। हर कंट्रोल `Tab` क्रम में शामिल होता है और `Space` या `Enter` दबाने पर प्रतिक्रिया देता है।

<!-- s:0c4878f82e -->
कंट्रोल

<!-- s:920d5e74e5 -->
| कंपोनेंट | कुंजियां | वैल्यू |
| :-- | :-- | :-- |
| `<Button>` | `↵` `Space` | `onPress` |
| `<Checkbox>` | `Space` `↵` | `checked` / `onChange` |
| `<Switch>` | `Space` `←` `→` | `checked` / `onChange` |
| `<RadioGroup>` | `↑` `↓` (या `←` `→`) | `value` / `onChange` |
| `<Slider>` | `←` `→`, `Shift` ×5, `Home` `End` | `value` / `onChange` |

<!-- s:1c3c5ba8fd -->
ये सभी `autoFocus`, `focused`, `id` और `disabled` स्वीकार करते हैं। कंट्रोल्ड और अनकंट्रोल्ड (`defaultChecked`, `defaultValue`) दोनों काम करते हैं।

<!-- s:0a2857b66b -->
बटन

<!-- s:1981291f42 -->
`variant` की वैल्यू `primary`, `secondary`, `ghost` या `danger` होती है। फ़ोकस होने पर बटन का आकार बदले बिना उसमें एक्सेंट रंग भर जाता है।

<!-- s:56be122300 -->
`<Dialog>`

<!-- s:30940c6b5c -->
विवरण और ऐक्शन की एक पंक्ति वाला `<Modal>`।

<!-- s:7cfec2b258 -->
`<Confirm>`

<!-- s:7e0406516a -->
हां या नहीं। `y` और `n` सीधे जवाब देते हैं; `←` `→` बटनों के बीच ले जाते हैं। `destructive` पुष्टि वाले बटन की स्टाइल तय करता है और पहले रद्द करें बटन पर फ़ोकस करता है।

<!-- s:fecae30a60 -->
टोस्ट

<!-- s:76abda6137 -->
एक `<Toaster />` रेंडर करें, फिर उसी रूट में कहीं भी `useToast()` कॉल करें।

<!-- s:d5c6b1208e -->
| विकल्प | विवरण |
| :-- | :-- |
| `duration` | मिलीसेकंड (डिफ़ॉल्ट `4000`; लोडिंग टोस्ट बने रहते हैं) |
| `id` | किसी टोस्ट को उसी जगह अपडेट करने के लिए दोबारा इस्तेमाल करें |
| `position` | `<Toaster>` पर: `bottom-right` (डिफ़ॉल्ट), `top-center`, … |
| `max` | `<Toaster>` पर: एक साथ दिखने वाले टोस्ट (डिफ़ॉल्ट `3`) |

<!-- s:476f42f2b3 -->
टोस्ट मोडल के ऊपर रेंडर होते हैं और कभी फ़ोकस नहीं लेते।
