ये इनपुट कीबोर्ड से चलते हैं और अपना फ़ोकस खुद संभालते हैं।

<!-- s:1d0d345c65 -->
फ़ोकस

<!-- s:bc06482880 -->
`Tab` और `Shift+Tab` कुंजियां फ़ोकस बदलती हैं। `autoFocus` प्रॉप माउंट होने पर फ़ोकस लेता है।

<!-- s:fca23dd943 -->
फ़ोकस वाले एडिटर अपनी कुंजियों के इवेंट खुद संभालते हैं, इसलिए `1` टाइप करने से कभी ग्लोबल शॉर्टकट ट्रिगर नहीं होता।

<!-- s:7c862ee98e -->
`<Input>`

<!-- s:fdde26d4d9 -->
readline-शैली की एडिटिंग वाला सिंगल-लाइन इनपुट।

<!-- s:88cdcfc0ea -->
| Prop | विवरण |
| :-- | :-- |
| `value` / `onChange` | कंट्रोल्ड वैल्यू |
| `onSubmit` | `Enter` दबाने पर कॉल होता है |
| `placeholder` | खाली होने पर दिखता है |
| `mask` | गोपनीय जानकारी छिपाने के लिए मास्क कैरेक्टर |

<!-- s:995d41e175 -->
`<Textarea>`

<!-- s:cf370a7f95 -->
मल्टी-लाइन कंपोज़र। `Enter` कुंजी सबमिट करती है, `Shift+Enter` शॉर्टकट नई लाइन जोड़ता है।

<!-- s:667b32bc16 -->
`<Select>`

<!-- s:1c8033c766 -->
कीबोर्ड से चलने वाली विकल्प सूची, जिसमें फ़ज़ी सर्च का विकल्प है।

<!-- s:70fe7d6c9b -->
| Prop | विवरण |
| :-- | :-- |
| `options` | `{ value, label, hint?, badge? }[]` |
| `onChange` | `Enter` दबाने पर कॉल होता है |
| `searchable` | टाइप करने से विकल्प फ़िल्टर होते हैं |

<!-- s:958ee46fb6 -->
`<Tabs>`

<!-- s:f61cb509c5 -->
फ़ोकस के बिना कर्सर

<!-- s:f0552feed5 -->
जब पेज से फ़ोकस हटता है, तो कर्सर स्थिर हो जाते हैं और फ़्रेम रुक जाते हैं, ताकि आप कंसोल का टेक्स्ट चुनकर कॉपी कर सकें।
