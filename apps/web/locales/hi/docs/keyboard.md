`useKeymap` हुक से शॉर्टकट एक बार घोषित करें। Text.js उन्हें रूट करता है, `?` ओवरले में सूचीबद्ध करता है, आपके फ़ुटर में दिखाता है और कमांड पैलेट में खोजने योग्य बनाता है।

<!-- s:b084dfc727 -->
`useKeymap`

<!-- s:f944f97e4b -->
| सिंटैक्स | मतलब |
| :-- | :-- |
| `ctrl+k` | मॉडिफ़ायर: `ctrl` `alt` `shift` `meta` `mod` |
| `mod+k` | `⌘` या `Ctrl`, जो भी दबाकर रखा हो |
| `j, down` | विकल्प |
| `g g` | एक क्रम (कुंजियों के बीच 1 सेकंड) |
| `G` | बड़े अक्षर का मतलब `Shift` |
| `?` | प्रिंट करने योग्य कुंजियों का अक्षर से मिलान |

<!-- s:ef55b4b9de -->
वैल्यू एक हैंडलर या `label`, `group`, `hint`, `disabled` और `noRepeat` वाली बाइंडिंग होती है। बिना लेबल वाली बाइंडिंग काम करती हैं, लेकिन हेल्प ओवरले में नहीं दिखतीं।

<!-- s:01f344cdbe -->
`useKeymapBindings()` आपके अपने फ़ुटर और मेन्यू के लिए अभी सक्रिय लेबल वाली बाइंडिंग लौटाता है।

<!-- s:dd8af5eb69 -->
कीमैप `useInput` हुक के ज़रिए चलते हैं, इसलिए सामान्य नियम लागू होते हैं: फ़ोकस वाले इनपुट को प्राथमिकता मिलती है, मेल खाने वाली कुंजी प्रोपेगेशन रोकती है और खुला `<Modal>` कंपोनेंट अपने बाहर की बाइंडिंग बंद कर देता है। इसे बदलने के लिए `{ priority, global, isActive }` पास करें।

<!-- s:da19075700 -->
`<KeyHelp>`

<!-- s:907e2eedda -->
हर लेबल वाली बाइंडिंग को ग्रुप में देखने के लिए `?` दबाएं। यह उस जगह सक्रिय बाइंडिंग की सूची दिखाता है जहां इसे खोला गया था।

<!-- s:3cebb95bfc -->
`<KeyHints>` और `<StatusBar>`

<!-- s:04fa34bd49 -->
`<KeyHints />` कंपोनेंट `hint: true` से चिह्नित बाइंडिंग या स्पष्ट रूप से दिए गए `items` दिखाता है। `<StatusBar>` कंपोनेंट एक पंक्ति का फ़ुटर है जिसमें `right` स्लॉट है।

<!-- s:b9ded39a0a -->
`<Kbd>mod+k</Kbd>` एक कुंजी रेंडर करता है। `formatKeys("ctrl+shift+p")` macOS पर `⌃⇧P` और बाकी जगह `ctrl+shift+P` देता है।

<!-- s:8b6afd6178 -->
`<CommandPalette>`

<!-- s:65192cd436 -->
`Ctrl+K` (या `Ctrl+P`) आपके कमांड और हर लेबल वाली बाइंडिंग के लिए एक फ़ज़ी लॉन्चर खोलता है, जिसमें मेल खाने वाले अक्षर हाइलाइट होते हैं।

<!-- s:e88bab4eab -->
| Prop | विवरण |
| :-- | :-- |
| `commands` | `{ id, label, group?, keys?, keywords?, run }[]` |
| `keys` | खोलने का शॉर्टकट (डिफ़ॉल्ट `ctrl+k, ctrl+p`; बंद करने के लिए `null`) |
| `includeKeymap` | कीमैप बाइंडिंग की सूची (डिफ़ॉल्ट `true`) |
| `open` / `onOpenChange` | कंट्रोल्ड |

<!-- s:ddd093fe85 -->
पैलेट कमांड चलाने से पहले बंद हो जाता है, इसलिए कमांड अपने मॉडाल खोल सकते हैं। आपकी अपनी सूचियों के लिए `fuzzyMatch` और `fuzzyFilter` एक्सपोर्ट किए जाते हैं।
