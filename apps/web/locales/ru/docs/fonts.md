Макет

<!-- s:d143897d5b -->
Горизонтальный макет соответствует флагам FIGlet.

<!-- s:115b8ae91e -->
| `layout` | `figlet` | Эффект |
| :-- | :-- | :-- |
| `"default"` | `-s` | Макет шрифта, обычно со слиянием символов |
| `"full"` | `-W` | Полная ширина; символы не соприкасаются |
| `"fitted"` | `-k` | Кернинг; символы сближаются до соприкосновения |
| `"smushed"` | `-S` | Слияние по правилам шрифта, даже для шрифтов с кернингом |
| `"universal"` | `-o` | Последующие символы перекрывают предыдущие |
| `0`–`63` | `-m` | Явно заданный режим слияния |

<!-- s:d9f3601792 -->
Реализованы все шесть правил горизонтального слияния: одинаковый символ, подчёркивание, иерархия, противоположная пара, большой X и hardblank.

<!-- s:889b1e19ef -->
`verticalLayout` применяется к многострочному тексту. FIGlet 2.2.5 никогда не сближает строки по вертикали, поэтому по умолчанию используется `"full"`; `"fitted"`, `"smushed"` и `"universal"` реализуют пять вертикальных правил, включая суперслияние вертикальных линий, а `"default"` использует правила шрифта.

<!-- s:d4ec30b173 -->
Перенос и выравнивание

<!-- s:f799453d05 -->
`columns` (или `width` в `renderFiglet`) переносит текст сначала по границам слов, затем внутри слова, точно там же, где это сделал бы `figlet -w`. `align` принимает значения `"left"`, `"center"` или `"right"`; если ширина не задана, строки выравниваются по самой широкой строке. Шрифты с направлением справа налево, такие как `ivrit`, выводят текст справа налево и выравнивают его по правому краю; чтобы переопределить это поведение, используйте `direction`.

Каждый глиф состоит из печатных символов ASCII или Latin-1, поэтому каждый составляющий его символ занимает ровно одну ячейку в Menlo в DevTools. `@textjs/font/all` экспортирует все шрифты, а также `BUNDLED_FONTS` для галерей. Шрифты разбираются при первом рендеринге, а не при импорте.

Пользовательские шрифты

<!-- s:093892bc6a -->
Подойдёт любой FIGfont. Загрузите его, затем разберите:

<!-- s:c2f4ef471e -->
Парсер читает заголовок, строки комментариев, hardblank, маркеры конца, 102 обязательных символа и символы с кодовыми метками в десятичной, восьмеричной или шестнадцатеричной системе. Шрифты TOIlet `.tlf` рендерятся как обычный текст. Выбирайте шрифты, нарисованные символами ASCII или псевдографики; в Menlo ширина символов Брайля и эмодзи не равна одной ячейке.

Лицензирование

<!-- s:adad99f0de -->
Шрифты в комплекте побайтно совпадают со шрифтами из дистрибутива FIGlet 2.2.5 и распространяются по лицензии BSD 3-Clause проекта FIGlet. Каждый шрифт сохраняет сведения об авторах в строках комментариев, доступных во время выполнения через `font.comment`. Популярные шрифты без разрешения на распространение, такие как Doom, Larry 3D, ANSI Shadow и Calvin S, в комплект не входят.

Проверка на соответствие `figlet`

<!-- s:111c132fa2 -->
Набор тестов воспроизводит 273 результата вывода, записанных при запуске настоящего бинарного файла `figlet` 2.2.5: каждый шрифт из комплекта во всех режимах макета, перенос, выравнивание, текст справа налево, режим абзацев и собственные входные данные регрессионных тестов FIGlet. Все результаты совпадают в точности.
