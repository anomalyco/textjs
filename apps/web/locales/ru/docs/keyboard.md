Объявите сочетания клавиш один раз с помощью `useKeymap`. Text.js направляет их обработчикам, перечисляет во всплывающей справке `?`, показывает в нижней панели и позволяет искать их в палитре команд.

<!-- s:b084dfc727 -->
`useKeymap`

<!-- s:f944f97e4b -->
| Синтаксис | Значение |
| :-- | :-- |
| `ctrl+k` | Модификаторы: `ctrl` `alt` `shift` `meta` `mod` |
| `mod+k` | `⌘` или `Ctrl`, в зависимости от того, что нажато |
| `j, down` | Альтернативы |
| `g g` | Последовательность (1 секунда между нажатиями) |
| `G` | Верхний регистр подразумевает `Shift` |
| `?` | Печатные клавиши сопоставляются с символом |

<!-- s:ef55b4b9de -->
Значения — это обработчик или привязка с `label`, `group`, `hint`, `disabled` и `noRepeat`. Привязки без названия работают, но не отображаются во всплывающей справке.

<!-- s:01f344cdbe -->
`useKeymapBindings()` возвращает активные в данный момент привязки с названиями для ваших собственных нижних панелей и меню.

<!-- s:dd8af5eb69 -->
Раскладки клавиш работают через `useInput`, поэтому действуют обычные правила: поля ввода в фокусе имеют приоритет, совпавшая клавиша останавливает распространение события, а открытый `<Modal>` отключает привязки за его пределами. Передайте `{ priority, global, isActive }`, чтобы изменить это поведение.

<!-- s:da19075700 -->
`<KeyHelp>`

<!-- s:907e2eedda -->
Нажмите `?`, чтобы увидеть все привязки с названиями, разбитые на группы. Справка перечисляет привязки, активные там, где она открыта.

<!-- s:3cebb95bfc -->
`<KeyHints>` и `<StatusBar>`

<!-- s:04fa34bd49 -->
`<KeyHints />` показывает привязки с отметкой `hint: true` или явно заданные `items`. `<StatusBar>` — однострочная нижняя панель со слотом `right`.

<!-- s:b9ded39a0a -->
`<Kbd>mod+k</Kbd>` отображает одну клавишу. `formatKeys("ctrl+shift+p")` возвращает `⌃⇧P` на macOS и `ctrl+shift+P` на остальных платформах.

<!-- s:8b6afd6178 -->
`<CommandPalette>`

<!-- s:65192cd436 -->
`Ctrl+K` (или `Ctrl+P`) открывает панель запуска с нечётким поиском по вашим командам и всем привязкам с названиями, подсвечивая совпавшие буквы.

<!-- s:e88bab4eab -->
| Prop | Описание |
| :-- | :-- |
| `commands` | `{ id, label, group?, keys?, keywords?, run }[]` |
| `keys` | Сочетание клавиш для открытия (по умолчанию `ctrl+k, ctrl+p`; `null` для отключения) |
| `includeKeymap` | Отображение привязок раскладки клавиш (по умолчанию `true`) |
| `open` / `onOpenChange` | Управляемое состояние |

<!-- s:ddd093fe85 -->
Палитра закрывается перед выполнением команды, поэтому команды могут открывать собственные модальные окна. `fuzzyMatch` и `fuzzyFilter` экспортируются для ваших собственных списков.
