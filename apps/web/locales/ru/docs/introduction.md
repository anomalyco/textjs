Text.js — это фреймворк React для приложений, которые рендерятся в консоли DevTools с помощью `console.log`.

<!-- s:34bf1ea7dd -->
Предпросмотр интерактивен. Щёлкните по нему и нажмите `↑`.

<!-- s:0bccbd98be -->
Что входит в состав

<!-- s:d3708efc68 -->
- **React 19**: конкурентный рендеринг, Suspense и границы ошибок.
- **App Router**: макеты, страницы, динамические сегменты и обработчики маршрутов.
- **Макет Yoga**: flexbox в WebAssembly с привязкой к целым ячейкам.
- **Turbolog**: один вызов `console.log` на каждый изменённый кадр.
- **Интерфейс в консоли**: на странице размещены только панель фокуса и скрытое поле ввода.

<!-- s:5ae438610c -->
Принцип работы

<!-- s:75f47f9f8c -->
Состояние передаётся сверху вниз: React, затем макет, затем буфер ячеек, затем консоль.

<!-- s:25c55610d2 -->
Неизменённые кадры пропускаются, поэтому простаивающие приложения ничего не выводят в консоль.
