Эти примитивы формируют макет сетки ячеек с помощью Yoga flexbox.

<!-- s:00be928124 -->
`<Box>`

<!-- s:cdedc6ec73 -->
Контейнер макета.

<!-- s:b2726c7ef5 -->
| Prop | Описание |
| :-- | :-- |
| `className` | Утилиты для ячеек |
| `border` | `single` `rounded` `double` `heavy` `dashed` |
| `title` | Текст, встроенный в верхнюю границу |
| `bg` / `fg` | Цвет фона и текста |
| `overflow` | `hidden` или `scroll` |

<!-- s:a83221d138 -->
`<Text>`

<!-- s:ea0876c03f -->
Строчный текст. Вложенные `<Text>` становятся span со стилями.

<!-- s:d078a242d3 -->
| Prop | Описание |
| :-- | :-- |
| `color` | Цвет текста |
| `bold` `italic` `underline` `dim` | Атрибуты |
| `wrap` | `wrap` `nowrap` `truncate-end` |

<!-- s:e9a9218253 -->
`<ScrollBox>`

<!-- s:51162fc3b2 -->
Прокручиваемый столбец. `stickyScroll` удерживает прокрутку у нижнего края по мере добавления содержимого.

<!-- s:9029b4d81b -->
`<Modal>`

<!-- s:3804dec517 -->
Центрированный оверлей, который затемняет содержимое под ним и удерживает фокус внутри.

<!-- s:7a128a8b11 -->
Spacer, Divider и Badge

<!-- s:72e5d35050 -->
Вспомогательные компоненты макета

<!-- s:e76299d593 -->
Сокращённые записи для типовых компоновок flex.

<!-- s:0f066fb217 -->
`<SplitPane>`

<!-- s:20cd99b8e7 -->
Две панели и разделитель. С `resizable` разделитель включается в порядок перехода по `Tab`, а `←` `→` меняют размер панелей (с `Shift` на пять ячеек).

<!-- s:2143924860 -->
`size` задаёт долю (`0.3`) или число ячеек (`24`). `direction="column"` располагает панели друг под другом.
