Папки в `app/` определяют маршруты, а специальные файлы определяют интерфейс каждого маршрута.

<!-- s:11f7d9178c -->
Папки

<!-- s:8bda4d61c2 -->
| Папка | Назначение |
| :-- | :-- |
| `app` | Маршруты, макеты и обработчики маршрутов |
| `lib` | Общие модули без маршрутов |
| `public` | Статические ресурсы |

<!-- s:25756fa68d -->
Файлы маршрутизации

<!-- s:8d1e739d99 -->
| Файл | Назначение |
| :-- | :-- |
| `layout.tsx` | Общий интерфейс сегмента |
| `page.tsx` | Экран, доступный по маршруту |
| `loading.tsx` | Запасной интерфейс Suspense |
| `error.tsx` | Граница ошибок |
| `not-found.tsx` | URL без соответствующего маршрута |
| `route.ts` | Конечная точка API |

<!-- s:ed4806a616 -->
Динамические маршруты

<!-- s:7f3bfd19e0 -->
| Папка | URL | `params` |
| :-- | :-- | :-- |
| `[id]` | `/sessions/42` | `{ id: "42" }` |
| `[...slug]` | `/docs/a/b` | `{ slug: ["a", "b"] }` |

<!-- s:854c967567 -->
text.config.ts

<!-- s:144c0672ce -->
| Параметр | По умолчанию | Описание |
| :-- | :-- | :-- |
| `title` | `""` | Заголовок страницы и FocusPad |
| `viewport` | по размеру консоли, иначе `120×36` | `responsive` (по умолчанию `true`), запасной размер `width × height`, `theme` |
| `hints` | `[]` | Две или три клавиши, показанные на FocusPad страницы |
| `action` | `press <first hint>` | Действие после получения фокуса, например `"type a prompt"` |
| `devIndicators` | `true` | Оверлей разработчика в консоли (`[▼]`) |
| `focusHint` | `true` | «Щёлкните по странице, чтобы использовать клавиатуру» над последней строкой консоли, пока страница не в фокусе |
| `rewrites` | `[]` | Перезаписи и прокси |
| `ansi` | `{ cols: 80, rows: 24 }` | Размер кадра для [curl и терминальных клиентов](/docs/curl) или `false`, чтобы отдавать им HTML |

CLI

| :-- | :-- |
