<!-- s:aca2697522 -->
Turbolog превращает каждый коммит React в один вызов `console.log` или не делает вызовов, если ни одна ячейка не изменилась.

<!-- s:d01b048a1d -->
Цели

<!-- s:53b8b34f5a -->
1. **Один вызов на изменённый кадр.**
2. **Ноль вызовов при простое.** Для неизменённого кадра выполнение завершается до построения строки.
3. **Мало аргументов стиля.** 149 span с `%c` для 3200 ячеек плотно заполненной панели `100×32`.

<!-- s:e284ac0068 -->
Конвейер

<!-- s:28cb69fc5d -->
CellBuffer

<!-- s:55cc83174a -->
Кадр хранится в плоских типизированных массивах символов, цветов и атрибутов, память для которых выделяется один раз.

<!-- s:6215aa69f7 -->
Проверка изменений

<!-- s:617da960c4 -->
Для каждой строки вычисляется хеш. Если ничего не изменилось, драйвер завершает выполнение досрочно:

<!-- s:524a0717a4 -->
Смена кадров

<!-- s:3c7194b785 -->
Turbolog дописывает кадры и очищает консоль только при первом кадре, после `invalidate()`, при простое после накопления 100 кадров и при 300 кадрах. DevTools сразу удаляет очищенные сообщения, но отрисовывает новые с ограничением частоты в 50 мс, поэтому очистка при каждом кадре вызывает мигание пустой консоли. Дописанные кадры сменяются за одну отрисовку, а span-завеса нулевой ширины скрывает предыдущий кадр. Прокрутите вверх, чтобы увидеть предыдущие кадры.

<!-- s:7845be2cbb -->
Кадры выводятся с частотой около 15 кадров/с. Более частые кадры сбрасывают таймер ограничения частоты DevTools и отбрасываются.

<!-- s:a36177ad5b -->
Кодирование длин серий

<!-- s:d4079278eb -->
Совпадающие ячейки объединяются в один span с `%c`. Span продолжаются через переносы строк, а строки CSS интернируются.

<!-- s:7fe20496b0 -->
Особенности Chromium

<!-- s:ff8301db1f -->
- Символ `%` экранируется как `%%`.
- В URL и текст вида `path:line` добавляется word joiner, чтобы DevTools не менял их стиль.
- Span используют только полные свойства CSS. DevTools копирует каждое развёрнутое свойство в каждую строку.
- Span настроены так, чтобы фоны стыковались без зазоров.

<!-- s:41e36e3179 -->
Firefox и Safari

<!-- s:8b2f3136a1 -->
Chromium размещает каждую строку span с `%c` как строчный блок. Firefox и Safari оставляют span строчными, поэтому игнорируют вертикальные отступы и переносят длинные строки. `CssConsoleDriver` определяет браузер с помощью проверок поддержки CSS и для этих двух консолей задаёт высоту строки 14 пикселей без отступов, отключает переносы через `text-wrap-mode: nowrap` и скрывает предыдущие кадры с помощью завесы с `line-height: 100vh`. При подгонке под размер консоли остаётся место для столбца ссылок на исходный код в Firefox. Safari ставит Menlo первым в списке шрифтов, потому что его страницы не могут использовать установленный пользователем SF Mono, которым может отрисовывать текст Web Inspector. Передайте `browser` в `createConsoleRoot`, чтобы выбрать консоль самостоятельно.
