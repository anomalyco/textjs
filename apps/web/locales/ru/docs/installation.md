Открыть консоль

<!-- s:14e4fdc5be -->
Перейдите на `http://localhost:3000` и откройте консоль.

<!-- s:a370660339 -->
| Браузер | macOS | Windows / Linux |
| :-- | :-- | :-- |
| Chrome, Edge, Arc, Brave | `⌘` `⌥` `J` | `Ctrl` `Shift` `J` |
| Firefox | `⌘` `⌥` `K` | `Ctrl` `Shift` `K` |
| Safari | `⌘` `⌥` `C` | Только macOS |

<!-- s:de7134a591 -->
В Safari сначала включите **«Показывать функции для веб-разработчиков»** в разделе «Настройки» → «Дополнения».

<!-- s:8f6c6cf39e -->
Щёлкните по странице, чтобы передать ей фокус, затем печатайте. Если закрепить DevTools снизу, сетка будет самой широкой.

<!-- s:9807a8b582 -->
Настройки консоли

<!-- s:803094bd72 -->
Отключите **«Сохранить журнал»** в настройках консоли. Text.js дописывает одно сообщение на кадр и очищает консоль, чтобы освободить старые кадры. Когда параметр «Сохранить журнал» включён, DevTools игнорирует очистку, и старые кадры накапливаются.
