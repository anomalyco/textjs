Задавайте стили компонентов с помощью утилит `className` или типизированных пропсов. В приложениях Text.js нет таблиц стилей.

<!-- s:e0ac1db626 -->
Утилиты

<!-- s:2de571e2bf -->
`className` принимает утилиты в стиле Tailwind. Одна единица равна одной ячейке.

<!-- s:785b2c3db0 -->
| Категория | Примеры |
| :-- | :-- |
| Макет | `flex-row` `grow` `items-center` `gap-1` |
| Отступы | `p-1` `px-2` `mt-1` |
| Границы | `border` `rounded` `border-accent` |
| Цвет | `bg-surface` `text-muted` |

<!-- s:0b98e5506b -->
Типизированные пропсы

<!-- s:4963259a42 -->
У каждой утилиты есть пропс. Пропсы имеют приоритет над `className`.

<!-- s:15a3834a24 -->
Цвета

<!-- s:d333dad27a -->
Используйте шестнадцатеричные коды, названия цветов Tailwind или токены темы, например `fg`, `muted`, `surface`, `accent`, `success` и `danger`. Токены соответствуют активной теме.

<!-- s:087abce968 -->
Темы

<!-- s:abba2a3188 -->
Встроены пять готовых тем: `geistDark`, `geistLight`, `opencodeDark`, `tokyoNight` и `amberCrt`.

<!-- s:5dc490305b -->
