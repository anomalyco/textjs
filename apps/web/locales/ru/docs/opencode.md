[OpenCode](https://opencode.ai) — агент с открытым исходным кодом для написания кода. **OpenCode Lite** — консольный клиент для него, созданный на Text.js.

<!-- s:a0fa47c98f -->
Попробовать

<!-- s:8b5f5ed2de -->
- На этом сайте: перейдите на страницу [OpenCode](/opencode) и откройте DevTools.
- Локально: `bunx create-text-app my-app --template opencode`.

<!-- s:db57075dd8 -->
На сайте работает песочница с агентом, который действует по сценарию. Введите любой промпт.

<!-- s:867840c638 -->
Устройство

<!-- s:7b522f9378 -->
| Область | Компоненты |
| :-- | :-- |
| Переписка | `<ScrollBox stickyScroll>` + `<Markdown>` |
| Карточки инструментов | `<Code>` и `<Diff>` |
| Промпт | `<Textarea>` |
| Палитра | `<Modal>` + `<Select searchable>` |

<!-- s:ae25d36239 -->
Клавиши

<!-- s:9bda94e125 -->
| Клавиша | Действие |
| :-- | :-- |
| `Enter` | Отправить |
| `Shift+Tab` | Переключить агента (build / plan) |
| `Ctrl+P` | Команды |
| `Ctrl+X`, затем `L` | Сессии |
| `Ctrl+X`, затем `N` | Новая сессия |
| `Esc` дважды | Прервать текущую сессию |

<!-- s:b2700ea8eb -->
Подключить локальный сервер

<!-- s:a98495bd7f -->
Оставьте мост запущенным. На [странице OpenCode](/opencode) введите `http://127.0.0.1:4096`, нажмите **Подключить** и разрешите доступ к локальной сети, если Chrome запросит его. Затем введите код сопряжения, который вывел мост. Страница остаётся сопряжённой, пока мост не перезапустится или вы не нажмёте **Отключить**. Используйте URL моста, а не порт сервиса: мост передаёт учётные данные сервиса и заголовки CORS. Завершив работу, остановите его сочетанием Ctrl+C.

<!-- s:7c6a89edc5 -->
Если сервер уже работает на переднем плане на порту 4096, запустите `bunx @textjs/opencode@latest proxy --port 4097 --target http://127.0.0.1:4096` и подключите страницу к порту **4097**. Если сервер на переднем плане защищён паролем, экспортируйте его `OPENCODE_PASSWORD` в оболочке моста; не указывайте пароль в URL браузера.

<!-- s:951b1ef5cb -->
Мост — это пакет `@textjs/opencode`. У него нет зависимостей, и он работает с `npx` на Node 22 или новее. В проекте Text.js команда `text proxy` запускает тот же мост.
