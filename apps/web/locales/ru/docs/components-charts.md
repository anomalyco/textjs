<!-- s:8f99ab8d5a -->
Графики рисуются блочными символами. Столбцы используют восемь уровней на ячейку, а линии — сетку из 2×2 точек на ячейку.

<!-- s:9bd48fe162 -->
`<LineChart>`

<!-- s:79abfce919 -->
Линейные графики из точек с осью Y и легендой.

<!-- s:977778a73f -->
| Prop | Описание |
| :-- | :-- |
| `series` | `{ data, label?, color? }[]` |
| `data` | Сокращённая запись для одного ряда |
| `height` | Строки (по умолчанию `8`) |
| `min` / `max` | Фиксированные границы (по умолчанию: по данным) |
| `axis` | Ось Y с подписями минимума и максимума |
| `formatValue` | Подписи оси (по умолчанию `1.2k`) |
| `marker` | `quadrant` (по умолчанию) или `braille` |

<!-- s:3827b070cb -->
`braille` размещает 2×4 точки в ячейке. Используйте его в терминалах: в Menlo, шрифте консоли DevTools на macOS, нет символов Брайля, а символы из подставляемого шрифта шире ячейки.

<!-- s:a1d8752203 -->
Цвета рядов по умолчанию: `accent`, `success`, `warning`, `info` и `danger`.

<!-- s:58352890aa -->
`<BarChart>`

<!-- s:d57e6053f7 -->
Горизонтальные столбцы с выровненными подписями и значениями, с точностью до одной восьмой ячейки.

<!-- s:2d6e002278 -->
`<Sparkline>`

<!-- s:4bb495c66f -->
Заполняет свою ширину последними точками. При `height` больше `1` рисуется область с заливкой.

<!-- s:9b515e6ed1 -->
`sparkline(values)` возвращает тот же спарклайн в виде строки.

<!-- s:ddc43709d7 -->
`<ProgressBar>`

<!-- s:5455ef1226 -->
| Prop | Описание |
| :-- | :-- |
| `value` / `max` | Прогресс (не указывайте для неопределённого) |
| `variant` | `block` (плавный) `line` `thin` |
| `width` | Ячейки (по умолчанию: заполнение) |
| `label` | Текст в начале |
| `formatValue` | Текст в конце (по умолчанию `42%`) |

<!-- s:39c076d22f -->
Неопределённые индикаторы движутся с частотой кадров рендерера и останавливаются при приостановке вывода.

<!-- s:d5174cb2b9 -->
`<Gradient>`

<!-- s:2239584d9f -->
Интерполяция цвета по ячейкам. Многострочные строки используют один общий градиент, поэтому компонент сочетается с `<AsciiFont>`.

<!-- s:99155d62a4 -->
Именованные градиенты: `geist` `dusk` `ocean` `mono` `ember`.

<!-- s:22dc53f52a -->
`<Image>`

<!-- s:35a4098e50 -->
Консоли Chromium и Firefox рисуют изображение как пиксельный спрайт. Пиксельная графика (256 цветов или меньше, без частично прозрачных пикселей) сохраняет до 8 × 16 пикселей на ячейку, а фотографии — до 4 × 8. В Safari, терминалах, текстовых копиях и на страницах с [`runtime = "server"`](/docs/server-rendering) используются полублоки `▀`: каждая ячейка содержит два пикселя, верхний в цвете текста и нижний в цвете фона. Передайте `renderMode="halfblock"`, чтобы везде рисовать полублоками, как это делал `<Image>` в 1.3.

<!-- s:70bb4fc454 -->
| Prop | Описание |
| :-- | :-- |
| `src` | URL изображения (только в браузере) |
| `pixels` | Необработанные RGBA-данные в виде `{ width, height, data }`, 4 байта на пиксель в порядке строк |
| `width` / `height` | Ширина в ячейках, высота в строках. Передайте одно значение, чтобы сохранить пропорции, или не передавайте оба для 1 × 2 пикселей на ячейку (`src` масштабируется максимум до 256 × 256 пикселей) |
| `fit` | `contain` (по умолчанию), `cover` или `fill` |
| `alt` | Текст, отображаемый во время загрузки `src` или при её ошибке |
| `renderMode` | `auto` (по умолчанию: спрайт там, где поддерживается, полублоки `▀` в остальных случаях) или `halfblock` |

<!-- s:c106665c64 -->
`<Image>` также принимает свойства макета.

<!-- s:20dac26bff -->
`src` загружается через canvas, поэтому изображениям с другого источника нужен CORS. `pixels` принимает необработанные RGBA-данные везде, включая терминал.

<!-- s:4e3b06ef0e -->
Изображение также рисуется полублоками в Chromium и Firefox, когда его нельзя отобразить одним спрайтом:

<!-- s:00d2e660eb -->
- Два изображения рядом в одних и тех же строках, как в галерее.
- Фотография с текстом рядом. Пиксельная графика рядом с текстом остаётся спрайтом.
- Изображение, обрезанное блоком с `overflow="hidden"` или частично перекрытое другим блоком.
- Прозрачные пиксели поверх текста или нескольких цветов фона.

<!-- s:dd4fefaac0 -->
`<Pixels>` (экспериментальный)

<!-- s:71eeeca05d -->
`@textjs/react/experimental` экспортирует `<Pixels>` для обновляемых кадровых буферов `0xRRGGBBAA`, например для игр, эмуляторов и видео. Записывайте упакованные пиксели непосредственно в `source.data` и увеличивайте `frame` для перерисовки.

<!-- s:2d12b69e81 -->
| Prop | Описание |
| :-- | :-- |
| `source` | `{ width, height, data: Uint32Array }` в порядке `0xRRGGBBAA` |
| `frame` | Счётчик кадров; увеличивайте после изменения `source.data` |
| `width` / `height` | Размер блока в ячейках и строках |
| `fit` | `contain` (по умолчанию) или `fill` |
| `pixelAspect` | Отображаемая ширина одного исходного пикселя, делённая на его высоту (по умолчанию `1`) |
| `palette` | Необязательная палитра `PackedColor[]` для квантования цветов |
| `sample` | Фильтр при переходе к полублокам: `nearest` (по умолчанию) или `average` |
| `renderMode` | `auto` (по умолчанию: спрайт там, где поддерживается, полублоки `▀` в остальных случаях) или `halfblock` |

<!-- s:2164b4fe56 -->
`renderMode="auto"` рисует пикселизированный спрайт в Chromium, а в Firefox — согласно правилам стилей его консоли (производительность не измерялась), и переходит к полублокам `▀` в Safari, терминалах, текстовых копиях и на страницах с [`runtime = "server"`](/docs/server-rendering). Передайте `renderMode="halfblock"`, чтобы везде рисовать полублоками.

<!-- s:5d2bbbc47b -->
Чтобы рисовать пиксели без React, импортируйте `drawPixels` из `@textjs/core/experimental` вместе с `DrawPixelsOptions`, `PixelSource`, `PixelFit`, `PixelSample`, `PixelRenderMode`, `PixelEncoding` и `PixelRect`. Его параметр `encoding: "rgba"` сохраняет более 256 цветов и плавную прозрачность для статичных изображений, а `fallback` рисует ваши ячейки везде, где спрайт нельзя отобразить. О версионировании экспериментальных экспортов см. [Несовместимые изменения](/docs/support-policy#breaking-changes).
