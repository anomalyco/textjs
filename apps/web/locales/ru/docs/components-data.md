`<List>`, `<Table>` и `<Tree>` отображают большие наборы данных. Рендерятся только видимые строки.

<!-- s:44ffd1d0a7 -->
Навигация

<!-- s:e3dca4574c -->
`<List>`, `<Table>` и `<Tree>` используют общую модель управления с клавиатуры.

<!-- s:cdac0643be -->
| Клавиши | Действие |
| :-- | :-- |
| `↑` `↓` / `j` `k` | Перемещение |
| `PgUp` `PgDn`, `Ctrl+U` `Ctrl+D` | На страницу, на полстраницы |
| `Home` `End` / `g` `G` | В начало, в конец |
| `↵` | `onSelect` |
| Колесо мыши | Перемещение курсора |

<!-- s:1c65c42a4d -->
По умолчанию они заполняют родительский компонент. Передайте `height`, чтобы задать фиксированное число строк.

<!-- s:3a828804bb -->
`<List>`

<!-- s:2603a57dc8 -->
Виртуализированный список. Высота строки составляет одну ячейку.

<!-- s:3408e68b29 -->
| Prop | Описание |
| :-- | :-- |
| `items` | Любой массив |
| `renderItem` | `(item, { highlighted, focused }) => ReactNode` |
| `isItemDisabled` | Пропуск элемента курсором |
| `height` | Видимые строки (по умолчанию: заполнение) |
| `highlightedIndex` / `onHighlight` | Управляемый курсор |
| `vimKeys` | `j` `k` `g` `G` (по умолчанию `true`) |

<!-- s:55759482eb -->
`<Table>`

<!-- s:ff77c49577 -->
Столбцы делят оставшуюся ширину, если для них не задано `width`. Заголовки и ячейки используют одинаковые правила flex, поэтому всегда выровнены.

<!-- s:e9719839f0 -->
| Поле столбца | Описание |
| :-- | :-- |
| `key` | Идентификатор и ключ доступа по умолчанию |
| `width` / `grow` | Фиксированное число ячеек или доля остатка |
| `align` | `left` `right` `center` |
| `value` | Значение для отображения и сортировки |
| `render` | Пользовательское содержимое ячейки |
| `compare` | Пользовательская сортировка |

<!-- s:045ee40857 -->
Сортировка

<!-- s:d04de39344 -->
При включённом `sortable` нажмите номер столбца для сортировки по нему (повторно для смены направления), `s` для перебора столбцов и `S` для смены направления. Сортировка стабильная. Управляйте ею через `sort` и `onSortChange`.

<!-- s:6d625a19ed -->
Выбор

<!-- s:2132bc20a2 -->
`selectionMode="multiple"` добавляет столбец с флажками; `Space` переключает выбор подсвеченной строки. Используйте `selectedKeys` и `onSelectionChange` для управления выбором, а `getRowKey` для стабильных ключей.

<!-- s:3bd95f58e2 -->
`<Tree>`

<!-- s:ec4c582ab8 -->
Раскрываемое дерево с направляющими линиями.

<!-- s:eeb148154f -->
`→` раскрывает ветвь или переходит в неё. `←` сворачивает ветвь или переходит к родительскому узлу. `Space` переключает состояние раскрытия. `flattenTree(data, expanded)` предоставляет видимые строки, если вам нужен собственный рендерер.
