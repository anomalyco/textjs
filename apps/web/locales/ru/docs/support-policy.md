На этой странице описано, как долго каждая ветка выпусков Text.js получает исправления и что считается несовместимым изменением.

<!-- s:80371443b7 -->
Ветки выпусков

<!-- s:19aa9fdfd3 -->
| Статус | Обновления | Срок |
| :-- | :-- | :-- |
| Активная | Новые функции, исправления, патчи безопасности | До следующего мажорного выпуска |
| LTS в режиме сопровождения | Критические исправления и патчи безопасности | 12 месяцев после выхода следующего мажорного выпуска |
| Поддержка завершена | Нет | — |

<!-- s:d5987f6ecf -->
Исправления получает только последний минорный выпуск каждой мажорной версии: после выхода `1.5.0` исправления попадают в `1.5.x`, а не в `1.4.x`. После выхода `2.0.0` последний минорный выпуск `1.x` становится веткой LTS в режиме сопровождения и публикуется с dist-тегами `lts` и `v1-lts`.

<!-- s:6a7ba75ff1 -->
| Версия | Статус | Срок поддержки |
| :-- | :-- | :-- |
| 1.x | Активная | 12 месяцев после выхода 2.0.0 |

<!-- s:d71377bf9c -->
Исправления в LTS

<!-- s:043b92b499 -->
- Уязвимости безопасности в пакетах Text.js
- Аварийные завершения, потеря данных и сбои сборки без обходного решения
- Совместимость с новыми выпусками Chrome, Edge, Firefox и Safari, которые нарушают рендеринг в консоли
- Совместимость с поддерживаемыми средами выполнения и целевыми платформами развёртывания

<!-- s:e01d1121d2 -->
Новые функции, оптимизации производительности и рефакторинг попадают только в активную ветку.

<!-- s:d1c69ba9bc -->
Несовместимые изменения

<!-- s:82596fcd52 -->
Следующее меняется только в мажорном выпуске, после предупреждения об устаревании хотя бы в одном минорном выпуске:

<!-- s:4ca9fd7807 -->
- Публичные экспорты `@textjs/app`, `@textjs/react` и `@textjs/core`, включая `@textjs/app/server` и `@textjs/app/cache`
- Параметры `text.config.ts`, команды и флаги CLI `text`
- Файловые соглашения в `app/`, `middleware.ts` и конфигурация сегментов маршрута
- Структура выходных файлов адаптеров (`.vercel/output`, `_worker.js`, `dist/server.js`)

<!-- s:3a8ad71311 -->
Гарантии не распространяются на API с пометкой experimental или `unstable_`, включая всё в `@textjs/core/experimental` и `@textjs/react/experimental` (они могут меняться в минорном выпуске с примечаниями в журнале изменений), внутренние API вроде `@textjs/core/internal`, заголовки `x-middleware-*` и метаданные сборки в `.text/`, canary-выпуски, а также точные строки форматирования `console.log` и CSS (кадры остаются визуально идентичными; их кодирование может стать быстрее).

<!-- s:5c7d9aae9b -->
Поддержка сред выполнения

<!-- s:30122ce1bb -->
| Среда выполнения | Поддерживаемые версии |
| :-- | :-- |
| Chrome / Edge DevTools | Текущий и два предыдущих стабильных выпуска |
| Консоли Firefox и Safari | Текущий стабильный выпуск |
| Node.js | Активные выпуски LTS и выпуски LTS в режиме сопровождения (`text start`, функции Vercel) |
| Bun | Последний выпуск 1.x |
| Cloudflare Workers | `compatibility_date` от 2025-01-01, `nodejs_compat` |

<!-- s:509c18536b -->
Прекращение поддержки версии среды выполнения, срок поддержки которой уже истёк, не считается несовместимым изменением.

<!-- s:52543dba9b -->
Безопасность

<!-- s:2aff0514c5 -->
Сообщайте об уязвимостях конфиденциально на [security@textjs.org](mailto:security@textjs.org) или через [уведомления безопасности GitHub](https://github.com/anomalyco/textjs/security/advisories/new). Исправления выходят одновременно для всех поддерживаемых веток, а уведомление публикуется после появления исправленных версий в npm.

<!-- s:b933131934 -->
О том, как создаются версии и dist-теги, читайте в разделе [Каналы выпусков](/docs/release-channels).
