Эти поля ввода управляются с клавиатуры и сами управляют своим фокусом.

<!-- s:1d0d345c65 -->
Фокус

<!-- s:bc06482880 -->
`Tab` и `Shift+Tab` циклически переключают фокус. `autoFocus` устанавливает фокус при монтировании.

<!-- s:fca23dd943 -->
Редакторы в фокусе перехватывают нажатия клавиш, поэтому ввод `1` никогда не активирует глобальное сочетание клавиш.

<!-- s:7c862ee98e -->
`<Input>`

<!-- s:fdde26d4d9 -->
Однострочное поле ввода с редактированием в стиле readline.

<!-- s:88cdcfc0ea -->
| Prop | Описание |
| :-- | :-- |
| `value` / `onChange` | Управляемое значение |
| `onSubmit` | Вызывается при нажатии `Enter` |
| `placeholder` | Отображается в пустом поле |
| `mask` | Символ маски для секретных данных |

<!-- s:995d41e175 -->
`<Textarea>`

<!-- s:cf370a7f95 -->
Многострочное поле ввода. `Enter` отправляет текст, `Shift+Enter` добавляет новую строку.

<!-- s:667b32bc16 -->
`<Select>`

<!-- s:1c8033c766 -->
Список вариантов с управлением с клавиатуры и необязательным нечётким поиском.

<!-- s:70fe7d6c9b -->
| Prop | Описание |
| :-- | :-- |
| `options` | `{ value, label, hint?, badge? }[]` |
| `onChange` | Вызывается при нажатии `Enter` |
| `searchable` | Ввод текста фильтрует варианты |

<!-- s:958ee46fb6 -->
`<Tabs>`

<!-- s:f61cb509c5 -->
Курсор без фокуса

<!-- s:f0552feed5 -->
Когда страница теряет фокус, курсоры замирают и кадры перестают обновляться, чтобы вы могли выделить и скопировать текст консоли.
