Эти компоненты отображают Markdown, код, различия и крупные надписи на сетке ячеек.

<!-- s:10d1e663ca -->
`<Markdown>`

<!-- s:842bba9c18 -->
Markdown с поддержкой потокового вывода. Передавайте растущую строку, и кадр останется стабильным.

<!-- s:f6f3074d02 -->
`<Code>`

<!-- s:e3dec08834 -->
Подсветка синтаксиса для `ts`, `tsx`, `json`, `bash`, `python`, `rust`, `go` и других языков.

<!-- s:e75addc84e -->
| Prop | Описание |
| :-- | :-- |
| `language` | Идентификатор языка |
| `showLineNumbers` | Поле номеров строк |
| `highlightLines` | Строки для подсветки |
| `maxHeight` | Обрезка с пометкой «ещё строки» внизу |

<!-- s:14338ded97 -->
`<Diff>`

<!-- s:ec6578a933 -->
Различия в формате unified diff или вычисленные из `{ before, after }`.

<!-- s:4fb43d4ba9 -->
`<Spinner>`

<!-- s:502520871a -->
Варианты: `dots`, `pulse`, `matrix`, `line` и `braille` (для терминалов; в Menlo нет символов Брайля). Во время паузы таймеры останавливаются.

<!-- s:b252598191 -->
`<AsciiFont>`

<!-- s:2cf13f8260 -->
Крупные пиксельные надписи для заголовков.

<!-- s:d3f90f7b9b -->
Используйте `font="compact"` для варианта высотой в 3 строки. Передайте шрифт FIGlet из [`@textjs/font`](/docs/fonts), например `font={slant}`, для надписей в стиле FIGlet.
