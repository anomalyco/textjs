`@textjs/app/testing` (или `@textjs/react/testing`) рендерит ваше приложение за пределами экрана, нажимает клавиши и возвращает кадр в виде текста. Тесты выполняются без браузера и DevTools.

<!-- s:9bc71b1ad2 -->
Это работает с любым инструментом запуска тестов, который поддерживает `async`-тесты, включая Bun, Vitest и Jest.

<!-- s:f7898e6b92 -->
Рендеринг

<!-- s:fc969a7928 -->
| Метод | Описание |
| :-- | :-- |
| `render(el, { cols, rows, theme })` | Монтирование за пределами экрана (по умолчанию 80×24) |
| `lastFrame()` | Кадр в виде обычного текста |
| `lines()` | Кадр в виде массива строк |
| `frames` | Все различающиеся кадры на текущий момент |
| `toAnsi()` | ANSI с Truecolor для снимков |
| `cell(x, y)` | `{ char, fg, bg, attrs }` |
| `locate(text)` | `{ x, y }` первого совпадения |
| `rerender(el)` / `unmount()` | Обновление или размонтирование |

<!-- s:893f22353a -->
`renderToString(el, options)` рендерит один раз и возвращает текст.

<!-- s:99a3c4d459 -->
Ввод

<!-- s:105149560b -->
Каждый вызов выполняется внутри `act()` и дожидается вывода полученных кадров, поэтому следующая проверка видит обновление.

<!-- s:1f65c071dc -->
Время

<!-- s:ab365d9403 -->
Анимации, индикаторы загрузки и всплывающие уведомления используют реальные таймеры, поэтому `wait` и `waitFor` позволяют надёжно отслеживать их.

<!-- s:26f93acae3 -->
Снимки

<!-- s:05724c9883 -->
Пустое пространство справа и снизу кадра обрезается, поэтому снимки не меняются из-за пробельных символов.
