`text run` рендерит приложение App Router в терминале. Макет, компоненты, раскладки клавиш и обработчики маршрутов используются и в браузере. Вывод использует truecolor ANSI вместо span с `%c`.

<!-- s:7d8aa376e3 -->
Нажмите `Ctrl+C` для выхода. Для `text run` нужен Bun.

<!-- s:eed3d00ac7 -->
`text run`

<!-- s:36358c3ead -->
`text run` импортирует каждый файл в `app/`, монтирует App Router с историей в памяти и отрисовывает его на весь экран. `<Link>`, `useRouter()`, `notFound()` и `redirect()` работают без изменений.

<!-- s:75b65c161d -->
Вызовы `fetch("/api/...")` к тому же источнику запускают ваши обработчики `route.ts` в текущем процессе, точно так же, как их обслуживает `text dev`. Запросы к другим URL отправляются в сеть.

`renderToTerminal`

<!-- s:1bcde87690 -->
Для отдельного компонента или собственного CLI:

<!-- s:e62e62bfaa -->
`useApp().exit()` размонтирует приложение и восстанавливает терминал.

<!-- s:082b75dda7 -->
| Параметр | Описание |
| :-- | :-- |
| `stdin` / `stdout` | По умолчанию `process.stdin` / `process.stdout` |
| `cols` / `rows` | Фиксированный размер (по умолчанию: по размеру терминала) |
| `altScreen` | Восстановление истории прокрутки при выходе (по умолчанию `true`) |
| `mouse` | Прокрутка колёсиком (по умолчанию `true`) |
| `exitOnCtrlC` | По умолчанию `true` |
| `fps` | Предел частоты кадров (по умолчанию `60`) |
| `patchConsole` | Задержка вывода `console.*` до выхода (по умолчанию `true`) |
| `theme` / `transparent` | Как в `createConsoleRoot` |

<!-- s:e34e364b9c -->
Вывод

<!-- s:2ac174afda -->
Каждый кадр сравнивается с предыдущим построчно. Записываются только изменённые строки, обрамлённые маркерами синхронизированного вывода, поэтому терминалы с их поддержкой никогда не показывают частично отрисованный кадр. Простаивающие приложения ничего не записывают.

<!-- s:99a3c4d459 -->
Ввод

<!-- s:4a9817d820 -->
Ввод stdin в необработанном режиме преобразуется в те же события, что создаёт браузер: стрелки и функциональные клавиши с модификаторами, комбинации с `Alt`, вставка с маркерами, колёсико мыши SGR и клавиатурный протокол kitty. `TerminalInputParser` и `parseTerminalInput` экспортируются, если они нужны вам в другом месте.
