Text.js включает элементы управления формами, диалоги и всплывающие уведомления. Каждый элемент управления включается в порядок обхода по `Tab` и реагирует на `Space` или `Enter`.

<!-- s:0c4878f82e -->
Элементы управления

<!-- s:920d5e74e5 -->
| Компонент | Клавиши | Значение |
| :-- | :-- | :-- |
| `<Button>` | `↵` `Space` | `onPress` |
| `<Checkbox>` | `Space` `↵` | `checked` / `onChange` |
| `<Switch>` | `Space` `←` `→` | `checked` / `onChange` |
| `<RadioGroup>` | `↑` `↓` (или `←` `→`) | `value` / `onChange` |
| `<Slider>` | `←` `→`, `Shift` ×5, `Home` `End` | `value` / `onChange` |

<!-- s:1c3c5ba8fd -->
Все они принимают `autoFocus`, `focused`, `id` и `disabled`. Поддерживаются как управляемый, так и неуправляемый (`defaultChecked`, `defaultValue`) режимы.

<!-- s:0a2857b66b -->
Кнопки

<!-- s:1981291f42 -->
`variant` принимает значения `primary`, `secondary`, `ghost` или `danger`. При фокусе кнопка заполняется акцентным цветом без изменения размера.

<!-- s:56be122300 -->
`<Dialog>`

<!-- s:30940c6b5c -->
Компонент `<Modal>` с описанием и строкой действий.

<!-- s:7cfec2b258 -->
`<Confirm>`

<!-- s:7e0406516a -->
Да или нет. `y` и `n` отвечают напрямую; `←` `→` перемещают фокус между кнопками. `destructive` задаёт оформление кнопки подтверждения и сначала устанавливает фокус на кнопку «Отмена».

Всплывающие уведомления

<!-- s:76abda6137 -->
Отрендерите один `<Toaster />`, затем вызывайте `useToast()` в любом месте того же корня.

<!-- s:d5c6b1208e -->
| Параметр | Описание |
| :-- | :-- |
| `duration` | Миллисекунды (по умолчанию `4000`; уведомления о загрузке остаются) |
| `id` | Повторное использование для обновления уведомления на месте |
| `position` | У `<Toaster>`: `bottom-right` (по умолчанию), `top-center`, … |
| `max` | У `<Toaster>`: число одновременно видимых уведомлений (по умолчанию `3`) |

<!-- s:476f42f2b3 -->
Всплывающие уведомления отображаются поверх модальных окон и никогда не забирают фокус.
