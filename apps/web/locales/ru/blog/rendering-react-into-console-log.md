Text.js рендерит React-приложения в консоли Chrome DevTools. Кроме скрытого поля ввода, на странице нет интерфейса. Каждый кадр приложения — один вызов `console.log`.

<!-- s:fe9cd991d4 -->
Консоль как дисплей

<!-- s:5ae20a07fc -->
`console.log` принимает строку формата. Каждый `%c` применяет CSS из следующего аргумента к тексту после него, вплоть до следующего `%c`:

<!-- s:2822a0243c -->
Эти стили позволяют задавать цвета, фон, полужирное и курсивное начертание и подчёркивание, а шрифт консоли — моноширинный (Menlo в macOS). Благодаря моноширинному шрифту и цветам, которые могут меняться для каждой последовательности символов, консоль работает как сетка символьных ячеек со стилями. На ней можно рисовать границы, панели, поля ввода и графики.

<!-- s:585742694b -->
Кадр как сетка ячеек

<!-- s:04a12244bc -->
Рендерер хранит каждый кадр в `CellBuffer`. Символы находятся в одном типизированном массиве, цвета текста и фона — ещё в двух, а атрибуты вроде полужирного начертания и подчёркивания — в четвёртом. Массивы выделяются один раз для заданного размера и повторно используются для каждого кадра.

<!-- s:2ff86351b3 -->
Чтобы вывести кадр, драйвер обходит каждую строку и объединяет соседние ячейки с одинаковым стилем в последовательности. Каждая последовательность становится одним span с `%c`, а строки соединяются через `\n`. Наша тестовая панель размером 100×32, то есть 3200 ячеек, кодируется примерно в 200 span.

<!-- s:48a9b4f008 -->
Один вызов на кадр

<!-- s:aa2cafe395 -->
Выводить каждую строку отдельным сообщением не получится. Каждое сообщение получает собственную рамку и ссылку на исходный код в DevTools, а одинаковые последовательные сообщения DevTools сворачивает за счётчиком повторов, поэтому две одинаковые строки таблицы слились бы в одну. Кадр, выведенный одним сообщением, остаётся целым.

<!-- s:ea38228d16 -->

Кадры без изменений без вывода в консоль

Для каждой строки буфера вычисляется хеш. Если с прошлого кадра ни один хеш не изменился, драйвер завершает работу до сборки строки и не обращается к консоли. Приложение, ожидающее ввода, не делает вызовов.

Ввод

<!-- s:e95aae4719 -->
Консоль не получает нажатия клавиш, поэтому их собирает страница. Скрытый `<textarea>` принимает нажатия клавиш, вставку и композицию IME и превращает их в события клавиатуры для приложения. Щелчок по странице переводит на него фокус.
