Сегодня мы выпускаем Text.js 1.0, консольный фреймворк для веба.

<!-- s:e4787165f5 -->
Text.js рендерит приложения React 19 в консоли Chrome DevTools: макеты, маршрутизацию, фокус, ввод, формы, графики и потоковый Markdown отрисовывает `console.log`.

<!-- s:48b184a262 -->
Что вошло в 1.0

<!-- s:7f7f2a9a76 -->
- **App Router.** `layout.tsx`, `page.tsx`, `[param]`, `loading.tsx`, `error.tsx`, `not-found.tsx` и `api/*/route.ts`, синхронизированные с `window.location`. Он следует соглашениям Next.js App Router.
- **Turbolog.** Yoga flexbox размещает сетку ячеек, `CellBuffer` на основе типизированных массивов хранит её, а кодировщик серий превращает её в один вызов `console.log(format, ...css)`. Кадры без изменений не вызывают консоль.
- **Набор компонентов.** `Box`, `Text`, `ScrollBox`, `Input`, `Select`, `Tabs`, `Markdown`, `Diff`, виртуализированный `List`, `Table`, `Tree`, графики, диалоги, всплывающие уведомления и палитра команд `Ctrl+K` на основе `useKeymap`.
- **Дописываемые кадры.** Кадры дописываются ниже предыдущего, поэтому консоль не вспыхивает пустотой между кадрами. Подробнее об этом в статье [Turbolog: устранение мерцания](/blog/turbolog-eliminating-the-flash).
- **Текст справа налево.** Иврит и арабский отображаются в визуальном порядке с формообразованием арабских букв благодаря реализации UAX #9, которая проходит все 770 241 тест из `BidiTest.txt`. См. [Текст справа налево в консоли](/blog/right-to-left-text).
- **Адаптивная консоль.** Text.js подстраивается под закреплённую панель DevTools, учитывая масштаб страницы и переносы панели инструментов. В отдельном окне используется размер `120×36`.
- **`text run`.** То же приложение App Router рендерится в настоящем терминале.
- **Инструменты для агентов и редакторов.** `text mcp` предоставляет ваше приложение агентам программирования через Model Context Protocol, а расширение Text.js DevTools добавляет панель рядом с «Консолью». `eslint-plugin-textjs` и расширение для VS Code тоже входят в 1.0.

Одно переименование

<!-- s:b47aa37902 -->
Пакет фреймворка теперь называется `@textjs/next`. Имя `textjs` было занято в npm. Обновите импорты:

<!-- s:e4005009f1 -->
**Обновление, 1.0.2:** пакет теперь называется `@textjs/app`, а `@textjs/next` устарел. Чтобы перейти, выполните `bun remove @textjs/next && bun add @textjs/app` и импортируйте из `@textjs/app`.

Числа

<!-- s:2ee54da34c -->
На плотно заполненной панели `100×32` (46 текстовых узлов, 149 span `%c`), измерено с помощью `packages/core/test/perf.test.ts`:

<!-- s:9729def172 -->
| Кадр | Среднее |
| :-- | --: |
| Полная перерисовка (расчёт макета, отрисовка, кодирование) | 0,163 мс |
| Изменение одной строки (ввод текста) | 0,011 мс |
| Без изменений | 0,000 мс, 0 вызовов консоли |

<!-- s:2fee8c4c3d -->
Обработка неизменившегося кадра завершается до выделения памяти под строку, поэтому кадры без изменений занимают 0,000 мс.

Попробовать

<!-- s:aeb9cc2b5d -->
Откройте [textjs.org](/) и нажмите ⌘⌥J (Ctrl+Shift+J в Windows и Linux). Сайт запускает приложение Text.js в вашей консоли, по одному представлению на страницу. В [Playground](/playground) есть панель показателей, потоковый Markdown и «Змейка». [OpenCode](/opencode) подключается к вашему локальному серверу OpenCode.
