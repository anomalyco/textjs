Mở console

<!-- s:14e4fdc5be -->
Truy cập `http://localhost:3000` và mở console.

<!-- s:a370660339 -->
| Trình duyệt | macOS | Windows / Linux |
| :-- | :-- | :-- |
| Chrome, Edge, Arc, Brave | `⌘` `⌥` `J` | `Ctrl` `Shift` `J` |
| Firefox | `⌘` `⌥` `K` | `Ctrl` `Shift` `K` |
| Safari | `⌘` `⌥` `C` | Chỉ macOS |

<!-- s:de7134a591 -->
Trong Safari, trước tiên bật **Hiển thị tính năng dành cho nhà phát triển web** trong Cài đặt → Nâng cao.

Cài đặt console

<!-- s:803094bd72 -->
Tắt **Lưu giữ nhật ký** trong cài đặt console. Text.js nối thêm một thông báo cho mỗi frame và xóa console để giải phóng các frame cũ. Khi bật Lưu giữ nhật ký, DevTools bỏ qua lệnh xóa và các frame cũ tích tụ lại.
