控制台是由单元格组成的网格。Text.js 使用 Yoga 布局，它也是 React Native 使用的 flexbox 引擎，因此 `<Box>` 遵循 CSS flexbox 规则。尺寸以单元格为单位：`p-1` 表示一列和一行的内边距。

<!-- s:029cc40e38 -->
顶部栏

<!-- s:4708298213 -->
大多数界面采用纵向布局：先是一行高的顶部栏，再是其余内容。用 `h-1` 为顶部栏设置固定高度，用 `grow` 让内容占据剩余空间。

<!-- s:5f781355bb -->
`<Spacer>` 是一个可扩展的盒子：它后面的所有内容都会被推到右边缘。

<!-- s:0c01f22e11 -->
侧边栏和卡片

<!-- s:7bf034d9ab -->
添加一个带右边框的固定宽度侧边栏，以及三张平分剩余宽度的卡片。`basis-0` 配合 `grow` 可让每张卡片获得相同的宽度，不受内容影响。

<!-- s:493f8816f0 -->
在控制台中按 `s` 和 `d`。Yoga 会重新计算布局，并且只重绘发生变化的行，因此切换侧边栏只需一次 `console.log`。

<!-- s:66bd0231a6 -->
默认支持响应式布局

<!-- s:7d3f8e46eb -->
网格随停靠的 DevTools 面板调整大小。拖动控制台以增加宽度或高度，卡片就会重新排列。需要断点时，`useBreakpoint()` 会返回当前断点，以单元格为单位。
