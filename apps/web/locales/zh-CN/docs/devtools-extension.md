<!-- s:263d7e4a86 -->
Text.js DevTools 扩展在控制台旁添加一个 **Text.js** 面板，用于检查正在控制台中渲染的应用。

<!-- s:becd3b25ff -->
- **组件：**每个控制台根节点的 React 树，包含 props、Hook、key，以及背后的 `tx-box` / `tx-text` 场景节点，按单元格布局。
- **帧：**以单元格网格显示当前帧。悬停在单元格上可查看绘制它的组件。点击可选择节点。该节点会在实时控制台中高亮显示。
- **时间线：**每帧的 React、布局、绘制和编码耗时，跳过与输出的帧、帧间隔以及 `%c` span。
- **控制：**暂停和恢复输出，切换布局线框，固定或自动适配网格大小，将帧复制为文本。

<!-- s:98304b8243 -->
安装

<!-- s:2452819f12 -->
从 `packages/devtools-extension` 构建扩展，然后以解压缩形式加载：

<!-- s:3754c750b3 -->
1. 打开 `chrome://extensions`，启用**开发者模式**。
2. 点击**加载已解压的扩展程序**，选择 `packages/devtools-extension/dist`。
3. 重新加载应用并打开 DevTools。页面创建控制台根节点后，**Text.js** 面板就会出现。

<!-- s:e0c59fa53a -->
构建还会生成 `release/textjs-devtools-<version>.zip`，可直接提交到 Chrome 应用商店。

<!-- s:364bc3ef6f -->
组件

<!-- s:e1204a3559 -->
选择组件可查看其 props、按调用顺序排列的 Hook（`State`、`Ref`、`Memo`、`Effect` 等，含当前值），以及它渲染的场景节点，包括以单元格为单位的位置、大小和盒内边距。悬停在某一行上会在控制台中高亮显示该节点。**宿主节点**用于显示或隐藏组件之间的 `tx-box` 和 `tx-text` 元素。

<!-- s:77b62adc9c -->
面板打开时，树会在提交后刷新。显示的值是摘要，并非实时对象。

<!-- s:a0d819048c -->
帧

<!-- s:2cceea6000 -->
帧检查器绘制渲染器的单元格缓冲区：每个字形、前景色、背景色和属性。悬停在单元格上会显示其字符和颜色、按绘制顺序位于其最上层的场景节点（遵循 `overflow`、滚动偏移和 `zIndex`），以及渲染该节点的组件。点击会在**组件**中选中该节点，并通过渲染器自身的高亮覆盖层在实时控制台中高亮显示它。

<!-- s:57a8990372 -->
时间线

<!-- s:2187cf7a17 -->
每根柱表示渲染器的一帧：

<!-- s:f53def4922 -->
| 阶段 | 测量内容 |
| --- | --- |
| React | 帧开始时同步执行完毕的 React 工作 |
| 布局 | Yoga 布局 |
| 绘制 | 将场景栅格化到单元格缓冲区 |
| 编码 | 构建 `%c` 格式字符串并调用 `console.log()` |

<!-- s:9b988f3cfb -->
跳过的帧以淡色显示：没有变化，因此没有输出日志。帧间隔图表以 66 ms 的最小间隔为参照，显示输出帧之间的间隔。

<!-- s:8abccb04ec -->
计时止于 `console.log()`。消息的格式化和绘制发生在 DevTools 内部，页面无法观测，因此时间线不显示这些耗时。在帧之间提交的并发渲染会计入提交次数，但不计时。

<!-- s:5ae438610c -->
工作原理

<!-- s:1dda342130 -->
与 React DevTools 一样，扩展会在页面运行前安装一个全局 Hook：

<!-- s:9a7af3e89c -->
每个控制台根节点都会向这个 Hook 注册。页面上的第一个根节点会加载与面板通信的代码（gzip 压缩后约 5 KB），并在代码加载完成后注册。后续根节点在创建时注册。未安装扩展时，这个 Hook 不存在，因此根节点只检查一次，不加载任何代码，也不执行逐帧工作。安装扩展但关闭面板时，每帧的开销是读取一次属性。只有面板请求时，才会计算树和帧。

<!-- s:843fc9a8ad -->
消息流向为页面 → 内容脚本 → Service Worker → 面板。内容脚本在每个页面上运行，确保 Hook 在应用启动前就已存在。这是扩展请求的唯一访问权限。扩展不加载远程代码，也不向本机之外发送任何内容。

<!-- s:e425f181df -->
隐私

<!-- s:f2cd52a110 -->
扩展不收集任何数据。不发起网络请求，不存储任何内容，也不做分析统计。组件树、帧和耗时数据仅在同一浏览器的页面与 DevTools 面板之间传递，关闭 DevTools 后即丢弃。点击**复制帧**会将该帧的文本写入剪贴板。

<!-- s:639d5ea4c0 -->
限制

<!-- s:05616a1196 -->
- 支持 Chrome 和基于 Chromium 的浏览器，版本需为 111 或更高。
- 安装扩展前已启动的应用需要重新加载。
- 仅检查标签页的顶层框架。
- 面板连接后，时间线才开始记录帧。
- 耗时取自 `performance.now()`，浏览器会将其精度降低至约 0.1 ms。
