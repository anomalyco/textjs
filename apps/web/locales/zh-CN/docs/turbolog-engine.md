<!-- s:aca2697522 -->
Turbolog 将每次 React 提交转换为一次 `console.log` 调用；如果没有单元格变化，则不调用。

<!-- s:d01b048a1d -->
目标

<!-- s:53b8b34f5a -->
1. **每个发生变化的帧只调用一次。**
2. **空闲时零调用。** 未变化的帧在构建字符串之前就返回。
3. **少量样式参数。** 密集的 `100×32` 仪表盘包含 3200 个单元格，只需 149 个 `%c` span。

<!-- s:e284ac0068 -->
处理流水线

<!-- s:28cb69fc5d -->
CellBuffer

<!-- s:55cc83174a -->
帧存储在用于字符、颜色和属性的扁平类型化数组中，这些数组只分配一次。

<!-- s:6215aa69f7 -->
变化检测关卡

<!-- s:617da960c4 -->
每行都会计算哈希值。如果没有变化，驱动程序会提前返回：

<!-- s:524a0717a4 -->
帧切换

<!-- s:3c7194b785 -->
Turbolog 追加帧，仅在首帧、调用 `invalidate()` 之后、累积 100 帧后的空闲时以及达到 300 帧时清空控制台。DevTools 会立即移除已清空的消息，但以 50 ms 的节流间隔绘制新消息，因此每帧都清空会导致控制台闪现空白。追加的帧在一次绘制中完成切换，零宽度的幕帘 span 将上一帧挡在视野之外。向上滚动可查看更早的帧。

<!-- s:7845be2cbb -->
帧速率控制在约 15 fps。更快的帧会重置 DevTools 的节流计时并被丢弃。

<!-- s:a36177ad5b -->
游程编码

<!-- s:d4079278eb -->
样式相同的单元格合并为一个 `%c` span。span 可跨越换行符，CSS 字符串则通过驻留机制复用。

<!-- s:7fe20496b0 -->
Chromium 细节

<!-- s:ff8301db1f -->
- 字面量 `%` 转义为 `%%`。
- URL 和 `path:line` 文本会插入 word joiner，防止 DevTools 重新设置其样式。
- span 仅使用 CSS 长属性。DevTools 会将每个展开后的属性复制到每一行。
- span 经过调整，使背景平铺时不留间隙。

<!-- s:41e36e3179 -->
Firefox 和 Safari

<!-- s:8b2f3136a1 -->
Chromium 将 `%c` span 的每一行布局为行内块。Firefox 和 Safari 则保持 span 的行内布局，因此会忽略垂直外边距，并将长行折行。`CssConsoleDriver` 通过 CSS 特性检测识别浏览器，并为这两个控制台设置 14 px 行高且不留外边距，使用 `text-wrap-mode: nowrap` 关闭折行，再通过 `line-height: 100vh` 幕帘将更早的帧推到视野之外。适配控制台尺寸时会为 Firefox 的源码链接列预留空间。Safari 将 Menlo 放在字体栈首位，因为页面无法使用用户安装的 SF Mono，而 Web Inspector 可能使用该字体绘制。向 `createConsoleRoot` 传入 `browser` 可自行选择控制台。
