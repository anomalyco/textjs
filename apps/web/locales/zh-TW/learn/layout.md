主控台是由儲存格組成的網格。Text.js 使用 Yoga 配置版面，這也是 React Native 使用的 flexbox 引擎，因此 `<Box>` 遵循 CSS flexbox 規則。單位是儲存格：`p-1` 表示一欄寬、一列高的內距。

<!-- s:029cc40e38 -->
頂端列

<!-- s:4708298213 -->
多數畫面採垂直排列：先放一列高的頂端列，其餘內容接在下方。使用 `h-1` 固定頂端列的高度，再用 `grow` 讓內容佔滿剩餘空間。

<!-- s:5f781355bb -->
`<Spacer>` 是會擴展的方塊：放在後面的內容都會推到右側邊緣。

<!-- s:0c01f22e11 -->
側邊欄與卡片

<!-- s:7bf034d9ab -->
加入帶有右邊框的固定寬度側邊欄，以及平分剩餘寬度的三張卡片。`basis-0` 搭配 `grow` 可讓每張卡片獲得相同寬度，不受內容影響。

<!-- s:493f8816f0 -->
在主控台按下 `s` 和 `d`。Yoga 會重新計算版面配置，並且只重繪有變動的列，因此切換側邊欄只需呼叫一次 `console.log`。

<!-- s:66bd0231a6 -->
預設支援響應式版面配置

<!-- s:7d3f8e46eb -->
網格會配合停駐的 DevTools 面板調整。拖曳主控台使其變寬或變高，卡片就會重新排列。需要斷點時，`useBreakpoint()` 會回傳目前的斷點，以儲存格為單位。
