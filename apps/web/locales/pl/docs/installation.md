Otwieranie konsoli

<!-- s:14e4fdc5be -->
Wejdź na `http://localhost:3000` i otwórz konsolę.

<!-- s:a370660339 -->
| Przeglądarka | macOS | Windows / Linux |
| :-- | :-- | :-- |
| Chrome, Edge, Arc, Brave | `⌘` `⌥` `J` | `Ctrl` `Shift` `J` |
| Firefox | `⌘` `⌥` `K` | `Ctrl` `Shift` `K` |
| Safari | `⌘` `⌥` `C` | tylko macOS |

<!-- s:de7134a591 -->
W przeglądarce Safari najpierw włącz **„Pokazuj funkcje dla deweloperów witryn”** w sekcji Ustawienia → Zaawansowane.

<!-- s:8f6c6cf39e -->
Kliknij stronę, aby ustawić na niej fokus, a następnie pisz. Zadokowanie DevTools na dole zapewnia najszerszą siatkę.

<!-- s:9807a8b582 -->
Ustawienia konsoli

<!-- s:803094bd72 -->
Wyłącz **„Zachowaj dziennik”** w ustawieniach konsoli. Text.js dopisuje jeden komunikat na klatkę i czyści konsolę, aby zwolnić stare klatki. Przy włączonej opcji „Zachowaj dziennik” DevTools ignoruje czyszczenie i stare klatki się gromadzą.
