# French (fr)

- Address the reader as vous in docs, UI and marketing. Never tu. Instructions use the imperative: « Exécutez `bun dev` », « Ouvrez la console ».
- Headings and labels are noun phrases or infinitives without a period: « Installation », « Ouvrir la console », « Regrouper les routes ». Sentence case: only the first word and proper names take a capital.
- Put a narrow no-break space (U+202F) before : ; ! ? and inside « » guillemets: « Conserver le journal ». Never add these spaces inside code, paths, URLs or Markdown link targets. No space before a period or comma.
- Browser interface labels go in « » and match Chrome's French interface: « Conserver le journal », « Paramètres ». The Console panel is « Console ».
- Decimal comma, and a no-break space (U+00A0) before units and the percent sign in prose: 0,163 ms, 70,6 %, 66 ms, 21 kB. Thousands take a narrow no-break space from five digits: 3200 cellules, 12 000 frames. Never touch version numbers (Bun 1.2+, Node.js 22+, 1.4.1), numbers in code, paths or URLs.
- Dates read 3 novembre 2026. Ranges use an en dash: 70–81 %.
- Accented capitals keep their accents (À, É).
- Genders: la console, la frame (les frames), la route, le layout, le hook, le composant, le thème, le span, l’application.
- Use the typographic apostrophe (’) in prose; ASCII ' stays in code.
- Keep API names, components, hooks, file paths, CLI commands and keyboard shortcuts (⌘⌥J, Ctrl+Shift+J, Enter) exactly as written.
- In a list or table, keep items parallel: all noun phrases, or all full sentences.
- Avoid translationese and filler: no « Il est important de noter que », « Notez que » as an opener, « simplement », « facilement », « en toute simplicité », « puissant », « fluide », « sans effort », « n’hésitez pas à », « Découvrons », rhetorical questions, dramatic tirets or « non seulement… mais aussi ». Prefer active voice to « est effectué par ». Use « permet de » sparingly.
- Marketing copy keeps the deadpan tone: the console-as-production-UI premise is stated straight, never explained or winked at.
- Names kept in English: the Enterprise plan, the Playground and the course Learn Text.js. The Learn section and nav are « Apprendre ».
- Merch print slogans stay in English: « YOU WOULDN’T RENDER A WEBSITE IN THE CONSOLE ».

## Focus pad

- The console pad's actions finish the sentence “Then click here and {action}.” Translate each action as the form that fits that slot. « Puis cliquez ici et {action}. » : {action} est un impératif en vous qui termine la phrase : « tapez », « appuyez sur ↑ ↓ », « saisissez un prompt ».
- “type” is the verb (type on the keyboard), never a data type. “Custom size” is the size picker's option for entering your own columns and rows.
- Hint labels under the keycaps are one or two lowercase words: « retour », « détails », « panier ».

## Captions

- Subtitle style: about 17 characters per second. Drop filler and repetition, keep every fact, number and code name.
- “See you there.” at the end of a chapter is « À tout de suite. » “Welcome back to Learn Text.js.” is « Bon retour dans Learn Text.js. »
