<!-- s:19797c0276 -->
これらのプリミティブは、Yoga flexboxでセルグリッドをレイアウトします。

<!-- s:00be928124 -->
`<Box>`

<!-- s:cdedc6ec73 -->
レイアウト用のコンテナーです。

<!-- s:b2726c7ef5 -->
| プロパティ | 説明 |
| :-- | :-- |
| `className` | セル用ユーティリティー |
| `border` | `single` `rounded` `double` `heavy` `dashed` |
| `title` | 上辺の罫線に埋め込むテキスト |
| `bg` / `fg` | 背景色と文字色 |
| `overflow` | `hidden` または `scroll` |

<!-- s:a83221d138 -->
`<Text>`

<!-- s:ea0876c03f -->
インラインテキストです。ネストした `<Text>` はスタイル付きのスパンになります。

<!-- s:d078a242d3 -->
| プロパティ | 説明 |
| :-- | :-- |
| `color` | 文字色 |
| `bold` `italic` `underline` `dim` | 属性 |
| `wrap` | `wrap` `nowrap` `truncate-end` |

<!-- s:e9a9218253 -->
`<ScrollBox>`

<!-- s:51162fc3b2 -->
スクロール可能な列です。`stickyScroll` はコンテンツが増えてもスクロール位置を最下部に固定します。

<!-- s:9029b4d81b -->
`<Modal>`

<!-- s:3804dec517 -->
背後を暗くし、フォーカスを内部に閉じ込める、中央配置のオーバーレイです。

<!-- s:7a128a8b11 -->
Spacer、Divider、Badge

<!-- s:72e5d35050 -->
レイアウトヘルパー

<!-- s:e76299d593 -->
よく使うflex配置の短縮記法です。

<!-- s:0f066fb217 -->
`<SplitPane>`

<!-- s:20cd99b8e7 -->
2つのペインと区切り線です。`resizable` を指定すると、区切り線が `Tab` キーのフォーカス移動順に加わり、`←` `→` でサイズを変更できます（`Shift` 併用で5セルずつ）。

<!-- s:2143924860 -->
`size` は比率（`0.3`）またはセル数（`24`）です。`direction="column"` はペインを縦に並べます。
