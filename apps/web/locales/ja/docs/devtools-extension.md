<!-- s:263d7e4a86 -->
Text.js DevTools拡張機能は、コンソールの隣に**Text.js**パネルを追加します。コンソールでレンダリングしているアプリを検査します。

<!-- s:becd3b25ff -->
- **コンポーネント：**各コンソールルートのReactツリーと、props、フック、キー、およびそれらに対応する `tx-box` / `tx-text` シーンノードをセル単位で表示します。
- **フレーム：**現在のフレームをセルのグリッドで表示します。セルにカーソルを合わせると、描画したコンポーネントを確認できます。クリックするとノードを選択します。選択したノードは実際のコンソールでハイライトされます。
- **タイムライン：**フレームごとのReact、レイアウト、描画、エンコードの所要時間、スキップしたフレームと出力したフレーム、フレームの出力間隔、`%c` スパンを表示します。
- **コントロール：**出力の一時停止と再開、レイアウトのワイヤーフレームの切り替え、グリッドサイズの固定や自動調整、フレームのテキストコピーができます。

<!-- s:98304b8243 -->
インストール

<!-- s:2452819f12 -->
拡張機能は `packages/devtools-extension` からビルドし、パッケージ化せずに読み込みます。

<!-- s:3754c750b3 -->
1. `chrome://extensions` を開き、**「デベロッパーモード」**をオンにします。
2. **「パッケージ化されていない拡張機能を読み込む」**をクリックし、`packages/devtools-extension/dist` を選択します。
3. アプリを再読み込みしてDevToolsを開きます。ページがコンソールルートを作成すると、**Text.js**パネルが表示されます。

<!-- s:e0c59fa53a -->
ビルド時には、Chromeウェブストアに提出できる `release/textjs-devtools-<version>.zip` も生成されます。

<!-- s:364bc3ef6f -->
コンポーネント

<!-- s:e1204a3559 -->
コンポーネントを選択すると、props、呼び出し順のフック（`State`、`Ref`、`Memo`、`Effect` などとその現在の値）、レンダリングするシーンノードを、セル単位の位置、サイズ、ボックスのインセットとともに確認できます。行にカーソルを合わせると、コンソール内のノードがハイライトされます。**ホストノード**で、コンポーネント間の `tx-box` 要素と `tx-text` 要素の表示を切り替えます。

<!-- s:77b62adc9c -->
パネルを開いている間、コミット後にツリーが更新されます。値は表示用の要約であり、ライブオブジェクトではありません。

<!-- s:a0d819048c -->
フレーム

<!-- s:2cceea6000 -->
フレームインスペクターは、レンダラーのセルバッファーにあるすべてのグリフ、前景色、背景色、属性を描画します。セルにカーソルを合わせると、その文字と色、描画順で最前面にあるシーンノード（`overflow`、スクロールオフセット、`zIndex` を反映）、そのノードをレンダリングしたコンポーネントを確認できます。クリックすると、**コンポーネント**でそのノードが選択され、レンダラー独自のハイライトオーバーレイによって実際のコンソール内でハイライトされます。

<!-- s:57a8990372 -->
タイムライン

<!-- s:2187cf7a17 -->
各バーはレンダラーの1フレームを表します。

<!-- s:f53def4922 -->
| フェーズ | 計測対象 |
| --- | --- |
| React | フレームの開始時にフラッシュされる同期的なReact処理 |
| レイアウト | Yogaによるレイアウト |
| 描画 | シーンのセルバッファーへのラスタライズ |
| エンコード | `%c` 書式文字列の構築と `console.log()` の呼び出し |

<!-- s:9b988f3cfb -->
スキップしたフレームは薄く表示されます。変更がなかったため、何もログ出力されていません。出力間隔のチャートでは、出力したフレーム間の間隔を最小間隔の66msと比較できます。

<!-- s:8abccb04ec -->
時間の計測は `console.log()` で終了します。メッセージの整形と描画はDevTools内で実行され、ページからは観測できないため、タイムラインには表示されません。フレーム間でコミットされた並行レンダリングはコミットとして数えられますが、時間は計測されません。

<!-- s:5ae438610c -->
動作の仕組み

<!-- s:1dda342130 -->
React DevToolsと同様に、この拡張機能はページの実行前にグローバルフックを設置します。

<!-- s:9a7af3e89c -->
すべてのコンソールルートがこのフックに登録されます。ページの最初のルートは、パネルと通信するコード（gzip圧縮で約5 KB）を読み込み、読み込みが完了すると登録されます。後続のルートは作成時に登録されます。拡張機能がなければフックは存在しないため、ルートはその存在を1回確認するだけで、何も読み込まず、フレームごとの処理も実行しません。拡張機能がインストールされていてもパネルが閉じている場合、フレームごとの処理はプロパティーの読み取り1回です。ツリーとフレームは、パネルから要求されたときにのみ計算されます。

<!-- s:843fc9a8ad -->
メッセージはページ→コンテンツスクリプト→サービスワーカー→パネルの順に流れます。アプリの起動前にフックを用意するため、コンテンツスクリプトはすべてのページで実行されます。拡張機能が要求するアクセス権はこれだけです。リモートコードは読み込まず、マシンの外部には何も送信しません。

<!-- s:e425f181df -->
プライバシー

<!-- s:f2cd52a110 -->
この拡張機能はデータを収集しません。ネットワークリクエストも保存もせず、アクセス解析もありません。コンポーネントツリー、フレーム、計測時間は、同じブラウザー内のページとDevToolsパネルの間だけでやり取りされ、DevToolsを閉じると破棄されます。**フレームをコピー**をクリックすると、フレームのテキストがクリップボードに書き込まれます。

<!-- s:639d5ea4c0 -->
制限事項

<!-- s:05616a1196 -->
- ChromeおよびChromiumベースのブラウザーのバージョン111以降に対応しています。
- 拡張機能のインストール前に起動したアプリは、再読み込みが必要です。
- 検査対象はタブの最上位フレームのみです。
- タイムラインはパネルが接続されるとフレームの記録を開始します。
- 時間は `performance.now()` から取得しますが、ブラウザーによって精度が約0.1msに制限されます。
