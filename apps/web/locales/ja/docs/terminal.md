`text run` はApp Routerアプリをターミナルに描画します。レイアウト、コンポーネント、キーマップ、ルートハンドラーはブラウザーと共通です。出力には `%c` スパンではなくトゥルーカラーANSIを使います。

<!-- s:7d8aa376e3 -->
終了するには `Ctrl+C` を押します。`text run` にはBunが必要です。

<!-- s:eed3d00ac7 -->
`text run`

<!-- s:36358c3ead -->
`text run` は `app/` 内のすべてのファイルをインポートし、メモリー内の履歴を使ってApp Routerをマウントして、全画面に描画します。`<Link>`、`useRouter()`、`notFound()`、`redirect()` はそのまま動作します。

<!-- s:75b65c161d -->
同一オリジンの `fetch("/api/...")` 呼び出しは、`text dev` がリクエストを処理するときと同じように、`route.ts` ハンドラーをプロセス内で実行します。それ以外のURLにはネットワーク経由でアクセスします。

`renderToTerminal`

<!-- s:1bcde87690 -->
単一のコンポーネントや独自のCLIには、次のように使います。

<!-- s:e62e62bfaa -->
`useApp().exit()` はアンマウントしてターミナルを元の状態に戻します。

<!-- s:082b75dda7 -->
| オプション | 説明 |
| :-- | :-- |
| `stdin` / `stdout` | デフォルトは `process.stdin` / `process.stdout` |
| `cols` / `rows` | 固定サイズ（デフォルトはターミナルに追従） |
| `altScreen` | 終了時にスクロールバックを復元（デフォルトは `true`） |
| `mouse` | ホイールスクロール（デフォルトは `true`） |
| `exitOnCtrlC` | デフォルトは `true` |
| `fps` | フレームレートの上限（デフォルトは `60`） |
| `patchConsole` | 終了まで `console.*` の出力を保留（デフォルトは `true`） |
| `theme` / `transparent` | `createConsoleRoot` と同じ |

<!-- s:e34e364b9c -->
出力

<!-- s:2ac174afda -->
各フレームの差分を行ごとに計算します。変更された行だけを書き込み、同期出力マーカーで囲むため、対応するターミナルでは描画途中のフレームが表示されません。アイドル状態のアプリは何も書き込みません。

<!-- s:99a3c4d459 -->
入力

<!-- s:4a9817d820 -->
rawモードの標準入力は、ブラウザーが生成するものと同じイベントに解析されます。修飾キー付きの矢印キーやファンクションキー、`Alt` のキーの組み合わせ、ブラケットペースト、SGRマウスホイール、kittyキーボードプロトコルに対応します。ほかの場所でも使えるように、`TerminalInputParser` と `parseTerminalInput` をエクスポートしています。

<!-- s:6b688e229b -->
違い

<!-- s:56ed51fed3 -->
| 機能 | DevTools | ターミナル |
| :-- | :-- | :-- |
| フレームの描画頻度 | 約15fps | 最大 `fps` |
| グリッドサイズ | ドッキングされたコンソール | ターミナルウィンドウ |
| `<Image src>` | canvas経由で読み込み | `pixels` を使用 |
| `console.log` | アプリのフレーム | 終了まで保留 |
