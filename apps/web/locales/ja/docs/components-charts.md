<!-- s:8f99ab8d5a -->
チャートはブロック要素で描画します。棒にはセルあたり8段階、線にはセルあたり2×2のドットグリッドを使います。

<!-- s:9bd48fe162 -->
`<LineChart>`

<!-- s:79abfce919 -->
Y軸と凡例を備えたドットマトリックスの折れ線グラフです。

<!-- s:977778a73f -->
| プロパティ | 説明 |
| :-- | :-- |
| `series` | `{ data, label?, color? }[]` |
| `data` | 単一系列の省略記法 |
| `height` | 行数（デフォルトは `8`） |
| `min` / `max` | 固定の上下限（デフォルトはデータに基づく） |
| `axis` | 最小値・最大値ラベル付きのY軸 |
| `formatValue` | 軸ラベル（デフォルトは `1.2k`） |
| `marker` | `quadrant`（デフォルト）または `braille` |

<!-- s:3827b070cb -->
`braille` はセルあたり2×4のドットを詰め込みます。ターミナルで使ってください。macOSのDevToolsコンソールのフォントであるMenloには点字がなく、フォールバックのグリフはセルより幅が広いためです。

<!-- s:a1d8752203 -->
系列の色のデフォルトは `accent`、`success`、`warning`、`info`、`danger` です。

<!-- s:58352890aa -->
`<BarChart>`

<!-- s:d57e6053f7 -->
ラベルと値を揃えた横棒グラフで、セルの8分の1の精度で描画します。

<!-- s:2d6e002278 -->
`<Sparkline>`

<!-- s:4bb495c66f -->
最新のデータ点で幅全体を埋めます。`height` が `1` より大きい場合は、塗りつぶし領域を描画します。

<!-- s:9b515e6ed1 -->
`sparkline(values)` は同じsparklineを文字列として返します。

<!-- s:ddc43709d7 -->
`<ProgressBar>`

<!-- s:5455ef1226 -->
| プロパティ | 説明 |
| :-- | :-- |
| `value` / `max` | 進捗（不定の場合は省略） |
| `variant` | `block`（滑らか） `line` `thin` |
| `width` | セル数（デフォルトは利用可能な幅全体） |
| `label` | 先頭のテキスト |
| `formatValue` | 末尾のテキスト（デフォルトは `42%`） |

<!-- s:39c076d22f -->
不定のバーはレンダラーのフレームのペースで移動し、出力が一時停止すると止まります。

<!-- s:d5174cb2b9 -->
`<Gradient>`

<!-- s:2239584d9f -->
セルごとに色を補間します。複数行の文字列は1つのグラデーションを共有するため、`<AsciiFont>` と組み合わせて使えます。

<!-- s:99155d62a4 -->
名前付きグラデーションは `geist` `dusk` `ocean` `mono` `ember` です。

<!-- s:22dc53f52a -->
`<Image>`

<!-- s:de5a8a66f8 -->
ChromiumとFirefoxのコンソールは、画像をピクセルスプライトとして描画します。ピクセルアート（256色以下で、半透明のピクセルがないもの）はセルあたり最大8 × 16ピクセル、写真は最大4 × 8ピクセルを保持します。Safari、ターミナル、プレーンテキストのコピーでは `▀` の半ブロックを使い、各セルに2ピクセルを格納して、上側を前景色、下側を背景色で表示します。どこでも半ブロックで描画するには、`renderMode="halfblock"` を渡します。

<!-- s:20dac26bff -->
`src` はキャンバス経由で読み込むため、クロスオリジンの画像にはCORSが必要です。`pixels` はターミナルを含むどの環境でも生のRGBAを受け取ります。

<!-- s:4e3b06ef0e -->
画像を1つのスプライトにできない場合は、ChromiumとFirefoxでも半ブロックで描画します。

<!-- s:00d2e660eb -->
- ギャラリーのように、同じ行に2つの画像を横に並べた場合。
- 写真の横にテキストがある場合。テキストの横にあるピクセルアートはスプライトのままです。
- `overflow="hidden"` のボックスで画像が切り取られている場合、または別のボックスで一部が覆われている場合。
- 透明なピクセルがテキストや複数の背景色に重なっている場合。

<!-- s:dd4fefaac0 -->
`<Pixels>`（実験的）

<!-- s:71eeeca05d -->
`@textjs/react/experimental` は、ゲーム、エミュレーター、動画などのリアルタイムな `0xRRGGBBAA` フレームバッファー向けに `<Pixels>` をエクスポートします。パックされたピクセルを `source.data` に直接書き込み、`frame` を増やして再描画します。

<!-- s:2d12b69e81 -->
| プロパティ | 説明 |
| :-- | :-- |
| `source` | `0xRRGGBBAA` 順の `{ width, height, data: Uint32Array }` |
| `frame` | フレームカウンター。`source.data` の変更後に加算 |
| `width` / `height` | セル数と行数で指定するボックスのサイズ |
| `fit` | `contain`（デフォルト）または `fill` |
| `pixelAspect` | ソースの1ピクセルの表示幅を高さで割った値（デフォルトは `1`） |
| `palette` | 色の量子化に使う任意の `PackedColor[]` パレット |
| `sample` | 半ブロックへのフォールバック時のフィルター：`nearest`（デフォルト）または `average` |
| `renderMode` | `auto`（デフォルト：対応環境ではスプライト、それ以外では `▀` の半ブロック）または `halfblock` |

<!-- s:c90e634603 -->
`renderMode="auto"` はChromiumでピクセル化されたスプライトを描画し、Firefoxではコンソールのスタイル規則に従って描画します（ベンチマーク未実施）。Safari、ターミナル、プレーンテキストのコピーでは `▀` の半ブロックにフォールバックします。どこでも半ブロックで描画するには、`renderMode="halfblock"` を渡します。

<!-- s:5d2bbbc47b -->
Reactを使わずにピクセルを描画するには、`@textjs/core/experimental` から `drawPixels` を、`DrawPixelsOptions`、`PixelSource`、`PixelFit`、`PixelSample`、`PixelRenderMode`、`PixelEncoding`、`PixelRect` とともにインポートします。`encoding: "rgba"` オプションは静止画像の256色を超える色と滑らかなアルファ値を保持し、`fallback` はスプライトを表示できない場所で独自のセルを描画します。実験的エクスポートのバージョン管理については、[破壊的変更](/docs/support-policy#breaking-changes)を参照してください。
