これらの入力コンポーネントはキーボードで操作し、それぞれが自身のフォーカスを管理します。

<!-- s:1d0d345c65 -->
フォーカス

<!-- s:bc06482880 -->
`Tab` と `Shift+Tab` でフォーカスを順に切り替えます。`autoFocus` はマウント時にフォーカスを取得します。

<!-- s:fca23dd943 -->
フォーカス中のエディターはキー入力を自身で処理するため、`1` を入力してもグローバルショートカットは実行されません。

<!-- s:7c862ee98e -->
`<Input>`

<!-- s:fdde26d4d9 -->
readline形式の編集に対応した1行の入力欄です。

<!-- s:88cdcfc0ea -->
| プロパティ | 説明 |
| :-- | :-- |
| `value` / `onChange` | 制御された値 |
| `onSubmit` | `Enter` 押下時の呼び出し |
| `placeholder` | 空欄時の表示 |
| `mask` | 機密情報を隠すマスク文字 |

<!-- s:995d41e175 -->
`<Textarea>`

<!-- s:cf370a7f95 -->
複数行の入力欄です。`Enter` で送信し、`Shift+Enter` で改行を追加します。

<!-- s:667b32bc16 -->
`<Select>`

<!-- s:1c8033c766 -->
キーボードで操作する選択肢リストで、任意であいまい検索を有効にできます。

<!-- s:70fe7d6c9b -->
| プロパティ | 説明 |
| :-- | :-- |
| `options` | `{ value, label, hint?, badge? }[]` |
| `onChange` | `Enter` 押下時の呼び出し |
| `searchable` | 入力による選択肢の絞り込み |

<!-- s:958ee46fb6 -->
`<Tabs>`

<!-- s:f61cb509c5 -->
フォーカスが外れたときのカーソル

<!-- s:f0552feed5 -->
ページからフォーカスが外れると、カーソルが静止してフレームの更新が止まるため、コンソールのテキストを選択してコピーできます。
