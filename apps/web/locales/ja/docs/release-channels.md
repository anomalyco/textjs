Text.jsは3つのnpm dist-tagで配布されます。すべてのパッケージ（`@textjs/app`、`@textjs/react`、`@textjs/core`、`@textjs/font`、`@textjs/opencode`、`create-text-app`、`eslint-plugin-textjs`）のバージョンは同期して更新されるため、1つのバージョン番号がフレームワーク全体を表します。

<!-- s:a2c3664770 -->
チャネル

<!-- s:6b5c5ba172 -->
| チャネル | dist-tag | バージョン | インストール |
| :-- | :-- | :-- | :-- |
| 安定版 | `latest` | `1.0.x` | `bun add @textjs/app` |
| Canary版 | `canary` | `1.0.x-canary.N` | `bun add @textjs/app@canary` |
| LTS版 | `lts`, `v1-lts` | `2.0.0` のリリース後に公開 | `bun add @textjs/app@lts` |

<!-- s:27e8b81dc6 -->
本番環境では安定版を使用してください。修正や機能が `dev` に入った当日に試すには、Canary版を使用してください。LTS系列が提供されたら、年に1回アップグレードする場合はLTS版を使用してください。

<!-- s:abc686bd76 -->
安定版

<!-- s:df32c144c0 -->
安定版リリースは[セマンティックバージョニング](https://semver.org)に従います。パッチではバグを修正し、マイナーでは後方互換性のある機能を追加し、メジャーでは非推奨期間を経てAPIに破壊的変更を加える場合があります。安定版リリースは、テストスイート全体に合格したCanary版から昇格され、npmの来歴情報付きで公開されます。

<!-- s:7307c50761 -->
Canary版

<!-- s:db409040ca -->
公式リポジトリの `dev` へのプッシュごとに、型チェックとテストを実施し、接尾辞 `-canary.N` を付けた次のパッチバージョンとして公開します。

<!-- s:d8b8cffefe -->
| `latest` | `dev` へのプッシュ | 公開バージョン |
| :-- | :-- | :-- |
| `1.0.0` | 初回 | `1.0.1-canary.0` |
| `1.0.0` | 2回目 | `1.0.1-canary.1` |
| `1.0.1` | 次回 | `1.0.2-canary.0` |

<!-- s:dd9c67b1f5 -->
`N` はnpm上にあるCanary版の最大値から続くため、番号が重複することはありません。Canary版のバージョンはリポジトリにコミットされません。リリースをスキップするには、コミットメッセージに `[skip canary]` を追加してください。

<!-- s:762894d754 -->
Canary版は、すべてのプルリクエストのマージ先である `dev` ブランチのビルドです。未リリースのAPIは予告なく変更または削除される場合があります。Canary版に依存する場合は、正確なバージョンを固定してください。

リリースの作成

<!-- s:a3217d58a6 -->
メンテナーはリリーススクリプトを使い、すべてのワークスペースパッケージのバージョンを同期して更新します。

<!-- s:614a1ea872 -->
`release:version` は各 `package.json` とそれを反映するバージョン定数（`VERSION`、reconcilerの `rendererVersion`）を書き換え、パッケージ間でバージョンがずれている場合は実行を拒否し、`--dry-run` では実行計画を表示します。`release:publish` はビルド、パック（`workspace:*` を解決）、`publishConfig` の適用を実施し、プレリリースを `latest` に、または安定版を `canary` に公開することを拒否し、npmにすでに存在するバージョンをスキップします。

<!-- s:ec6955472a -->
各リリース系列のメンテナンス期間については、[サポートポリシー](/docs/support-policy)を参照してください。
