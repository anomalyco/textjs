<!-- s:dd02562b57 -->
`@textjs/font` はFIGfont 2（`.flf`）ファイルを解析し、`figlet` プログラムとまったく同じレイアウトで表示します。各フォントはESモジュールなので、インポートしたフォントだけが配信されます。

<!-- s:a15d12503b -->
インストール

<!-- s:63bfd61a05 -->
使い方

<!-- s:fdffc4b786 -->
`<FigletText>` はフォントと文字列を受け取ります。行はセル単位で計測されるため、ほかの `<Text>` と同じようにflexboxレイアウトに配置できます。

<!-- s:a85abebd7c -->
[`<AsciiFont>`](/docs/components-content#asciifont) も同じフォントを受け取り、組み込みの `block` と `compact` の文字スタイルも引き続き使えます。

<!-- s:9fc6ab3e8b -->
Reactの外では、`renderFiglet` が行ごとに1つの文字列を返します。

<!-- s:1ab8b509e0 -->
レイアウト

<!-- s:d143897d5b -->
水平方向のレイアウトはFIGletのフラグに従います。

<!-- s:115b8ae91e -->
| `layout` | `figlet` | 効果 |
| :-- | :-- | :-- |
| `"default"` | `-s` | フォントのレイアウト。通常はスマッシング |
| `"full"` | `-W` | 全幅。文字同士は接触しない |
| `"fitted"` | `-k` | カーニング。文字同士が接触するまで間隔を詰める |
| `"smushed"` | `-S` | fittedフォントでも、フォントのルールでスマッシング |
| `"universal"` | `-o` | 後の文字を前の文字に重ねる |
| `0`〜`63` | `-m` | 明示的なスマッシングモード |

<!-- s:d9f3601792 -->
水平方向のスマッシングルールは、同一文字、アンダースコア、階層、対向ペア、大きなX、ハードブランクの6種類すべてを実装しています。

<!-- s:889b1e19ef -->
`verticalLayout` は複数行のテキストに適用されます。FIGlet 2.2.5は行間を詰めないため、デフォルトは `"full"` です。`"fitted"`、`"smushed"`、`"universal"` は垂直線のスーパースマッシングを含む5種類の垂直方向ルールを実装し、`"default"` はフォントのルールを使います。

<!-- s:d4ec30b173 -->
折り返しと配置

<!-- s:f799453d05 -->
`columns`（`renderFiglet` では `width`）は単語の区切りを優先し、次に単語の途中で、`figlet -w` とまったく同じ位置で折り返します。`align` は `"left"`、`"center"`、`"right"` のいずれかです。幅を指定しない場合は、最も幅の広い行を基準に各行を揃えます。`ivrit` などの右から左に書くフォントは、右から左に出力され、右揃えになります。`direction` で上書きできます。

<!-- s:f8ccfce091 -->
同梱フォント

<!-- s:15e0b8eca7 -->
| インポート | 行数 | 備考 |
| :-- | :-- | :-- |
| `@textjs/font/standard` | 6 | FIGletのデフォルト |
| `@textjs/font/slant`, `smslant` | 6, 5 | 斜体 |
| `@textjs/font/small` | 5 | コンパクト |
| `@textjs/font/big` | 8 | ギリシャ文字を含む |
| `@textjs/font/banner` | 8 | `#` による文字、カタカナ、キリル文字 |
| `@textjs/font/block`, `lean` | 8 | 輪郭文字、直立と傾斜 |
| `@textjs/font/shadow`, `smshadow` | 5, 4 | ドロップシャドウ |
| `@textjs/font/script`, `smscript` | 7, 5 | 筆記体 |
| `@textjs/font/mini` | 4 | 極小 |
| `@textjs/font/bubble`, `digital` | 4, 3 | 円や四角で囲んだ文字 |
| `@textjs/font/ivrit` | 6 | ヘブライ文字、右から左 |
| `@textjs/font/term` | 1 | 入力をそのまま出力 |

<!-- s:a8ecd7e9c1 -->
すべてのグリフは印字可能なASCIIまたはLatin-1で構成されるため、構成文字はそれぞれDevToolsのMenloで正確に1セルを占めます。`@textjs/font/all` はすべてのフォントに加え、ギャラリー用の `BUNDLED_FONTS` をエクスポートします。フォントはインポート時ではなく、初回レンダリング時に解析されます。

<!-- s:74ff0f95fa -->
カスタムフォント

<!-- s:093892bc6a -->
どのFIGfontも使えます。取得してから解析します。

<!-- s:c2f4ef471e -->
パーサーはヘッダー、コメント行、ハードブランク、終端マーカー、102個の必須文字、および10進数、8進数、16進数のコードタグ付き文字を読み取ります。TOIletの `.tlf` フォントはプレーンテキストとしてレンダリングされます。ASCIIまたは罫線文字で描かれたフォントを推奨します。点字や絵文字はMenloでは1セル幅ではありません。

<!-- s:f64649f401 -->
ライセンス

<!-- s:adad99f0de -->
同梱フォントはFIGlet 2.2.5の配布フォントとバイト単位で同一で、FIGletのBSD 3-Clauseライセンスに従います。各フォントのクレジットはコメント行に保持され、実行時に `font.comment` として参照できます。Doom、Larry 3D、ANSI Shadow、Calvin Sなど、再配布の許可がない人気フォントは同梱していません。

<!-- s:2a50d4cddc -->
`figlet` との照合検証

<!-- s:111c132fa2 -->
テストスイートは、実際の `figlet` 2.2.5バイナリーから記録した273の出力を再現します。対象は、すべての同梱フォントの全レイアウトモード、折り返し、行揃え、右から左へのテキスト、段落モード、FIGlet自体の回帰テスト入力です。すべて完全に一致します。
