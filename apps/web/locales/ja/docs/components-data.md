`<List>`、`<Table>`、`<Tree>` は大規模なデータセットを表示します。表示範囲内の行のみをレンダリングします。

<!-- s:44ffd1d0a7 -->
ナビゲーション

<!-- s:e3dca4574c -->
`<List>`、`<Table>`、`<Tree>` は共通のキーボード操作を使います。

<!-- s:cdac0643be -->
| キー | 操作 |
| :-- | :-- |
| `↑` `↓` / `j` `k` | 移動 |
| `PgUp` `PgDn`, `Ctrl+U` `Ctrl+D` | 1ページ移動、半ページ移動 |
| `Home` `End` / `g` `G` | 先頭、末尾 |
| `↵` | `onSelect` |
| ホイール | カーソルの移動 |

<!-- s:1c65c42a4d -->
デフォルトでは親要素いっぱいに広がります。行数を固定するには `height` を渡します。

<!-- s:3a828804bb -->
`<List>`

<!-- s:2603a57dc8 -->
仮想化されたリストです。各行の高さは1セルです。

<!-- s:3408e68b29 -->
| プロパティ | 説明 |
| :-- | :-- |
| `items` | 任意の配列 |
| `renderItem` | `(item, { highlighted, focused }) => ReactNode` |
| `isItemDisabled` | カーソルがスキップする項目 |
| `height` | 表示行数（デフォルト：親要素いっぱい） |
| `highlightedIndex` / `onHighlight` | 制御されたカーソル |
| `vimKeys` | `j` `k` `g` `G` （デフォルト： `true` ） |

<!-- s:55759482eb -->
`<Table>`

<!-- s:ff77c49577 -->
`width` が設定されていない列は、残りの幅を分け合います。ヘッダーとセルには同じflexルールが適用されるため、常に位置が揃います。

<!-- s:e9719839f0 -->
| 列のフィールド | 説明 |
| :-- | :-- |
| `key` | IDとデフォルトのアクセサー |
| `width` / `grow` | 固定セル数、または残りの幅の配分比率 |
| `align` | `left` `right` `center` |
| `value` | 表示とソートに使う値 |
| `render` | カスタムのセル内容 |
| `compare` | カスタムのソート処理 |

<!-- s:045ee40857 -->
ソート

<!-- s:d04de39344 -->
`sortable` を指定すると、列番号を押してその列でソート（再度押すと方向を反転）、`s` で列を順に切り替え、`S` で方向を反転できます。ソートは安定ソートです。`sort` と `onSortChange` で制御します。

<!-- s:6d625a19ed -->
選択

<!-- s:2132bc20a2 -->
`selectionMode="multiple"` はチェック列を追加し、`Space` でハイライトされた行の選択を切り替えます。選択の制御には `selectedKeys` と `onSelectionChange` を、安定したキーには `getRowKey` を使います。

<!-- s:3bd95f58e2 -->
`<Tree>`

<!-- s:ec4c582ab8 -->
ガイド線付きの展開可能なツリーです。

<!-- s:eeb148154f -->
`→` で枝を展開するか、枝の中へ移動します。`←` で折りたたむか、親へ移動します。`Space` で展開と折りたたみを切り替えます。独自のレンダラーが必要な場合は、`flattenTree(data, expanded)` で表示範囲内の行を取得できます。
