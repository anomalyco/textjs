[OpenCode](https://opencode.ai)はオープンソースのコーディングエージェントです。**OpenCode Lite**は、Text.jsで構築されたOpenCode用のコンソールクライアントです。

<!-- s:a0fa47c98f -->
試用

<!-- s:8b5f5ed2de -->
- このサイトでの利用：[OpenCode](/opencode)にアクセスしてDevToolsを開きます。
- ローカルでの利用：`bunx create-text-app my-app --template opencode`。

<!-- s:db57075dd8 -->
このサイトでは、スクリプトに従って動作するエージェントをサンドボックスで実行しています。任意のプロンプトを入力してください。

<!-- s:867840c638 -->
構成

<!-- s:7b522f9378 -->
| 領域 | コンポーネント |
| :-- | :-- |
| 会話履歴 | `<ScrollBox stickyScroll>` + `<Markdown>` |
| ツールカード | `<Code>` と `<Diff>` |
| プロンプト | `<Textarea>` |
| パレット | `<Modal>` + `<Select searchable>` |

<!-- s:ae25d36239 -->
キー操作

<!-- s:9bda94e125 -->
| キー | 操作 |
| :-- | :-- |
| `Enter` | 送信 |
| `Shift+Tab` | エージェントの切り替え（build / plan） |
| `Ctrl+P` | コマンド |
| `Ctrl+X` の後に `L` | セッション一覧 |
| `Ctrl+X` の後に `N` | 新規セッション |
| `Esc` を2回 | 実行中のセッションの中断 |

<!-- s:b2700ea8eb -->
ローカルサーバーへの接続

<!-- s:a98495bd7f -->
ブリッジを実行したままにします。[OpenCodeページ](/opencode)で `http://127.0.0.1:4096` を入力し、**接続**を押して、Chromeから求められた場合はローカルネットワークへのアクセスを許可します。次に、ブリッジが出力したペアリングコードを入力します。ブリッジが再起動するか、**切断**を押すまで、ページのペアリングは維持されます。接続にはサービスのポートではなくブリッジのURLを使います。ブリッジがサービスの認証情報とCORSヘッダーを提供します。使い終わったらCtrl+Cで停止します。

<!-- s:7c6a89edc5 -->
フォアグラウンドサーバーがすでにポート4096で動作している場合は、`bunx @textjs/opencode@latest proxy --port 4097 --target http://127.0.0.1:4096` を実行し、ページをポート**4097**に接続します。パスワードで保護されたフォアグラウンドサーバーの場合は、ブリッジのシェルでその `OPENCODE_PASSWORD` をexportし、ブラウザーのURLにはパスワードを含めないでください。

<!-- s:951b1ef5cb -->
ブリッジは `@textjs/opencode` パッケージです。依存関係はなく、Node 22以降では `npx` でも実行できます。Text.jsプロジェクト内では、`text proxy` で同じブリッジを起動できます。
