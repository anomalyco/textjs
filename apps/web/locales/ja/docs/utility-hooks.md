Text.jsには、タイマー、アニメーション、計測、永続化のためのフックが含まれています。タイマーとアニメーションは、レンダラーのフレーム間隔に従います。

<!-- s:43bb49a7a4 -->
タイマー

<!-- s:15335858dd -->
どちらも常に最新のコールバックを呼び出します。`null` を渡すと停止します。

<!-- s:dc96b9db35 -->
`useAnimationFrame`

<!-- s:58c49546c3 -->
`useAnimationFrame` はフレームスロットごとに1回実行されます。Text.jsは1秒あたり約15フレームを出力するため、それより速くアニメーションを更新すると、ログに出力されないフレームにCPUを費やします。ループは同じ更新頻度ごとに1つのタイマーを共有し、出力が一時停止している間は停止します。

<!-- s:faffc1716f -->
`useTween` と `useSpring`

<!-- s:e1a9665d36 -->
どちらも目標値に向かってアニメーションする数値を返し、値が落ち着くと更新を停止します。`easings` には `linear`、`easeOutCubic`、`easeInOutCubic`、`easeOutExpo` などが含まれています。

<!-- s:de4c9b6297 -->
`useMeasure`

<!-- s:97430a02ce -->
レイアウトはReactのコミット後に実行されるため、サイズは1フレーム遅れて取得されます。サイズが変わったときにのみ再レンダリングします。

<!-- s:bf30354376 -->
`useBreakpoint`

<!-- s:7a09c8535c -->
| Breakpoint | 列数 |
| :-- | :-- |
| `xs` | 0 |
| `sm` | 60 |
| `md` | 80 |
| `lg` | 110 |
| `xl` | 140 |

<!-- s:c1005c7ee2 -->
ブレークポイントの単位は列数です。独自のしきい値を引数として渡してください。

<!-- s:09d1859930 -->
`useLocalStorage`

<!-- s:cd8360f199 -->
`useLocalStorage` はJSONを `localStorage` に保存し、ブラウザー外ではメモリーに保存します。同じキーを共有するフックは、タブをまたいでも同期を保ちます。

<!-- s:9bf5fe6a8b -->
`useClipboard`

<!-- s:4ad3c688f3 -->
`<FocusScope>`

<!-- s:b57f3d6ddc -->
`<FocusScope>` は不可視のフォーカス境界です。`trap` を指定すると、オーバーレイのない `<Modal>` と同じように、`Tab` と `useInput` の動作範囲がその内側に制限されます。
