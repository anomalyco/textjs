必要な環境

<!-- s:16d53f1055 -->
- [Bun](https://bun.sh) 1.2+またはNode.js 22+
- デスクトップ版のChrome、Edge、Firefox、Safariのいずれか

<!-- s:d7f4dad213 -->
アプリの作成

<!-- s:b32738e24d -->
テンプレート（`starter`、`dashboard`、`opencode` のいずれか）を選び、開発サーバーを起動します。

<!-- s:21fb743289 -->
コンソールを開く

<!-- s:14e4fdc5be -->
`http://localhost:3000` にアクセスし、コンソールを開きます。

<!-- s:a370660339 -->
| ブラウザー | macOS | Windows / Linux |
| :-- | :-- | :-- |
| Chrome, Edge, Arc, Brave | `⌘` `⌥` `J` | `Ctrl` `Shift` `J` |
| Firefox | `⌘` `⌥` `K` | `Ctrl` `Shift` `K` |
| Safari | `⌘` `⌥` `C` | macOSのみ |

<!-- s:de7134a591 -->
Safariでは、まず「設定」→「詳細」で**Webデベロッパ用の機能を表示**をオンにします。

<!-- s:8f6c6cf39e -->
ページをクリックしてフォーカスを合わせてから、入力します。DevToolsを下部に配置すると、グリッドの幅を最大にできます。

<!-- s:9807a8b582 -->
コンソールの設定

<!-- s:803094bd72 -->
コンソールの設定で**ログを保持**をオフにします。Text.jsはフレームごとに1件のメッセージを追加し、古いフレームを解放するためにコンソールをクリアします。「ログを保持」がオンの場合、DevToolsはクリアを無視するため、古いフレームが蓄積されます。

<!-- s:35e7d1d33e -->
手動セットアップ

<!-- s:ff78ccae69 -->
フレームワークを使わない場合

<!-- s:26f8520062 -->
既存のサイトから任意のReactツリーをコンソールにマウントします。
