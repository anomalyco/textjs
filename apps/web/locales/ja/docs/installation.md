動作要件

<!-- s:16d53f1055 -->
- [Bun](https://bun.sh) 1.2+またはNode.js 22+
- デスクトップ版のChrome、Edge、Firefox、Safari

<!-- s:d7f4dad213 -->
アプリの作成

<!-- s:b32738e24d -->
テンプレート（`starter`、`dashboard`、`opencode`）を選択して、開発サーバーを起動します。

<!-- s:21fb743289 -->
コンソールを開く

<!-- s:14e4fdc5be -->
`http://localhost:3000` にアクセスして、コンソールを開きます。

<!-- s:a370660339 -->
| ブラウザー | macOS | Windows / Linux |
| :-- | :-- | :-- |
| Chrome、Edge、Arc、Brave | `⌘` `⌥` `J` | `Ctrl` `Shift` `J` |
| Firefox | `⌘` `⌥` `K` | `Ctrl` `Shift` `K` |
| Safari | `⌘` `⌥` `C` | macOSのみ |

<!-- s:de7134a591 -->
Safariでは、まず「設定」→「詳細」で**「Web開発者向けの機能を表示」**を有効にします。

<!-- s:8f6c6cf39e -->
ページをクリックしてフォーカスを移してから、入力します。DevToolsを下部にドッキングすると、グリッドの幅が最大になります。

<!-- s:9807a8b582 -->
コンソールの設定

<!-- s:803094bd72 -->
コンソールの設定で**「ログを保持」**を無効にします。Text.jsはフレームごとに1件のメッセージを追加し、古いフレームを解放するためにコンソールを消去します。「ログを保持」が有効だと、DevToolsは消去を無視するため、古いフレームが蓄積します。

<!-- s:35e7d1d33e -->
手動セットアップ

<!-- s:ff78ccae69 -->
フレームワークを使わない場合

<!-- s:26f8520062 -->
既存のサイトから任意のReactツリーをコンソールにマウントします。
