`@textjs/app/testing` （または `@textjs/react/testing` ）は、アプリを画面外にレンダリングし、キーを押してフレームをテキストとして返します。テストはブラウザーやDevToolsなしで実行できます。

<!-- s:9bc71b1ad2 -->
Bun、Vitest、Jestなど、 `async` テストに対応する任意のランナーで動作します。

<!-- s:f7898e6b92 -->
レンダリング

<!-- s:fc969a7928 -->
| メソッド | 説明 |
| :-- | :-- |
| `render(el, { cols, rows, theme })` | 画面外へのマウント（デフォルト80×24） |
| `lastFrame()` | プレーンテキストのフレーム |
| `lines()` | 行の配列としてのフレーム |
| `frames` | これまでの重複のない全フレーム |
| `toAnsi()` | スナップショット用のTruecolor ANSI |
| `cell(x, y)` | `{ char, fg, bg, attrs }` |
| `locate(text)` | 最初の一致の `{ x, y }` |
| `rerender(el)` / `unmount()` | 更新または破棄 |

<!-- s:893f22353a -->
`renderToString(el, options)` は1回レンダリングしてテキストを返します。

<!-- s:99a3c4d459 -->
入力

<!-- s:105149560b -->
すべての呼び出しは `act()` 内で実行され、生成されたフレームをフラッシュするため、次のアサーションで更新を確認できます。

<!-- s:1f65c071dc -->
時間

<!-- s:ab365d9403 -->
アニメーション、スピナー、トーストは実際のタイマーを使うため、これらを確実に確認するには `wait` と `waitFor` を使います。

<!-- s:26f93acae3 -->
スナップショット

<!-- s:05724c9883 -->
フレームの右端と下端の空白は取り除かれるため、空白によってスナップショットに差分が生じることはありません。
