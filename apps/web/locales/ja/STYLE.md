# Japanese (ja)

- Polite form: です・ます in docs, UI and marketing. Headings and labels are noun phrases without です.
- Full-width punctuation (、。「」), but keep ASCII punctuation inside code, paths and URLs.
- No space between Japanese and Latin words (`Text.js のアプリ` is wrong; write `Text.jsのアプリ`) except around inline code and links, where one space on each side reads better.
- Katakana for established technical terms (コンポーネント, レイアウト, ルーティング); keep API names, components and hooks in Latin as written.
- Keyboard keys and shortcuts stay as written (⌘⌥J, Ctrl+Shift+J, Enter).
- Marketing copy keeps the deadpan tone: the console-as-production-UI premise is stated straight, never explained.
