# Japanese (ja)

- Polite form: です・ます in docs, UI and marketing. Headings and labels are noun phrases without です.
- Full-width punctuation (、。「」), but keep ASCII punctuation inside code, paths and URLs.
- No space between Japanese and Latin text: `Text.jsのアプリ`, `Chromeで開きます`. Put one space on each side of inline code only: `` `app/` 内の ``, but none between inline code and full-width punctuation (、。（）「」): `` `app/`、 `` and `` （`app/`） ``.
- A sentence that introduces a code block ends with 。, not ：.
- Katakana technical terms take the trailing ー: ブラウザー, フォルダー, ハンドラー, アダプター, エントリー, サーバー.
- Browser interface labels go in 「」 and match the browser's own Japanese interface: 「設定」, 「ログを保持」. The Console panel is コンソール.
- In a list or table, keep items parallel: all noun phrases, or all です・ます sentences.
- Write ranges with 〜: 70〜81%.
- Keep API names, components, hooks, file paths, CLI commands and keyboard shortcuts (⌘⌥J, Ctrl+Shift+J, Enter) as written.
- Avoid translationese and filler: write 〜できます, not 〜することができます. Don't use 〜を行います, 〜となります, 非常に, 簡単に, シームレスに, 強力な, ぜひ, 〜しましょう, rhetorical questions, ―― or 〜だけでなく〜.
- Marketing copy keeps the deadpan tone: the console-as-production-UI premise is stated straight, never explained.
- Arabic numerals for counts, chapters and lines: 全10章, 第6章, 4行, 1回.
- Names kept in English: the Enterprise plan (Enterprise, not エンタープライズ) and the course Learn Text.js. The Learn section and nav are 学習.
- Terms: プリレンダリング, サーバーレンダリング, チャート (not グラフ), スパン, ワードジョイナー, インシデント, 追記 (appending frames), 共通の (shared), エッジ関数, エッジミドルウェア; long-vowel ー on ユーティリティー, ディレクトリー, クエリー, バイナリー, アーキテクチャー, メモリー.
- Merch print slogans stay in English, in 「」: 「YOU WOULDN’T RENDER A WEBSITE IN THE CONSOLE」.
- Table cells in a column read the same way: all noun phrases, ending without です.

## Captions

- Subtitle style, not full narration: about 4 characters per second of speech. Drop filler and repetition, keep every fact, number and code name.
- Questions end with ？. Welcome back is おかえりなさい. The chapter sign-off is それでは、次の章で。
- One wording per idea across chapters: 確認します (not 確認です), 合わせます (not 当てます).
- Arabic numerals: 第6章, 4行.
