<!-- s:cf6b8fc694 -->
これまで、Text.jsアプリでは `useInput` でキーを処理し、同じキーを `<KeyHint>` フッターにも手作業で記載していました。`useKeymap` は、この両方を1つの宣言に置き換えます。

<!-- s:8ec88859eb -->
`j` を押すと `next` が実行されます。macOSでは、これらのバインディングに `hint` が設定されているため、`<KeyHints>` がフッターに `j/↓ Next` と `⌃S Save` を表示します。`?` は4つすべてをNavigationグループにまとめたヘルプ画面を開き、`Ctrl+K` はそれらを検索できるパレットを開きます。

<!-- s:c7c1123a0d -->
キーの構文

<!-- s:e9843726ad -->
| 構文 | 意味 |
| :-- | :-- |
| `ctrl+k` | 修飾キー：`ctrl`、`alt`、`shift`、`meta`、`mod` |
| `mod+k` | `⌘` または `Ctrl` のうち押されている方 |
| `j, down` | いずれかのキー |
| `g g` | キー間の間隔が最大1秒のシーケンス |
| `G` | 大文字は `Shift` を含む指定 |
| `?` | 入力可能なキーは文字と照合 |

<!-- s:5d4b81956d -->
バインディングは、ハンドラー、または `label`、`group`、`hint`、`command`、`disabled`、`noRepeat` を持つオブジェクトです。`command: false` を指定すると、ラベル付きのバインディングがパレットから除外されます。ラベルのないバインディングも動作しますが、ヘルプ画面とパレットには表示されません。

<!-- s:7beff5bd29 -->
ルーティング

<!-- s:5f000bf949 -->
各キーマップは1つの `useInput` ハンドラーを登録するため、既存の入力ルールが適用されます。エディターは優先度10、キーマップは0で入力を受け取るため、フォーカスされた `<Input>` が先にキーを処理します。一致したキーは伝播を停止します。`<Modal>` が開いていると、その外側のバインディングは無効になります。ただし、キーマップが `global: true` を渡している場合は除きます。

<!-- s:a6076c8127 -->
シーケンスは、そのハンドラー内で照合されます。シーケンスを開始するキーは保留状態で保持され、伝播を停止し、次のキーが `sequenceTimeout` （デフォルトで1,000ms）を超えてから届くとシーケンスがリセットされます。

<!-- s:aa0a9c8615 -->
ルートごとに1つのレジストリー

<!-- s:8a689d7ce6 -->
ラベル付きのバインディングは、コンソールのルートに属するレジストリーに公開されます。`<KeyHelp>`、`<KeyHints>`、`<CommandPalette>` はそこから読み取り、独自のコンポーネントでも `useKeymapBindings()` を通じて読み取れます。モーダルが開いている間、レジストリーはその内側のバインディングだけを返すため、ヘルプ画面にはその時点で使えるキーが表示されます。

<!-- s:ab5f364d60 -->
キーマップは通常インラインで記述するため、レンダーのたびに新しいオブジェクトが作られます。このコストを抑えるため、キーマップは表示内容が変わったときだけラベルを再公開します。

<!-- s:fa6b5ba7b8 -->
キーが届いた時点でrefからハンドラーを読み取るため、レンダーごとに作られる新しいクロージャーが古くなることはありません。

<!-- s:1b173acf33 -->
ヘルプ画面とパレット

<!-- s:15201cd425 -->
`<KeyHelp>` は `?` で開き、有効なラベル付きバインディングをすべてグループ別に表示します。`keys` と `title` でトリガーと見出しを変更できます。

<!-- s:8a5c3a3297 -->
`<CommandPalette>` は `Ctrl+K` または `Ctrl+P` で開きます。`commands` とすべてのラベル付きバインディングをあいまい検索し、一致した文字を強調表示します。コマンドを実行する前に閉じるため、コマンドから独自のモーダルを開けます。

<!-- s:bea7ebdffb -->
`formatKeys` は、バインディングを表示用に整形します。`formatKeys("ctrl+shift+p")` はmacOSでは `⌃⇧P`、それ以外では `ctrl+shift+P` を返し、`<Kbd>` は同じ形式で単一のキーを表示します。

<!-- s:d068dd2764 -->
`useKeymap`、`<KeyHelp>`、`<KeyHints>`、`<StatusBar>`、`<CommandPalette>` はText.js 1.0に含まれています。リファレンスは[キーボード](/docs/keyboard)にあります。
