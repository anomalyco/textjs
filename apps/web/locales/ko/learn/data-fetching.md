Acme Deploys에는 실제 데이터가 필요해요. 라우트 핸들러는 `app/`에서 페이지 옆에 위치하고, 웹 `Request`와 `Response` API를 사용하며, `text dev`와 `text start`에서 실행돼요. 앱과 출처가 같아서 요청에 CORS 설정이 필요 없어요.

<!-- s:c6876ef862 -->

<!-- s:b226d3ca25 -->
`text dev`가 실행 중일 때 콘솔 프롬프트에서 호출하세요:

<!-- s:9ce3eb974c -->
페이지에서 데이터 가져오기

<!-- s:c02131685f -->
이펙트에서 데이터를 가져오고 데이터가 도착할 때까지 `<Spinner>`를 표시하세요. `r`은 데이터를 다시 가져오고, `n`은 새 배포를 POST 요청으로 생성해요. 새 배포는 빌드 중으로 표시되다가 빌드가 끝나면 준비 완료로 바뀌어요.

<!-- s:34de603227 -->
로딩 및 오류 상태

<!-- s:8b95fe08be -->
`loading`을 직접 처리하는 대신, 페이지가 일시 중단된 동안 페이지 옆의 `loading.tsx`가 표시되고 `error.tsx`가 페이지에서 발생하는 모든 오류를 잡아요. 둘 다 일반 컴포넌트예요:

<!-- s:6c694827e4 -->
스트리밍

<!-- s:c16e24a117 -->
핸들러는 `ReadableStream`을 반환할 수 있어요. 빌드 로그도 이 방식으로 대시보드에 한 줄씩 스트리밍돼요. 서버 전송 이벤트와 로컬 데몬 프록시는 [라우트 핸들러](/docs/route-handlers)를 참고하세요.
