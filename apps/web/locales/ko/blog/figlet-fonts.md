<!-- s:3c9b7877c3 -->
Text.js 0.3에 FIGlet 폰트용 파서와 렌더러인 `@textjs/font`가 추가됐어요. FIGlet 2.2.5 배포판의 폰트 17개를 각각 하나의 ES 모듈로 제공하며, 출력은 `figlet` 2.2.5 바이너리와 정확히 일치해요.

<!-- s:ffc9f0eae5 -->
FIGlet을 선택한 이유

<!-- s:3ff2fd01df -->
`<AsciiFont>`는 0.1부터 `block`과 `compact`라는 두 가지 내장 글자 스타일을 제공했어요. FIGlet은 1991년부터 이런 글자 스타일의 표준이었고, 수백 개의 `.flf` 폰트가 있어요. 이 형식을 지원하면 어느 폰트든 콘솔 앱에 넣을 수 있어요.

<!-- s:7fdbff5714 -->
FIGlet 폰트는 일반 텍스트 파일이에요. 헤더 줄에서 높이, 하드블랭크 문자, 레이아웃 규칙을 설정하고, 각 문자를 여러 행으로 된 블록으로 그리며 각 행 끝에는 종료 표시를 붙여요. 기본 레이아웃에서 FIGlet은 각 문자를 이전 문자에 닿을 때까지 왼쪽으로 옮긴 다음, 폰트의 겹침 규칙으로 맞닿은 두 구성 문자를 하나로 합칠지 결정해요.

<!-- s:4c761bba4d -->
레이아웃 모드

<!-- s:3f1c38cf92 -->
`figlet`에는 가로 레이아웃이 다섯 가지 있고, `renderFiglet`도 `layout`으로 같은 다섯 가지를 받아요:

<!-- s:51f1b95b8f -->
| `layout` | `figlet` | 효과 |
| :-- | :-- | :-- |
| `"default"` | `-s` | 폰트 자체 레이아웃, 대개 겹침 적용 |
| `"full"` | `-W` | 전체 너비 사용, 문자끼리 닿지 않음 |
| `"fitted"` | `-k` | 문자끼리 닿을 때까지 간격 축소 |
| `"smushed"` | `-S` | 폰트 규칙에 따른 겹침 |
| `"universal"` | `-o` | 뒤 문자가 앞 문자 위에 겹침 |

<!-- s:7a1307992e -->
-1~63의 숫자는 `-m` 레이아웃 모드의 원시 값이에요. `-1`은 전체 너비, `0`은 맞춤 배치이고, `1`~`63`은 겹침 규칙을 선택해요. 가로 겹침 규칙 6가지인 동일 문자, 밑줄, 계층, 반대 쌍, 큰 X, 하드블랭크를 모두 구현했어요. 파서는 형식의 나머지 요소도 처리해요. 주석 줄, 10진수·8진수·16진수 코드 태그가 붙은 문자, 누락 문자 글리프, `ivrit` 같은 오른쪽에서 왼쪽으로 쓰는 폰트도 지원해요.

<!-- s:0c920c94d3 -->
줄바꿈도 FIGlet을 따라요. `width`는 `figlet -w`와 같은 위치인 단어 경계에서 줄을 바꾸고, 단어가 줄보다 길면 단어 안에서 줄을 바꿔요. `figlet -w 80`은 최대 79열을 출력하므로, `-w N`은 `width: N - 1`에 해당해요.

<!-- s:729dda48fc -->
바이너리와의 출력 일치

<!-- s:385fe807a8 -->
`packages/font/test/fixtures/references.json`에는 실제 `figlet` 2.2.5로 모든 번들 폰트를 모든 레이아웃 모드에서 실행해 생성한 출력 273개가 있어요. 줄바꿈, 정렬, 오른쪽에서 왼쪽으로 쓰는 텍스트, 문단 모드, FIGlet 자체 회귀 테스트 입력을 `run-tests.sh`의 플래그와 함께 사용했어요. 각 사례는 인수, 입력, 정확한 출력을 저장하고, 테스트는 명령줄을 다시 옵션으로 변환해요:

<!-- s:d31215cb4b -->
273개가 모두 일치해요. 픽스처를 다시 생성하려면 `figlet` 2.2.5를 `PATH`에 넣고 `bun run --cwd packages/font references`를 실행하세요.

<!-- s:9854b41cbc -->
셀 그리드 위의 폰트

<!-- s:ede6764977 -->
모든 번들 폰트는 출력 가능한 ASCII 또는 Latin-1로 그리므로, 각 구성 문자는 Menlo에서 정확히 1개 셀을 차지하고 그리드에 맞춰져요. `<FigletText>`는 행을 셀 단위로 측정하므로 글자가 다른 `<Text>`처럼 flexbox 레이아웃에 배치되고, `columns`와 `align`이 상자 안에서 줄바꿈과 정렬을 처리해요.

<!-- s:3cedd51e92 -->
각 폰트는 별도 모듈이므로 앱에는 가져온 폰트만 포함되고, 폰트는 가져올 때가 아니라 처음 렌더링할 때 파싱돼요. `@textjs/font/all`은 갤러리용으로 모든 폰트를 내보내요.

<!-- s:9d54eeef4f -->
다른 FIGfont도 런타임에 가져와 파싱할 수 있어요:

<!-- s:f64649f401 -->
라이선스

<!-- s:67e882f6b4 -->
번들 폰트는 `figlet-2.2.5.tar.gz`에 있는 폰트와 바이트 단위로 동일하며, FIGlet의 BSD 3-Clause 라이선스로 배포돼요. 각 폰트는 주석 줄에 제작자 정보를 유지하며, `font.comment`로 확인할 수 있어요. Doom, Larry 3D, ANSI Shadow, Calvin S처럼 재배포 허가가 없는 인기 폰트는 포함하지 않아요.
