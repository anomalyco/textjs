<!-- s:cf6b8fc694 -->
지금까지 Text.js 앱은 `useInput`에서 키를 처리하고, `<KeyHint>` 푸터에 같은 키 목록을 수동으로 한 번 더 작성했어요. `useKeymap`은 선언 하나로 둘 다 처리해요.

<!-- s:8ec88859eb -->
`j`를 누르면 `next`가 실행돼요. macOS에서는 해당 바인딩에 `hint`가 설정되어 있어서 `<KeyHints>`가 푸터에 `j/↓ Next`와 `⌃S Save`를 표시해요. `?`는 Navigation 아래에 4개 바인딩을 모두 모은 도움말 화면을 열고, `Ctrl+K`는 이 바인딩을 검색할 수 있는 팔레트를 열어요.

<!-- s:c7c1123a0d -->
키 문법

<!-- s:e9843726ad -->
| 문법 | 의미 |
| :-- | :-- |
| `ctrl+k` | 보조 키: `ctrl`, `alt`, `shift`, `meta`, `mod` |
| `mod+k` | `⌘` 또는 `Ctrl` 중 누르고 있는 키 |
| `j, down` | 대체 키 |
| `g g` | 키 사이 간격이 최대 1초인 시퀀스 |
| `G` | 대문자는 `Shift`를 포함한다는 의미 |
| `?` | 출력 가능한 키는 해당 문자와 일치 |

<!-- s:5d4b81956d -->
바인딩은 핸들러이거나 `label`, `group`, `hint`, `command`, `disabled`, `noRepeat`가 있는 객체예요. `command: false`는 레이블이 있는 바인딩을 팔레트에서 제외해요. 레이블이 없는 바인딩도 작동하지만 도움말 화면과 팔레트에는 표시되지 않아요.

<!-- s:7beff5bd29 -->
라우팅

<!-- s:5f000bf949 -->
각 키맵은 `useInput` 핸들러를 하나 등록하므로 기존 입력 규칙이 적용돼요. 에디터는 우선순위 10에서, 키맵은 0에서 입력을 수신하므로 포커스된 `<Input>`이 키를 먼저 처리해요. 일치하는 키는 전파를 중단해요. 키맵이 `global: true`를 전달하지 않으면 열린 `<Modal>`은 바깥쪽 바인딩을 비활성화해요.

<!-- s:a6076c8127 -->
시퀀스는 해당 핸들러 안에서 매칭돼요. 시퀀스를 시작하는 키는 대기 상태로 유지되며 전파를 중단하고, 다음 키가 `sequenceTimeout`(기본값 1,000ms)보다 늦게 들어오면 시퀀스가 초기화돼요:

<!-- s:aa0a9c8615 -->
루트마다 하나의 레지스트리

<!-- s:8a689d7ce6 -->
레이블이 있는 바인딩은 콘솔 루트에 속한 레지스트리에 등록돼요. `<KeyHelp>`, `<KeyHints>`, `<CommandPalette>`는 이 레지스트리에서 바인딩을 읽고, 직접 만든 컴포넌트도 `useKeymapBindings()`로 읽을 수 있어요. 모달이 열려 있는 동안 레지스트리는 모달 내부의 바인딩만 반환하므로 도움말 화면에는 현재 작동하는 키가 표시돼요.

<!-- s:ab5f364d60 -->
키맵은 보통 인라인으로 작성하므로 렌더링할 때마다 새 객체가 생겨요. 이 비용을 낮게 유지하기 위해 키맵은 화면에 표시되는 형태가 바뀔 때만 레이블을 다시 등록해요:

<!-- s:fa6b5ba7b8 -->
키가 들어올 때 ref에서 핸들러를 읽으므로 렌더링마다 새로 생기는 클로저가 오래된 상태를 참조하지 않아요.

<!-- s:1b173acf33 -->
도움말 화면과 팔레트

<!-- s:15201cd425 -->
`<KeyHelp>`는 `?`로 열리며 현재 활성화된 모든 레이블 있는 바인딩을 그룹별로 표시해요. `keys`와 `title`로 트리거와 제목을 바꿔요.

<!-- s:8a5c3a3297 -->
`<CommandPalette>`는 `Ctrl+K` 또는 `Ctrl+P`로 열려요. `commands`와 레이블이 있는 모든 바인딩을 퍼지 매칭으로 검색하고, 일치하는 글자를 강조해요. 명령을 실행하기 전에 닫히므로 명령이 자체 모달을 열 수 있어요.

<!-- s:bea7ebdffb -->
`formatKeys`는 표시용 바인딩을 렌더링해요. `formatKeys("ctrl+shift+p")`는 macOS에서 `⌃⇧P`를, 다른 환경에서는 `ctrl+shift+P`를 반환하며, `<Kbd>`는 같은 형식으로 단일 키를 렌더링해요.

<!-- s:d068dd2764 -->
`useKeymap`, `<KeyHelp>`, `<KeyHints>`, `<StatusBar>`, `<CommandPalette>`는 Text.js 1.0에 포함돼요. 레퍼런스는 [키보드](/docs/keyboard)에 있어요.
