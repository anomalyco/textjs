콘솔 열기

<!-- s:14e4fdc5be -->
`http://localhost:3000`에 접속하고 콘솔을 여세요.

<!-- s:a370660339 -->
| 브라우저 | macOS | Windows / Linux |
| :-- | :-- | :-- |
| Chrome, Edge, Arc, Brave | `⌘` `⌥` `J` | `Ctrl` `Shift` `J` |
| Firefox | `⌘` `⌥` `K` | `Ctrl` `Shift` `K` |
| Safari | `⌘` `⌥` `C` | macOS 전용 |

<!-- s:de7134a591 -->
Safari에서는 먼저 ‘설정’ → ‘고급’에서 **‘웹 개발자용 기능 보기’**를 켜세요.

<!-- s:8f6c6cf39e -->
페이지를 클릭해 포커스를 맞춘 다음 입력하세요. DevTools를 하단에 배치하면 그리드를 가장 넓게 사용할 수 있어요.

<!-- s:9807a8b582 -->
콘솔 설정

<!-- s:803094bd72 -->
콘솔 설정에서 **‘로그 보존’**을 끄세요. Text.js는 프레임마다 메시지 하나를 덧붙이고 콘솔을 비워 이전 프레임을 해제해요. ‘로그 보존’이 켜져 있으면 DevTools가 콘솔 비우기를 무시해서 이전 프레임이 쌓여요.
