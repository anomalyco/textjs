이 입력 컴포넌트들은 키보드로 작동하며 포커스를 직접 관리해요.

<!-- s:1d0d345c65 -->
포커스

<!-- s:bc06482880 -->
`Tab`과 `Shift+Tab`으로 포커스를 순환해요. `autoFocus`는 마운트 시 포커스를 가져와요.

<!-- s:fca23dd943 -->
포커스된 편집기가 키 입력을 처리하므로 `1`을 입력해도 전역 단축키가 실행되지 않아요.

<!-- s:7c862ee98e -->
`<Input>`

<!-- s:fdde26d4d9 -->
readline 스타일 편집을 지원하는 한 줄 입력이에요.

<!-- s:88cdcfc0ea -->
| 속성 | 설명 |
| :-- | :-- |
| `value` / `onChange` | 제어되는 값 |
| `onSubmit` | `Enter` 입력 시 호출 |
| `placeholder` | 비어 있을 때 표시 |
| `mask` | 비밀 정보를 가리는 문자 |

<!-- s:995d41e175 -->
`<Textarea>`

<!-- s:cf370a7f95 -->
여러 줄 입력 편집기예요. `Enter`로 제출하고, `Shift+Enter`로 줄바꿈을 추가해요.

<!-- s:667b32bc16 -->
`<Select>`

<!-- s:1c8033c766 -->
퍼지 검색을 선택적으로 지원하는 키보드 옵션 목록이에요.

<!-- s:70fe7d6c9b -->
| 속성 | 설명 |
| :-- | :-- |
| `options` | `{ value, label, hint?, badge? }[]` |
| `onChange` | `Enter` 입력 시 호출 |
| `searchable` | 입력한 내용으로 옵션 필터링 |

<!-- s:958ee46fb6 -->
`<Tabs>`

<!-- s:f61cb509c5 -->
포커스가 없을 때의 커서

<!-- s:f0552feed5 -->
페이지가 포커스를 잃으면 커서와 프레임이 멈추므로 콘솔 텍스트를 선택하고 복사할 수 있어요.
