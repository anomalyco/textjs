`@textjs/app/testing`(또는 `@textjs/react/testing`)은 앱을 화면 밖에서 렌더링하고, 키를 누르고, 프레임을 텍스트로 반환해요. 테스트는 브라우저나 DevTools 없이 실행돼요.

<!-- s:9bc71b1ad2 -->
Bun, Vitest, Jest를 비롯해 `async` 테스트를 지원하는 모든 러너에서 작동해요.

<!-- s:f7898e6b92 -->
렌더링

<!-- s:fc969a7928 -->
| 메서드 | 설명 |
| :-- | :-- |
| `render(el, { cols, rows, theme })` | 화면 밖에 마운트 (기본값 80×24) |
| `lastFrame()` | 일반 텍스트로 된 프레임 |
| `lines()` | 행 배열로 된 프레임 |
| `frames` | 지금까지의 서로 다른 모든 프레임 |
| `toAnsi()` | 스냅샷용 트루컬러 ANSI |
| `cell(x, y)` | `{ char, fg, bg, attrs }` |
| `locate(text)` | 첫 번째 일치 항목의 `{ x, y }` |
| `rerender(el)` / `unmount()` | 업데이트 또는 해제 |

<!-- s:893f22353a -->
`renderToString(el, options)`는 한 번 렌더링하고 텍스트를 반환해요.

<!-- s:99a3c4d459 -->
입력

<!-- s:105149560b -->
모든 호출은 `act()` 안에서 실행되고 결과 프레임을 모두 반영하므로, 다음 검증에서 업데이트를 확인할 수 있어요.

<!-- s:1f65c071dc -->
시간

<!-- s:ab365d9403 -->
애니메이션, 스피너, 토스트는 실제 타이머를 사용하므로, `wait`와 `waitFor`로 상태를 안정적으로 확인할 수 있어요.

<!-- s:26f93acae3 -->
스냅샷

<!-- s:05724c9883 -->
프레임의 오른쪽과 아래쪽 공백을 제거하므로, 공백 때문에 스냅샷이 계속 바뀌지 않아요.
